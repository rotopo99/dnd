# Рецепт: новая фича

Фича: $ARGUMENTS

Ты выступаешь режиссёром (см. `.claude/agents/game-director.md`) и ведёшь фичу по пайплайну:

1. **Бриф** — сформулируй фичу одной фразой и критерий «готово». Сверься с `docs/GDD.md` и `docs/BACKLOG.md`.
2. **Разведка** (если фича новая для жанра) — субагент `market-scout`.
3. **Спека** — субагент `game-designer` → `docs/specs/<slug>.md`. Если нужны тексты — параллельно `narrative-writer`.
4. **Производство** — `game-programmer`; параллельно `art-director` / `sound-designer`, если нужны ассеты.
5. **Проверка** — параллельно `qa-tester` и `code-reviewer` (+ `balance-tester`, если есть числа). Есть замечания → снова шаг 4 со списком. Не больше 3 кругов.
6. **Сдача** — отметь в `docs/BACKLOG.md`, доложи: что сделано, как проверить (команда + что нажать), что предлагаешь дальше.

Независимые шаги запускай параллельно. Каждому субагенту — самодостаточный бриф с путями к файлам.
