# DnD — игра, которую делает команда агентов

## Что это
Браузерная игра (жанр/концепт уточняется — см. `docs/GDD.md`).
Над ней работает студия из агентов: один **режиссёр** раздаёт задачи **отделам-субагентам**.
Схема команды — `docs/TEAM.md`.

## Как запускать команду
- Полный режим (режиссёр в главном чате): `claude --agent game-director`
- Обычный чат: попроси «сделай фичу X» или вызови `/new-feature X` — пайплайн тот же.

## Техника
- Игра: чистый HTML5 Canvas + ES-модули, **без сборки и без зависимостей**. Вход — `game/index.html`.
- Код игры — `game/src/`. Один модуль = одна система (`input.js`, `render.js`, `scenes/…`).
- Локальный запуск: `python3 -m http.server 8000` в корне → http://localhost:8000/game/
- Плейтест: `node tools/playtest.mjs` (Playwright: скриншот + ошибки консоли).

## Источники правды
- `docs/GDD.md` — дизайн-документ. Меняет только `game-designer` (или по прямой просьбе человека).
- `docs/STYLE.md` — визуальный стиль и палитра. Меняет `art-director`.
- `docs/BACKLOG.md` — задачи и статусы. Ведёт `game-director`.

## Правила
- Отвечай пользователю по-русски. Код, имена файлов и коммиты — по-английски.
- Маленькие шаги: каждая фича должна оставлять игру запускаемой.
- Перед коммитом — плейтест без ошибок консоли.
- Не удалять файлы массово (`rm -rf` заблокирован хуком).
