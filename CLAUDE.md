# DnD — игра, которую делает команда агентов

## Что это
Браузерная RPG по настольной «Руслании Лайт» (постапокалипсис, киберспейс, кринж). Концепт — `docs/GDD.md`, канон — `docs/canon/`.
Над ней работает студия из агентов: один **режиссёр** раздаёт задачи **отделам-субагентам**.
Схема команды — `docs/TEAM.md`.

## Как запускать команду
- Полный режим (режиссёр в главном чате): `claude --agent game-director`
- Обычный чат: попроси «сделай фичу X» или вызови `/new-feature X` — пайплайн тот же.

## Техника
- Игра: чистый HTML5 Canvas + ES-модули, **без сборки и без зависимостей**. Вход — `game/index.html`.
- Код игры — `game/src/`. Один модуль = одна система (`input.js`, `render.js`, `scenes/…`).
- Локальный запуск: `python3 -m http.server 8000` в корне → http://localhost:8000/game/
- Плейтест: `node tools/playtest.mjs` (Playwright: скриншот + ошибки консоли).

## Источники правды
- `docs/canon/` — **первоисточник**: лор и правила настолки «Руслания Лайт». Не переписывать, не выдумывать поверх. Расхождения — в `docs/canon/README.md`, решения — в GDD.
- `docs/GDD.md` — дизайн-документ. Меняет только `game-designer` (или по прямой просьбе человека).
- `docs/STYLE.md` — визуальный стиль и палитра. Меняет `art-director`.
- `docs/BACKLOG.md` — задачи и статусы. Ведёт `game-director`.
- `docs/CODEMAP.md` — карта кода. Ведёт `game-programmer`.

## Правила
- Отвечай пользователю по-русски. Код, имена файлов и коммиты — по-английски.
- Маленькие шаги: каждая фича должна оставлять игру запускаемой.
- Перед коммитом — плейтест без ошибок консоли.
- Репозиторий **публичный**: никаких реальных имён игроков, контактов и личных данных.
- Не удалять файлы массово (`rm -rf` заблокирован хуком).

## Экономия лимита
- Отделы на моделях по сложности: программисты — основная модель; дизайн, сценарий, арт, ревью, QA, баланс — sonnet; звук и разведка — haiku.
- **Не больше 3 агентов параллельно.** Агента с раздутым контекстом (сотни тысяч токенов) не продолжать — запускать свежего с коротким брифом и ссылками на файлы.
- Канон — сначала `docs/canon/SUMMARY.md`, полные файлы канона — точечно.
- Отчёты агентов — до 250 слов, детали — в файлах.
- Сначала `docs/CODEMAP.md`, потом точечный поиск (Grep), и только потом открывать файлы. Не читать файлы «на всякий случай».
- Тяжёлое исследование отдавать субагенту: его контекст выбрасывается, в главный чат возвращается только вывод.
- Длинная сессия: важное держать в `docs/`, а не в чате.

## Compact instructions
При сжатии контекста сохраняй **дословно**, без пересказа: текущую задачу человека,
тексты ошибок, пути к файлам и номера строк, решения человека (одобрил/отклонил).
Выбрасывай: вывод `ls`/`cat`, старые версии файлов, промежуточные рассуждения.
