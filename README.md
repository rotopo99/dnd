# DnD

Браузерная игра, которую делает студия Claude-агентов: режиссёр + 9 субагентов-отделов.

```bash
claude --agent game-director   # запустить студию
/gdd                           # придумать концепт
/new-feature <задача>          # провести фичу через всю команду
node tools/playtest.mjs        # плейтест: скриншоты + ошибки консоли
```

Устройство команды — [docs/TEAM.md](docs/TEAM.md). Правила проекта — [CLAUDE.md](CLAUDE.md).
