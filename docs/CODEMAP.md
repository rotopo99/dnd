# Code Map

> Карта кода: читай её **вместо того, чтобы открывать файлы подряд**.
> Ведёт `game-programmer` и обновляет в том же коммите, где меняет структуру.
> Формат: файл — за что отвечает — главные экспорты — кто вызывает.

## Вход
- `game/index.html` — `<link>` Google Fonts Russo One (неблокирующий, `display=swap`; офлайн — системный sans); три canvas в одной ячейке грида: `#gl` (старый WebGL2) и `#gl3` (Three.js) снизу (`pointer-events: none`, виден только слой, рисовавший 3D в этом кадре) и `#game` (Canvas 2D, весь UI, ввод); importmap `three` / `three/addons/` / `@pixiv/three-vrm` → `game/vendor/` (относительные пути), фон `#14141c` (цвет `0`), грузит `src/main.js`.
- `game/src/main.js` — игровой цикл (фиксированный шаг 1/60), объект `game` { ctx, canvas, width, height, input, data, hero, save, time, scene, setScene, resume, modals, openModal, closeModal, toasts, toast }; пока открыт модал, сцена не получает `update`. Canvas = размер окна 1:1 (минимум 1280×720, меньше — даунскейл CSS); на resize зовёт `scene.resize?.(game)`. `game.gfx` — WebGL-слой (`gfx/scene3d.js createGfx`: размер как у `#game`, `endFrame()` после кадра прячет `#gl`, если сцена его не использовала; потеря контекста > 2 с → 2D + тост). Three.js-бэкенд грузится динамическим `import('./three/engine.js')` → `game.gfx.three` (ошибка — `game.gfx.threeFailed`, 3D на старом рендере). `window.__game` для плейтестов (`__game.scene.id`, у боя `__game.scene.S`). Кооп (multiplayer.md этап 3): если есть `game.coop` — `game.coop.sceneUpdate` вместо `scene.update` (гость: фильтр ввода), `game.coop.tick` каждый шаг, `game.coop.render` поверх сцены. Звук окна: `openModal` → `play('open')`, `closeModal` → `play('close')`.

## Системы
- `game/src/input.js` — `createInput(target, canvas)` → { isDown(code), wasPressed(code), typed() (символы за шаг), mouse { x, y, clicked, rightClicked, inside, down (кнопка зажата), released (отпущена за шаг), wheel (±шаги колеса за шаг), middle / right (зажаты средняя / правая — сдвиг 3D-камеры; средняя никогда не клик; `rightClicked` — на отпускании и только если сдвиг < `GFX.camera.dragMin` px, правый drag не снимает выбор) }, endFrame() }. Координаты мыши — в пикселях canvas. Вызывает: `main.js`.

## Движок правил (`game/src/rules/`)
Чистый JS без DOM и без импорта данных: данные передаются параметром `data`
(`{ RACES, CLASSES, STATUSES, ENEMIES, SUMMONS?, ENCOUNTERS, VEIL_TABLE, PROXY_STORM_TABLE, SURFACES?, SURFACE_RULES? }`, ключи можно и в нижнем регистре; `normalizeData`).

Решения по дырам спеки — комментарий в начале файла.
