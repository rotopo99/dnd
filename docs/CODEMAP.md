# Code Map

> Карта кода: читай её **вместо того, чтобы открывать файлы подряд**.
> Ведёт `game-programmer` и обновляет в том же коммите, где меняет структуру.
> Формат: файл — за что отвечает — главные экспорты — кто вызывает.

## Вход
- `game/index.html` — canvas на всё окно, фон `#14141c` (цвет `0`), грузит `src/main.js`.
- `game/src/main.js` — игровой цикл (фиксированный шаг 1/60), объект `game` { ctx, canvas, width, height, input, data, hero, save, time, scene, setScene, resume, modals, openModal, closeModal, toasts, toast }; пока открыт модал, сцена не получает `update`. Canvas = размер окна 1:1 (минимум 1280×720, меньше — даунскейл CSS); на resize зовёт `scene.resize?.(game)`. `window.__game` для плейтестов (`__game.scene.id`, у боя `__game.scene.S`).

## Системы
- `game/src/input.js` — `createInput(target, canvas)` → { isDown(code), wasPressed(code), typed() (символы за шаг), mouse { x, y, clicked, rightClicked, inside, down (кнопка зажата), released (отпущена за шаг), wheel (±шаги колеса за шаг) }, endFrame() }. Координаты мыши — в пикселях canvas. Вызывает: `main.js`.

## UI (`game/src/ui/`)
- `draw.js` — `C` (палитра по ключу), шрифты `FONT/FONT_B/FONT_L/FONT_XL`, `LINE`, `text`, `wrap` (кеш), `textBlock`, `fit`, `panel`, `button`, `hitButton`, `inRect`, `bar` (полоса ресурса по STYLE; `RES_COLORS` hp/mrl/enr/xp), `resLine`, `icon`/`drawIcon` (PNG из `game/assets/icons/`), `clear`.
- `scroll.js` — прокрутка области: `createScroll()` → `{off, max, drag, atEnd}`, `updateScroll(s, view, contentH, mouse, {step, follow})` (колесо над областью + слайдер справа: тянуть ползунок / клик по дорожке; `follow` — держаться конца; → true, если мышь занята слайдером), `beginClip/endClip`, `drawScrollbar`, `SCROLLBAR_W`. Журнал, лог боя, вкладка «Характеристики».
- `details.js` — панель деталей: `createDetails()`, `updateDetails(d, rect, mouse)` (колесо/слайдер, → true если слайдер занят), `drawDetails(ctx, d, rect, spec, key)` (спека подсказки целиком: перенос слов, прокрутка через `scroll.js`, смена `key` — к началу); `specRows(ctx, spec, w)` / `drawRows` — общая раскладка строк с `tooltip.js` (строки могут иметь `font`). Модал (`detail`), `create-talents.js`.
- `tooltip.js` — (текст без обрезки: перенос, высота по содержимому, не влезает по высоте — шире до ширины экрана, не выходит за экран) всплывающие подсказки: экраны в `render` регистрируют `hotspot(x, y, w, h, spec | () => spec)` или `showTip(spec)`; `main.js` рисует подсказку под мышью последней (`renderTips`; под модалом подсказки сцены сбрасываются `clearTips`). Спека `{title, titleColor?, glyph?: {ch, color}, lines: [string | {text, color}], width?}`. `lastTip()` — для тестов.
- `tips.js` — спеки подсказок терминов: `resTip('hp'|'mrl'|'enr'|'kb'|'xp')` (тексты `tip.res.*`), `statusTip(id, statuses, extra?)` (`STATUSES[id].desc`; Этап B: тик, «Снимается», `extra {turns, source, resist}`), `surfaceTip(layer, step?)`, `surfaceLines(a)` («Создаёт / Накладывает» — в `abilityTip` и `itemTip`), `abilityTip(a)`, `talentTip(id | talent)` (род, канон, описание, способности в числах — ЭНР/дальность/зона/раз за бой, «Вне боя»: навыки +N и `WORLD_FLAGS`, требования), `termTip(str, statuses, abilities)` (статус/способность по имени в сегменте лога); `xpInfo(xp, level)`, `xpLine(ctx, x, y, w, xp, level, {small})` (полоса опыта до следующего уровня + подсказка), `resLineTip` (= `resLine` + подсказка), `termText`.
- `save-ui.js` — окна сохранения: `openSaveMenu(game, onDone?)` (ручные слоты 1–4), `openLoadMenu(game, onCancel?)` (Авто + слоты: имя, уровень, место, день, дата/время — `slotSummary`), `openPauseMenu(game, {canSave, onMenu})` (Продолжить / Сохранить / Загрузить / В главное меню), `startFromSave(game, save)`, `continueLatest(game)` (самый свежий слот).
- `surface-view.js` (Этап B) — `drawSurfaces(ctx, S, tms, 'floor'|'gas')` (заливка α 0.35 + кромка 2 px, анимации: огонь 3 кадра × 0.15 с, ток — дуги, блики, пузыри, пульс, полосы; газ — туман поверх юнитов), `drawBarrels`, `surfaceHover(S, hero, inReach)` (подсказка клетки + «Шаг сюда»). Вызывает `battle-view.js`.
- `battle-log.js` — `formatEvent(S, e)` → строка лога (сегменты `[text, colour]`), `eventSound(S, e)` → `play(...)`, `teamColor(u)`.
- `battle-view.js` — `layoutBattle(game, S)` (+ `.buttons(S)` — при многих способностях две строки, `.result(game, S)`), `renderBattle(game, S)`, `isHiddenFoe(u)`. Портреты v2: карточка активного юнита (×2) и цели (×1), мини-портрет в `storyBubble`; живые hp/mrl из `S.dispOf(u)`, эмоция `d.emo` пока `d.emoT > 0` (ставит `emote` в `battle.js`: урон → angry/scared, «Срыв» → cringe/scared, крит → smug/happy, лечение → happy; `EMO_HOLD` 1.5 с).
- `battle-terrain.js` (combat-rework) — `liveChar`, `drawTileExtra` (высоты с кромкой, бетон/стена/стеллаж/генератор/обломки процедурно), `drawObjects` (полоски ЗДР объектов, рамки «Пробить» в режиме атаки, подсказка объекта/высоты), `drawIntents` (иконки намерений + подсказка), `drawOddsCard` (шанс · урон · укрытие/высота/фланг у цели), `drawHelp` (строка помощи, индикатор ×2/пропуска). Вызывает `battle-view.js`.
- `unit-pin.js` — закреплённая карточка юнита: `createPin`, `pinUnit(S, u)` (повтор — открепить), `updatePin(S, m, inp)` (×, ПКМ, прокрутка; true — мышь занята), `drawPin` (портрет, фракция/ранг, ресурсы, КБ, оружие, архетип/фаза/намерение, сопротивления, статусы и способности с подсказками), `intentText`. `S.pin` в `battle.js`.
- `emotion.js` — `detectEmotion(text)` (правила по тексту: кринж → cringe, `?!` → surprised, смех/«ха» → happy, страх → scared, угрозы/`!` → angry, `…`/грусть → sad, иначе neutral), `lineEmotion(line)` (поле `emo` важнее).
- `portrait-of.js` — кто на портрете: `heroBuild(h)` (save.hero или юнит → build без имени: лицо стабильно с создания), `speakerSubject(who)` (алиасы `victor` → `victor-sundown` и т.п., культисты/скрилет — look-объекты), `enemySubject(enemyId)` (раса по фракции/тегам), `wounds(u)`, `partyWounds(members)`, `drawUnitPortrait(ctx, u, x, y, scale, opts)`, `drawSpeaker(ctx, who, x, y, scale, opts, { hero, wounds })`, `crispScale(px)`.
- `avatar3d.js` — 3D-аватар героя (Canvas 2D, ≤ 600 граней, палитра STYLE): `LOOK_OPTIONS`, `defaultLook(race, gender, seed)`, `buildAvatarMesh(look)` → `{faces, mats, count}`, `renderAvatar(ctx, mesh, {x,y,size,yaw,pitch,light,zoom})`, `avatarToPortrait(look, size)` (кеш offscreen), `isLook3d`. Вызывают: `create-look.js`, `portrait-of.js drawSpeaker` (`info.hero.avatar`). Проверка — `tools/out/avatar.mjs`.
- `modal.js` — модальные окна (стек `game.modals`; спека `{ title, lines, options:[{label, sub, disabled, keep, run, tip?, detail?, inert?}], build?, onCancel? }`, клавиши 1–9/Enter/Esc; есть `detail` у опций → справа панель деталей (`ui/details.js`, ширина окна +416) с полной карточкой наведённой/последней опции, подсказки `tip` таких опций не показываются, `m._detail` — показанная спека (тесты); `inert` — строка-информация (лут), не выбирается, без номера; длинные списки — страницы ◀ ▶, последняя опция на каждой странице) и тосты (`game.toast(text, colour)`, справа сверху): `updateModal`, `renderModal`, `updateToasts`, `renderToasts`, `message`.
- `items-ui.js` (v3) — тексты предметов: `itemStats(it)` (строка чисел), `soonNote(it)` («скоро: …» для полей `needs`), `unmetReq(it, u)`, `itemTier(u, it)`, `tierName(n)`, `weaponTypeName`, `armorTypeName`, `itemTip(it, {u, equipped, price, have, tier})` → спека подсказки предмета (значок по слоту, тип, кости, КБ, свойства `props` (`prop.*`), эффект, цена, требования, ступень, сравнение с надетым).
- `recruit-ui.js` (companions-scenes.md) — `openRecruit(game, npc, onDone(game, joined))`: реплика `pitch`, условия основного и запасного пути (✓ / ✗ + `why` / ? «бросок при согласии»), кнопки «Позвать» / «Запасной путь» / «Извиниться» (ушедший); проверки пути — через `openCheckScene` (autoScene), затем `joinCompanion`. `pathLines(path)`. - `bark.js` — пузырь реплики напарника с портретом (`COMPANION_RULES.barks.durationSec`, снизу слева): `updateBarks(game, dt)` (берёт очередь `world/barks.js`, `game.barks` — кулдауны, `game.bark` — показанная), `renderBark(game)`. Зовёт `main.js` каждый шаг / кадр.
- `checks-ui.js` — окна проверок навыков: `openCheck` (выбор навыка → кто бросает → бросок с режимом и модификаторами; v4: первая опция «Бросает лучший» — лучшая пара член партии × навык, `o.auto`), групповая — ожидаемые успехи по навыку, `openGroupCheck`, `openChallenge` (N успехов до M провалов), `resultLines`.
