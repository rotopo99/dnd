# Style Guide

> Владелец — `art-director`.

- Тайл: 16×16 px, рендер с масштабом ×3, `imageSmoothingEnabled = false`.
- Контур: 1 px, цвет `0` палитры.
- Шрифт UI: моноширинный системный, размеры кратны 8 px.
