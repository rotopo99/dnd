# Студия агентов

```
                          ┌──────────────────────┐
          человек  ──────▶│    game-director     │  главный агент (режиссёр)
                          │ планирует · раздаёт  │  claude --agent game-director
                          └──────────┬───────────┘
        ┌──────────────┬────────────┼──────────────┬─────────────────┐
    РАЗВЕДКА         ДИЗАЙН     ПРОИЗВОДСТВО      АРТ И ЗВУК        ПРОВЕРКА
  market-scout   game-designer  game-programmer  art-director     qa-tester
                 narrative-                      sound-designer   balance-tester
                 writer                                           code-reviewer
```

**Принцип из роликов: «один ищет, другой пишет, третий проверяет».**
Режиссёр сам код не пишет: ставит задачу, отдаёт её отделу и не принимает работу без проверки.

## Термины по-человечески
- **Агент** — помощник, которому отдаёшь задачу целиком.
- **Субагент** — помощник помощника. Режиссёр зовёт его под конкретную подзадачу. У субагента свой чистый контекст, поэтому главный чат не забивается.
- **Скилл** — рецепт: пошаговая инструкция, которую вызывают командой (`/new-feature`, `/gdd`, `/playtest`, `/devlog`).
- **Память агента** (`memory: project`) — агент записывает, что ты одобрил и что отклонил, и учится на этом.
- **Хук** — правило-охранник. Рекурсивный `rm`, force-push, `reset --hard` блокируются автоматически (`.claude/hooks/block-dangerous.sh`).
- **Контекст** — «голова» агента. Переполнилась — начинай новый чат: всё важное лежит в `docs/`.

## Агенты (`.claude/agents/`)
| Агент | Роль | Модель | Память |
|---|---|---|---|
| game-director | режиссёр, раздаёт задачи | inherit | да |
| market-scout | референсы, тренды, идеи | sonnet | да |
| game-designer | механики, GDD, спеки | inherit | да |
| narrative-writer | сюжет, диалоги, тексты | inherit | — |
| art-director | пиксель-арт кодом, палитра | inherit | да |
| sound-designer | звуки через WebAudio | inherit | — |
| game-programmer | весь код в `game/` | inherit | да |
| qa-tester | плейтест в браузере, баги | sonnet | — |
| balance-tester | симуляции, цифры | sonnet | — |
| code-reviewer | ревью диффа | inherit | — |

## Скиллы (`.claude/skills/`)
| Команда | Что делает |
|---|---|
| `/gdd [идея]` | создать/обновить концепт игры и первый бэклог |
| `/new-feature <что>` | провести фичу через всю студию |
| `/playtest` | скриншоты + ошибки консоли |
| `/devlog` | девлог и сценарий короткого ролика о прогрессе |

## Как начать
1. `claude --agent game-director` (или обычный `claude` — скиллы работают и так).
2. `/gdd` — ответь на пару вопросов про игру.
3. `/new-feature <первая задача из BACKLOG>` — и дальше по списку.

**Студия по расписанию.** Можно настроить scheduled task в Claude Code
(например, каждое утро) с промптом `/new-feature следующая задача из docs/BACKLOG.md` —
пока ты спишь, команда делает задачу, а утром ты читаешь отчёт.
