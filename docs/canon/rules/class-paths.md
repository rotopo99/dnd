# Пути развития классов по уровням (1–15)

> Канон из наработок игры «Руслания Лайт». Текст перенесён как есть, без правок по смыслу.

Путь развития

1. Забивной (аналог Воина)

Путь Механизированного Убийцы

Уровень 1:

Боевой стиль: Выберите один из стилей: Двуручное оружие (+2 к урону), Защита (+1 к защите), или Дуэлянт (+2 к урону при одноручном оружии).

Кибернетические импланты: +1 к Силе или Ловкости.

Уровень 2:

Дополнительная атака: Может совершить одну дополнительную атаку как бонусное действие (1 раз за бой).

Уровень 3:

Скрытые клинки: Может использовать скрытые клинки для атаки из укрытия (+2d6 урона).

Уровень 5:

Энергетический щит: Может активировать энергетический щит, поглощающий 1d6 урона каждый ход.

Уровень 7:

Улучшенные импланты: +2 к Силе или Ловкости.

Уровень 9:

Смертельный удар: При атаке из укрытия наносит дополнительный урон (3d6).

Уровень 11:

Тройная атака: Может совершить три атаки за ход.

Уровень 13:

Кибернетическая ярость: Входит в состояние ярости, увеличивая урон на 2d6 на 3 хода.

Уровень 15:

Импланты высшего уровня: +3 к Силе или Ловкости.

Путь Снайпера Пустошей

Уровень 1:

Боевой стиль: Выберите один из стилей: Дальний бой (+2 к атаке), Защита (+1 к защите), или Меткий стрелок (игнорирует половину укрытия).

Снайперский прицел: +2 к атаке при дальнем бою.

Уровень 2:

Дополнительная атака: Может совершить одну дополнительную атаку как бонусное действие (1 раз за бой).

Уровень 3:

Дроны-разведчики: Может использовать дроны для разведки (видит врагов в радиусе 30 метров).

Уровень 5:

Снайперский выстрел: Может совершить критический удар с увеличенным уроном (3d10).

Уровень 7:

Улучшенный прицел: +3 к атаке при дальнем бою.

Уровень 9:

Энергетический выстрел: Может стрелять энергетическими зарядами, наносящими дополнительный урон (2d8).

Уровень 11:

Тройная атака: Может совершить три атаки за ход.

Уровень 13:

Скрытный снайпер: Может становиться невидимым на 1d4 хода.

Уровень 15:

Смертельный выстрел: Критический удар наносит 5d10 урона.
