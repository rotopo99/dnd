# Проекты «Лис» и «Волк»

> Дата: 2026-11-04. Автор: game-designer. **Статус: предложено, вне канона, не противоречит.**
> Канон автора (`docs/canon/README.md`, п. 9) говорит только: «Лис» — секретный оружейный проект неизвестной компании; модели называются «лисами»; Лис-1 — огромный мех/экзокостюм с ИИ (как в Titanfall), Лис-2 — система залпового огня «и т. п.»; «Бункер Лиса» — объект проекта. Похожий проект — «Волк».
> Всё остальное ниже (номера 3–9, название «Волк», его владелец и устройство) придумано нами. Автор может заменить любой пункт.

## Проект «Лис»
**Суть.** Довоенная (до ЭВК) разработка неназванной компании: штучные дорогие машины с **собственным ИИ-характером** («хитрость», отсюда лисы). Рыжая и белая заводская окраска, лисья морда на шильдиках. Каждая модель — отдельный «зверёк» с повадками: разведчик, нора, шкура, хвост. Модели делались вручную, поэтому уникальны и в продаже не бывают. Компания и заказчик не названы (канон), в игре — «Контора».

| Модель | Что это | В игре |
|---|---|---|
| Лис-0 «Часовой» | прототип без ИИ-ядра: гидрокулак, крепкий и тупой | враг `lis-sentry` (есть) |
| Лис-1 | мех-экзокостюм с ИИ (Titanfall): щит 20, протокол «Лис» | броня `lis-1` (реликт, есть), босс `boss-lis-1-defective` (есть) |
| Лис-2 | система залпового огня, радиус 2, 3 залпа | оружие `lis-2` (реликт, есть), враг `lis-2-battery` (есть) |
| Лис-3 «Лисёнок» | охранный дрон: спаренный карабин | враг `lis-drone` (есть), оружие `lis-3-twin` (новое) |
| Лис-4 «Нюх» | разведчик-дрон: подсвечивает цель | враг `lis-4-scout` (метка +2 урона), мод `lis-4-sniffer` (+1 атака, дальность +4) |
| Лис-5 «Нора» | автотурель, выезжает из пола | враг `lis-5-turret` (очередь 3) |
| Лис-6 «Хитрец» | ИИ-ядро для брони | мод брони `lis-6-core` (+1 КБ, сопр. электро; тяжёлая и мех) |
| Лис-7 «Чутьё» | винтовка с ИИ-наводкой | оружие `lis-7-chuyo` (+2 к атаке, мастеровое) |
| Лис-8 «Шкура» | накидка-хамелеон | броня `lis-8-hide` (лёгкая, КБ 3, +1 ВОС) |
| Лис-9 «Хвост» | командный носитель выводка дронов | босс `boss-lis-9-tail` |

**Где встретить.**
- **Бункер Лиса** (`bunker-lisa`, Нейтральные селения, люк под дачей Галины): Лис-0, Лис-3, Лис-4, Лис-5; в конце бракованный Лис-1. Бои `v3-lis-vault`, `v3-boss-lis-1` (кнопки боёв узла, один раз). Квестовый бой `enc-lis-drones` остался.
- **Ледяной бункер** (`dungeons-m15` = `vazgen-lab`, Дикие земли): Лис-9 «Хвост» с выводком (`v3-boss-lis-9`, ур. 5). Связка с канон-NPC: ИИ «Лис» в бункере оставлен Вазгеном, значит у Вазгена был доступ к проекту.
- Лут: таблица `lis-vault` (выпадает с босса Лис-9 и, при желании сценариста, из ящиков бункера).

**Для сценариста (крючки).** Кто такая «Контора» и кто заказчик; почему Лис-1 бракованный (ИИ научился врать); Галина знает больше, чем говорит.

## Проект «Волк»
**Предложение (вариант А, принят в данных).** «Волк» — **проект Военпрома** (вассал АИ Партии), армейский ответ на «Лисов»: инженеры Кремля получили часть чертежей Лиса (куплены, украдены или найдены в каком-то бункере) и **упростили** их до серии. Название обыгрывает «лис — хитрый одиночка / волк — стая».

| | «Лис» | «Волк» |
|---|---|---|
| Владелец | неназванная компания | Военпром (Кремль) |
| Тираж | штучный, уникальные реликты | серия, можно купить у военпромовского торговца (ступень 5) |
| ИИ | у каждой машины свой характер | **стайная сеть**: умны только вместе, ведёт связист и Вожак |
| Слабость | бракованный ИИ, электро, ЭМ | убей связиста «Вой» или Вожака: стая теряет координацию |

| Модель | Что это | В игре |
|---|---|---|
| Волк-0 «Вожак» | главный ИИ стаи в мехе-звере | босс `boss-wolf-0-alpha` (при гибели: дизбаланс стае на 3 хода) |
| Волк-1 «Серый» | четвероногий бегун | враг `wolf-1-grey` (прыжок, падение) |
| Волк-2 «Загонщик» | лёгкий бегун с сетью | враг `wolf-2-driver` (обездвиживание) |
| Волк-3 «Клык» | киборг-штурмовик | враг `wolf-3-fang`, оружие `wolf-fang` |
| Волк-4 «Вой» | связист: баффы стае, глушилка | враг `wolf-4-howler`, мод `wolf-link` (+1 атака) |
| Волк-5 «Матёрый» | серийный штурмовой мех | враг `wolf-5-matyorny`, броня `wolf-5-frame` (КБ 7, щит 10, без ИИ) |

**Где встретить.** Коридоры под Кремлём (`dungeons-m12`, Военпром, опасность 5): бои `v3-wolf-pack`, `v3-wolf-hunt`, `v3-boss-wolf-0`. Лут: таблица `wolf-pack`. Wolf-5 и «Клык» можно купить у военпромовских торговцев (поле `factions`).

**Альтернативы (на выбор автора).** Б: «Волк» — ветка той же компании («Лис» для одиночек, «Волк» для армии). В: «Волк» — проект Отступников, сделанный из трофейных Лисов, как «свобода для всех». Править придётся только лор и поле `faction` врагов.

## Что нужно движку (`needs`)
- Стайная связь по-настоящему (смерть связиста снимает баффы всей стае): сейчас «Вожак» это делает только через способность при смерти.
- Продажа предметов проекта «Лис» не предусмотрена (`factions: []`, нет в лавках); ограничение «только по квесту» — в логике лута.
- Сюжетные диалоги по Лису и Волку для NPC (Галина, Тряпкин, Вазген) пишет сценарист.
