# Производительность (perf pass 2026-11-25)

Инструмент: `node tools/out/perf.mjs [--hq] [--q low|medium|high] [--only …]` (headless Chromium + SwiftShader).
SwiftShader медленный в абсолюте, поэтому ниже сравниваются только **относительные** цифры. Время кадра по стене
(интервалы rAF) на SwiftShader шумит в 2–10 раз (ленивые компиляции конвейера), поэтому основная метрика —
**p50 времени отрисованного 3D-кадра** (колбэк кадра + чтение 1 px = CPU + GPU), `?hq=1` (полная цепочка поста, как на железе),
рендер 960×540.

## Что сделано
- Все уровни: персонажи (GLB и процедурные) вне фрустума не рисуются и не анимируются (их сетки и двойники контура/рентгена
  были `frustumCulled = false`); мелкие части GLB (лицо, отделка, `GFX.three.shadowMinR`) не отбрасывают тень.
- Настройка «Качество» (`gfx/quality.js`, `GFX.quality`): авто / низкое / среднее / высокое. «Высокое» = прежний вид.
  «Среднее»: DPR ≤ 1.25, MSAA 2, GTAO в половинном разрешении без персонажей в g-буфере, контуры и пружины только
  ближе 16 м к фокусу камеры, без рентгена массовки. «Низкое»: DPR 1, без MSAA/GTAO/bloom, тени ×0.5, контуры ближе 9 м,
  старый рендер — без поста.
- Авто: на железе начинает с «высокого», при 80-м перцентиле интервалов кадров > 25 мс (40 fps) за 3 с опускается на
  уровень и запоминает его (`autoQ`); выбор «авто» в настройках сбрасывает. Под автоматизацией не адаптируется
  (`?quality=` для тестов).

## Не сделано / дальше
- GTAO на «высоком» — половина стоимости кадра; не трогали, чтобы не менять вид. Кандидат: половинное разрешение и на «высоком» после проверки арт-директором.
- Редактор персонажа: 3D-портрет рисуется в WebGL и копируется в 2D с чтением из GPU (~65 мс на SwiftShader).
- Персонаж = 12–14 подсеток × (тело + контур + рентген); слияние подсеток сократило бы вызовы в 3 раза (нужна работа в Blender-конвейере).

Видимые меши в хабе 490 → 314, в бою пролога 255 → 169.

## Что сделано
- **GTAO**: «высокое» — буферы AO в половинном разрешении (`GFX.quality.high.gtao: 0.5`), «среднее» — в четвертном (0.25).
  Сравнение полное / ½ / ¼ на одном кадре: `tools/out/perf2-gtao-{prologue,roam}.png` (средняя разница пикселей ½ против полного — 0.4–1 из 255,
  углы стен и ящиков сохраняются; без AO — заметно светлее углы).
- **Контур и рентген персонажа — один меш вместо 12–14** (`three/models.js twinGeometry`, `three/character.js`): все skinned-подсетки
  с общим родителем/привязкой сливаются в одну геометрию двойника (позиция, нормаль, скин по объединённому списку костей, морфы по имени —
  лицо и фигура работают, веса синхронизируются через `C.morph`). Тела не сливаются: у каждой подсетки свой материал и своя текстура
  (тонировка по имени материала) — без атласа в Blender это не сделать. Рентген остаётся у всех юнитов (GreaterDepth рисует только
  закрытые пиксели), но стоит теперь 1 вызов на юнит.
- **Портрет редактора**: дыхание — 2D-масштаб кэшированного кадра; новый GL-кадр с чтением из GPU — только при смене облика, поворота
  (покачивание), моргания или эмоции, затем всё из кэша.
- **Контур команды у врагов** (андроид): на тонких пластинах задние грани контура пробивали тело — модель заливалась красным.
  Контур теперь сдвигается от камеры по глубине на 3× толщину (`HERO_MODELS.outlinePush`, `HULL_PUSH_VS`) — остаётся тонкий обод
  по силуэту, у всех GLB-юнитов и их оружия.
- **three-enemies FAIL**: не баг клипов, но и не только стенд — на SwiftShader кадр (~1 с) длиннее окна действия (0.5–0.62 с), и
  `party.js` пропускал атаку целиком. Теперь пропущенное между кадрами действие/попадание проигрывается с опозданием; стенд ждёт клип до 2.4 с.

# Проход 3: слияние тел персонажей (2026-11-25)

Те же условия (`perf.mjs --hq`, 960×540, SwiftShader, «высокое»; p50 отрисованного 3D-кадра, мс; в скобках — вызовы отрисовки).

| сцена | до | после |
|---|---|---|
| бой пролога | 763 (444) | 634 (210) |
| хаб (свободная карта) | 1209 (768) | 1111 (268) |
| бой забега (4 героя) | 680 (342) | 644 (208) |

Видимые меши: хаб 314 → 79, пролог 169 → 60. Время на SwiftShader упирается в заливку (GTAO, тени), поэтому выигрыш по мс
меньше, чем по вызовам; на железе вызовы — основная цена персонажа. Треугольники хаба +3 % (мелкие детали теперь в общем меше и отбрасывают тень).

Стенд `tools/out/three-merge.mjs` (тот же кадр с `HERO_MODELS.mergeBodies` выкл/вкл, без прохода теней):

| группа | вызовы выкл → вкл | пикселей с разницей > 24 |
|---|---|---|
| герои (7) | 84 → 22 | 0.008 % |
| NPC (7, с оттенками толпы) | 134 → 22 | 0.017 % |
| скелет / синт / андроид (6) | 60 → 13 | 0.004 % |
| враги (7, вкл. волка / дрон / шагоход / лиса) | 80 → 18 | 0.024 % |

С камерой ×3 дальше (мипы атласа) — до 0.06 %. Картинки «выкл / вкл»: `tools/out/three-merge-{heroes,npcs,mech,enemies}.png`.

## Решение: слияние в рантайме, без переэкспорта
- Выбран рантайм: работает для всех семейств (тела, волосы, одежда, NPC, механические тела, враги на своих скелетах) без
  Blender и без смены GLB; оттенки внешности (кожа, волосы, одежда, глаза/пластины мехов, толпа) задаются при сборке, как раньше.
- `three/character.js mergeBodies`: skinned-подсетки с одинаковой **мировой** матрицей и привязкой (glTF-меши с несколькими
  примитивами лежат в соседних группах — ключ по родителю их разделял) → один `SkinnedMesh` `Body+` с материалами [Body, Face]:
  2 вызова тела + 1 контур + 1 рентген на персонажа (было 12–25 + 2–8).
- Геометрия `models.js bodyGeometry`: позиция/нормаль/скин/морфы по имени + `uv` + атрибут `slot`; лицо — вторая группа отрисовки
  (своя текстура-атлас эмоций, своя смена карты). Морфы лица и фигуры работают через `C.morph`, пружины — через общие кости.
- Текстуры — `models.js atlasOf`: атлас на канвасе (сетка ячеек, поле-обёртка 1/16 размера). UV в GLB повторяются (до ±15),
  поэтому в шейдере `fract` внутри ячейки + `textureGrad` по непрерывным UV (без шва мипов на стыке повтора).
- Материал Body — тун с массивами униформ по слотам (цвет с оттенком, эмиссия — свечение роботов, прямоугольник атласа,
  режим: без карты / карта × цвет / яркость × усиление как `lumTint`). Собственные `color`/`emissive`/`opacity` материала —
  общие ручки поверх слотов (подсветка Ладова, вспышка попадания, прозрачность, ночной патч) — код `party.js` не менялся.
  `material.userData.slots` — живые цвета слотов (менять без перекомпиляции).
- Попутно: `mergeGeometries` терял имена морфов — у слитых двойников контура/рентгена (проход 2) морфы фигуры не применялись
  (контур не следовал за «Сложением»). Имена восстанавливаются.
- Выключатель — `HERO_MODELS.mergeBodies` (данные).

## Не сделано
- Атласы — по набору текстур (кэш LRU 48): ~1–2.5 МБ GPU на уникальную комбинацию одежды и причёски.
- Оружие — отдельные меши (2–3 вызова), не трогали.
