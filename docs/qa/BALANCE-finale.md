# Баланс поздней игры и финала (ур. 16–20)

Инструмент: `node tools/sim/finale.mjs [--n 12] [--size 3|4] [--prep 0|1] [--only a,b] [--chain 1] [--rest 0.35]`.
Методика: герой класса X (случайный путь/раса) + спутники случайных других классов, ур. 17 (волны), 18, 19, 20 (финал); лучшее снаряжение тир ≤4 по `gearScore` из `best-gear.js` (оружие, затем броня), 2 аптечки; ИИ ведёт всех. n=12 на класс (11 классов, ~130 боёв на строку), общая карта-арена.
НЕ моделируется: terrain волн (огонь/пролом/ночь), цели боя (terminal/hold), триггеры (залп барж, воскрешение), баффы флагов, расходники, диалог Жреца. Цифры — ориентир, не точное предсказание.
`prep 1` — союзники из `EVE_MODS` (2 стрелка Военпрома, турель, 3 из Предложки на волне 2). Цепочка — 3 волны подряд, между волнами выжившие +35% ЗДР, упавшие встают с 25%.
Отступ: «lockOpen» — доля боёв, где босс/мини-босс опустился ниже 66% ЗДР (фаза 2, `COMBAT.retreat.bossPhase`) и выходы открылись.

## Проблемы
1. Жрец «в силе» и Собиратель — босс-цели 55–70% не достигнуты: 92–97% и 77%. Боссы падают за 6–8 раундов.
2. Волны без флагов (цель спеки 55–65%) шли на 86% цепочкой; с флагами-союзниками — 100% (союзники слишком сильны: цель 70–85%).
3. c8-ветка «оборванное имя» (−10% ЗДР) ничего не меняет в исходе (77% = 77%); «назвал» — почти автопобеда (100%), это намеренная награда.
4. Судья: при партии 3 — 31–35% (ranger 8%), при партии 4 — 69–76%. Терминалы дают +20 п.п. — механика работает.
5. Ranger — последний или почти в каждом бою (цепочка 42–58%); `wp-cmd` (Кузнечик) имеет резист pierce/slash, бьёт по стрелку.
6. Андроиды/шагоходы Военпрома L16 (patrol/host) — 99–100%, мёртвая угроза; элита с шагоходом 93%.

## Ловушка отхода на волне 2?
Нет. Командир `wp-cmd` (`miniboss`) закрывает выходы, пока ЗДР < 66% (фаза 2): открылось в 99% боёв (партия 4 и 3), в среднем к 3–4 раунду; поражение до фазы 2 — 1% (партия 4), 13% (партия 3 на Судье/Жрце). Замечание: выходы закрыты и без флага `retreat` кнопки всё равно нет; ловушкой замок станет только если у командира не будет фазы (`boss`-архетип по маске `*-cmd-l*` есть). Рекомендация — оставить как есть.

## Предложения (не применены; решение за game-designer)
- `EVE_MODS`: союзники слишком сильны (цепочка 99–100%). Предлагаю: `harmony-ai` 2 → 1 стрелок, Предложка на волне 2: 3 → 2, либо союзники -2 уровня (`*-vet-l14`).
- Жрец: дальнейший рост hpK даёт лишь затяжку (hpK 3.4 → 18–20 раундов, win 62–74%); для 55–70% нужны механики, а не ЗДР: усилить `cp-verdict` (DC), скрилеты 2→3 призыва.
- Собиратель: оставить hpK 1.5; при желании «оборванное имя» −10% → −20% ЗДР, чтобы ветка ощущалась.
- Судья: при партии 3 добавить в `finaleMods` союзника по умолчанию (минимум партии = 3 с союзниками) либо `reduce` сильнее; hard-режим 69% в целях.
- Ranger: проверить урон по резистам pierce/slash (Кузнечик, wp-cmd): путь Снайпера с `armor-piercing`/energy-оружием; нет правки чисел класса в этой задаче.
- Волна 1: +1 аколит (партия 4) — по желанию, сейчас 95%; терраин (огонь) может уже добавлять сложность — проверить в плейтесте.
- Wp-patrol/host L16: +1 враг или POWER_V3 ×1.15 (файл вне рамок задачи).

### Приёмка
1. Цепочка: союзники 82% (70–85 ✓), без флагов 67% (60–70 ✓). Все флаги — 89% (выше коридора: награда за полную подготовку).
2. Жрец 54–61% (Сокральня на нижней границе, среднее 56%); Собиратель 61–65% ✓; torn на 3–7 п.п. легче обычного. **Раунды Жреца 13–14 на победах (цель ≤ 12) — не достигнуто**: hpK 1.8 + хор; ручки — `choirReduce` 0.2 → 0.1, хор 2 → 1 в Сокральне.
3. Партия 3: всё ≥ 45% ✓ (Судья 0 терм. 64%, hard 61%). Замечание: с союзником smallParty волны и Собиратель легче, чем партией 4 (99% / 83%) — ручка `bossHpPct` 0.9 → 1 или союзник l14.
4. Классы в цепочке ≥ 50%, разброс среднее–худший 17 п.п. ✓; ranger 68% ✓. В боях с боссами reper остаётся худшим (30–40%).
