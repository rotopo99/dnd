# Баланс классов v4 (ур. 10/15/20)

Инструмент: `node tools/sim/classes-v4.mjs [--size 1|4] [--n 30] [--levels 10,15,20] [--only cls] [--seed N]`.
Методика: класс x все 3 пути, стартовый кит, без талантов; бои v4 `*-patrol/*-host` уровня L-2..L (соло — доля врагов size/4). Партия «из 4» — 4 героя одного класса (случайные пути). n=30 на путь и бой. Это стресс-тест класса, а не реальная партия; на ур. 20 набор боёв другой (мало боёв v4 ур. 18–20), сравнивать уровни между собой нельзя — только классы внутри уровня.

## Остаточные проблемы (для game-designer)
1. Cybertech ур. 10: партия 54%, соло 28%. Увеличение бонусов пассивки (+5 урон, +20 ЭНР) на результат не влияло — причина не в числах ресурса; вероятно путь Проклятий / ИИ боя. Нужна диагностика по путям.
2. Slavotech соло 20% на 10–15 (роль саппорта, допустимо); партия 78–93 нормально.
3. Itishnik соло ур. 20: 25%, при этом партия 97–100 — доминирует в группе, одиночка слаб; допустимо. Zabivnoy/ranger/technomant стабильно сверху (соло 60–78 на 15) — кандидаты на лёгкий нерф при следующем проходе.
4. Arbiter ур. 15 партия 69%, бои 12+ раундов — мало урона на 11–15; следить.
5. Мутант после правок не доминирует (соло 49/73/63): при желании снизить Буйство до 3 ударов без +1d8.
6. Рекомендация: в class-файлах Itishnik, Ranger, Technomant, Arbiter мало способностей 6+ (6–8 шт. против 25 у cybertech/ecolog/reper/slavotech/ugolovnik) — неравномерность контента, а не только чисел.
