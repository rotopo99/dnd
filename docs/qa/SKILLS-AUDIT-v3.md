# Аудит применения навыков v3

> Дата: 2026-11-08. Скрипт: `node tools/audit-skills.mjs` (таблица), `node tools/check-skill-data.mjs` (id навыков, узлов, предметов, фракций, статусов).
> Источник списка навыков: `data/talents.js` SKILLS (20 канон-навыков, `docs/canon/rules/stats-skills.md`). Новых навыков нет.

## Метод
Обход данных (import) + список «зашитых в код» правил. Категории:
- **quests** — квесты (`quests*.js`, `density-quests`, `quests-npc`): поля `skill`/`skills` в целях и опциях. Считаются только проверки, где навыков **≤ 3** (в списке из 4+ игрок не видит, чей навык сработал; такие записи — в колонке «размыто»).
- **events** — ивенты (`events.js`, `density-events`); **travel** — дорожные проверки регионов (`travel-skills.js`); **caches** — тайники, скрытые пути и ворота узлов (`locations.js`, `density-caches`); **systems** — правила (`skill-rules`, `skill-uses2` не-боевые, `crime`, `rest`, `base`, вербовка) + зашитое в коде (торг, разбор, привал, кража, засада…).
- **nodeActions** — новое: `data/world/node-skill-actions.js`. **battle** — приёмы «Навык» (N6, `TRICKS2`, `BATTLE_SKILL_TRICKS`). **сцены** — подходы check-scenes (в «мир» не входят: это варианты тех же квестовых проверок).
- Норма: мир (quests+events+travel+caches+systems+nodeActions) ≥ 5 **и** бой ≥ 1.

## Что показал аудит (до правок)
Мир ≥ 5 было у всех, но: **0 боевых приёмов** у 7 навыков (Убеждение, Обман, Запугивание, Прокси-магия, Выживание, Наблюдательность, Религия); у Запугивания, Устойчивости и Медицины мало видимых применений вне квестов (тайники 0–1, ивенты 0, системы 2–6), у 9 навыков 0 ивентов-проверок. Остальное — однократные квесты и «размытые» дорожные проверки. То есть игрок «не видит» навык вне квеста: нет кнопки «здесь пригодится».

## Что добавлено
- `node-skill-actions.js`: **100 действий** (по 5 на навык: 2–3 общих по типу узла `town/camp/wild/dungeon/terminal/sea` + 1–2 в конкретных узлах), у каждого навыка есть «повторяемое» (`once: 'day'`) и «разовое» с наградой (предметы, кредиты, репутация, опыт) и ценой провала (ЗДР/МРЛ/кредиты/репутация/день).
- `BATTLE_SKILL_TRICKS`: 7 боевых приёмов для навыков без приёма → у всех 20 навыков есть бой.
- `skill-hints.js`: значки «здесь пригодится X» для 19 узлов и 30 NPC.
- Не сделано сознательно: размытые (4+ навыков) квестовые проверки не переписывались — в «размыто» осталось 5–12 записей на навык; ивентов-проверок новых нет (перекрыто действиями узлов). Кандидат следующего прохода: 1–2 события с проверкой на навык в density-events.
