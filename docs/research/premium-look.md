# Почему похожие игры выглядят «дорого» — и что сделать у нас (разведка, 2026-11-17)

Референсы: Divinity: OS2, BG3, Forsworn, Zenless Zone Zero, Rogue Trader, Wasteland 3, Pathfinder WotR, ATOM RPG, Disco Elysium, Hades.

## Уже есть
Тун-ступени с мягким краем, тень в оттенке, rim, inverted-hull контур, shadow map PCF 3×3, туман по биому, ночь со светом, частицы fx3d, блик на волосах, «Снизить эффекты».
## Нет
Постобработки (bloom, виньетка, tonemap, LUT), SSAO, DOF, hit-stop, тряски, контактных теней, SDF-тени лица.

## Топ-10 по эффект/стоимость
1. Хит-стоп 2–4 кадра + тряска камеры (крит, смерть, сильный удар) — только визуально, уважать «Снизить движение». Тряска 0.1–0.25 с, 2–4 px (2D), 0.05–0.1 (3D).
2. Всплывающие числа урона с «pop»: scale 1.4→1, ease-out-back ~120 мс, дрейф вверх ~40 px за 0.8 с, цвет по типу урона, крит крупнее с обводкой.
3. Контактные тени под юнитами и объектами (почти бесплатно).
4. Виньетка + лёгкое зерно (α 0.15–0.25), выключается «Снизить эффекты».
5. Шрифт заголовков: Russo One или Tektur (кириллица, OFL; проверить «Чч» у Tektur).
6. Easing UI: easeOutCubic 180–220 мс, hover 80 мс, открытие окна scale 0.96→1 + fade.
7. Bloom только на эмиссиве (циан, неон, огонь): 3 мипа, порог ~0.8, аддитивно ~0.3.
8. Мягкий tonemap (shoulder) вместо ACES/AgX (те гасят циан/мадженту).
9. Камера-акцент крупных способностей: зум 1.08 за 0.4 с + замедление 0.2 с.
10. Вариативность тайлов и мусор: 2 варианта тайла, 2–4 инстанс-детали на клетку (трещины, лужи, мусор).

## Прочее
- Освещение: fill-свет с противоположной стороны ~0.3 от key; rim ~0.5.
- Туман по высоте (y).
- Кромка тайла: светлая линия 1 px по верхней грани.
- Точечный свет от факелов/неона.
- Персонажи: SDF-тень лица (нужна маска), stylized normals; Kajiya-Kay для волос.
- UI: заголовки 16/24/32 px, тултипы без анимации > 150 мс, блик на карточках.

## Риски
Палитра 26 цветов (STYLE) — LUT/bloom/tonemap меняют восприятие; LUT по биому ломает «биом по цвету пола». Шрифт — решение по стилю. Хит-стоп не трогает логику. Без SSAO на слабом железе.

## Источники (частично заблокированы в сессии: 80.lv, learnopengl, gdcvault)
Jonasson & Purho «Juice It or Lose It» (GDC EU 2012); Nat Rowley «How Hades Creates A Responsive Underworld» (GDC); пост ACES Central о DOS2 (ACES 1.2 SDR SSTS); Unity Toon Shader docs (Angel Ring, MatCap); Khronos PBR Neutral; Google Fonts (Russo One, Tektur, Ruslan Display).

## Решения режиссёра (2026-11-17)
- Пост-эффекты разрешены: bloom только эмиссив, виньетка/зерно, мягкий tonemap с сохранением бренд-цветов; всё отключается «Снизить эффекты». LUT по биому — нет (ломает читаемость биома); вместо него лёгкий цветовой баланс по биому ≤ 5 %.
- Заголовки — Russo One (Google Fonts, OFL), основной текст остаётся моноширинным; фолбэк — системный шрифт.
- Хит-стоп/тряска — визуально, выключаются «Снизить движение».
