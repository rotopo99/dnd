# Спека: 3D поля боя и свободной карты узла

Решение человека: «3D-графика примерно как в Forsworn минимум, и глаза не режет».
Ориентир — изометрическая тактика, тёмное фэнтези (Forsworn); у нас русский постапокалипсис + ARC Raiders (`docs/STYLE.md`).
Ограничение проекта: без сборки и зависимостей, значит свой маленький WebGL2-рендер, без Three.js.
Статус: черновик арт-директора. Код не затронут.

## 1. Архитектура

Модуль `game/src/gfx/` (ES-модули, без DOM-логики игры):
- `gl.js` — контекст WebGL2, компиляция шейдеров, uniform-буфер, `hasWebGL2()`, потеря контекста.
- `mesh.js` — буферы вершин (pos, normal, color-индекс палитры, ao), статические батчи по чанкам 8x8, инстансинг.
- `camera.js` — изометрия (ортографика): поворот шагами 90° с плавным твином 0.25 с, зум 3 уровня (как roam 24/32/40), наклон 30–45° (по умолчанию 35.26° + 45°), `project(x,y,h)` → экран для 2D-слоя, `pick(px,py)` → клетка.
- `scene3d.js` — сборка сцены из `grid.js` (тайлы, `elev`, `T_FULL/T_HALF/T_BLOCK`), `def.props`, `b.objects`; пересборка чанка при `breakObject`.
- `models/` — `props3d.js`, `units3d.js`, `anim.js`.

Слои: нижний canvas — WebGL (мир), верхний — Canvas 2D (весь текущий UI, подсказки, полосы, иконки) с прозрачным фоном. Ввод слушает верхний; координаты клетки — через `camera.pick`.
Интеграция: `battle-view.js` и `roam.js` получают интерфейс `renderer.draw(S)`; два бэкенда: `view2d` (текущий, `field-view.js` + `battle-terrain.js`) и `view3d`. Данные боя не знают о бэкенде.
Запасной режим: нет WebGL2, ошибка шейдера или `webglcontextlost` без восстановления за 2 с → 2D, тост «3D недоступно». Настройка «Графика: 3D / 2D» в настройках, хранится в `localStorage`; по умолчанию 3D при наличии WebGL2.

## 2. Геометрия

Единица: клетка = 1 м, высота уровня `elev` = 0.5 м.
- Пол: плитка-вокс с высотой `elev`, боковые грани с цветом «тень» рампы, верх — «база», 4 варианта вершинного шума ±0.03 м (детерминированно по seed биома). Вода — плоскость ниже на 0.15 м, тихая анимация цвета (без мерцания, см. §7). Обломки — 3–5 низких призм.
- Стены `#`/`T_BLOCK`: объём 1.6 м со скосом верха; `T_FULL` (полное укрытие): 1.1 м; `T_HALF`: 0.55 м. Читаемость укрытия — высотой, плюс иконка в 2D.
- Биомы (9, `tilesets.js`): каждому — рампа из 3 ключей палитры [тень, база, свет], набор декоративных меш-элементов (трава-клинья, рельсы, трубы).
- Реквизит (`props.js`, 41 предмет, метаданные `{w,h,rise,cover,blocks,height}`): процедурные меши из боксов/цилиндров/клиньев с `rise` как высотой; footprint строго `w×h` клеток. Первая волна: машина, бочка (+токсичная), вагон, контейнер, ящик, генератор, стеллаж, бетонный блок; остальное — бокс нужной высоты цветом реквизита (заглушка) до этапа 4.
- Персонажи: низкополи-фигура ≤ 300 граней — голова из `avatar3d.js` (`buildAvatarMesh`, ≤600 граней, делится на кэш), туловище/руки/ноги/ранец по классу (ключи палитры по `hero.look`/cloth), раса — пропорции и уши/рога. Скелет — 10 костей (таз, торс, голова, 2×рука из 2, 2×нога из 2); анимации процедурные: idle (дыхание), walk, attack (мили/дальняя), hit, death, cast. Враги — по типу: шаблон «гуманоид / зверь / машина / мех / босс» + параметры.
- Юниты и объекты рисуются инстансингом; одинаковые шаблоны — один draw call.

## 3. Свет и материалы

- Шейдинг: ламберт 3 ступени (как в `avatar3d`: тень/база/свет) — цвет берётся из рампы палитры, а не умножением, чтобы оставаться в палитре STYLE. Светящиеся части (визоры, фонари, огонь) не затеняются.
- Тени: shadow map 1 источника (направленный, сверху-слева, как в STYLE), 1024 (низкое: 512; выкл. = запечённый AO). Мягкость PCF 3x3. Запечённый AO по клеткам (вершинный, пересчёт чанка при разрушении) — всегда включён, дёшев.
- Туман по биому и погоде (`WEATHER`): линейный, цвет из палитры, плотность из `vis`; ночь/сумерки — тонировка + точечные источники `lightSources(b)` с радиусом, статичные, без мерцания.
- Запрещено: bloom, motion blur, хроматическая аберрация, film grain, постоянный шейк, острые вспышки.
- Настройки: яркость (0.8–1.2), контраст (0.8–1.2), «Снизить эффекты» (нет теней, нет тумана-частиц, нет анимации воды/дождя, упрощённые модели), качество теней (выкл/низкое/высокое), «Снизить движение» (камера без твина).
- Все цвета — из палитры; новые — только через STYLE.md с обоснованием.

## 4. Читаемость тактики

- Клетки пути/зоны хода/радиуса/AoE/укрытий: плоские полупрозрачные квады на высоте пола (+0.01 м) в 3D, цвета те же, что в 2D; шов 2 px для различимости без цвета (штриховка у укрытий).
- Контуры юнитов: inverted-hull или экранный контур 2 px, цвет команды (`rival`/герои/враги) — совпадает с текущими кольцами; активный юнит — ореол на земле + стрелка.
- Скрытые за стеной юниты: силуэт-«рентген» 30% (по настройке) — иначе юнит за высоким укрытием теряется.
- Иконки статусов, полосы ЗДР, названия действий, подсказки, шансы — в 2D-слое поверх `camera.project(x,y,h)` (якорь над головой), с запретом перекрытий (смещение по Y).
- Прозрачность: стены между камерой и активным юнитом — срез/полупрозрачность (fade 0.2 с); при повороте камеры — выбор ближайшего обзора.
- Высоты: подпись «h1/h2» и иконка, как сейчас; прицел линии огня/LOS — дуга над клетками.

## 5. Производительность

Цель 60 fps (бюджет кадра 16 мс) на встроенной графике: бой 24×13 (312 клеток), roam 40×30 (1200 клеток).
- Статичный мир — чанки 8×8, один буфер на чанк, frustum-culling; пересборка только изменённого чанка.
- Юниты и реквизит — инстансинг; ≤ 150 draw calls на кадр.
- Тени: статичный пас кэшируется до изменения мира; динамические — только юниты.
- Рендер по требованию: если нет анимаций и камера стоит — перерисовка с 15 fps (экономия батареи).
- Автоподстройка: средний кадр > 20 мс 2 с подряд → снижает качество (тени → выкл., затем «снизить эффекты»), с тостом; DPR ≤ 1.5.
- Память: меши юнитов кэшируются по ключу `look+class`; `avatar3d` — один раз.

## 6. Этапы

1. Каркас: `gl/mesh/camera`, клетки, высоты, стены, укрытия, реквизит (первая волна), юниты-болванки (капсулы цвета команды), 2D-слой поверх, подсветки, переключатель 2D/3D, фолбэк, плейтест-скрипт `tools/out/3d-battle.mjs`.
2. Персонажи с анимациями (idle/walk/attack/hit/death/cast), враги по типам, эффекты способностей и поверхностей (огонь, ток, газ — в 3D как плоские/объёмные меши), разрушаемые объекты.
3. Свободная карта узла (roam 40×30) в 3D: камера за лидером, NPC, объекты узла, погода (дождь/метель/туман/ночь), день/ночь.
4. Полировка: все 41 реквизит, ассеты биомов, настройки, автоподстройка, доступность, QA на слабом железе.

Каждый этап оставляет игру запускаемой (фолбэк на 2D).

## 7. Критерии приёмки «глаза не режет»

- Контраст: яркость фона мира в диапазоне, не белее светов STYLE; максимальная яркость пиксела ≤ 90% (нет чистого белого вне UI-текста); текст UI поверх 3D — плашка, контраст ≥ 4.5:1 (WCAG AA).
- Нет мерцания: никакие эффекты не мигают чаще 2 Гц (рекомендация WCAG ≤ 3 Гц), нет полноэкранных вспышек, площадь мигающей области < 10% экрана; вспышки урона — плавный пик ≥ 150 мс.
- Нет шума/зерна, нет муара на текстурах (MSAA ×4 или FXAA, мип-карты не нужны — цвет плоский); нет z-fighting, нет «плавания» теней (привязка карты теней к сетке).
- Камера: поворот ≤ 0.3 с с ease, без тряски по умолчанию; «Снизить движение» отключает твины и качание.
- Гамма и палитра: после шейдинга цвета остаются в пределах ±10% от рампы STYLE; проверка скриншотом + гистограммой в плейтесте.
- Скриншот-регрессия 3 сцен (бой, roam, ночной бой) на каждом этапе; консоль без ошибок.
- Ручной просмотр 15 минут без жалоб на усталость глаз (оценка человека).

## Риски

- Объём: 41 реквизит × меши + 9 биомов + враги — главный риск; смягчение: бокс-заглушки и шаблоны.
- Стилистика: низкополи-3D рядом с пиксель-арт 2D-UI; смягчение: плоский цвет, контур, дизеринг не нужен; портреты остаются 2D.
- Читаемость клеток под наклоном: смягчение: поворот 90°, срез стен, силуэт сквозь стены.
- Старые/слабые GPU и баги драйверов: фолбэк, автоподстройка.
- Тесты: Playwright headless использует SwiftShader — медленно; нужен режим `?gfx=2d` для старых тестов и `?gfx=3d` для новых.
- Сетевой кооп: рендер не должен влиять на состояние боя (детерминизм); только `view`.
- Размер репозитория: меши только процедурные, внешних файлов нет.

## Решения режиссёра (2026-11-15)
- «Снизить движение» — отдельная настройка: да.
- Существующие 2D-тесты и сценарии гоняются с `?gfx=2d` (дефолт в headless — 2D, если нет WebGL2); добавить отдельный сценарий для 3D.
