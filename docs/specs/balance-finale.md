# Баланс финала, раунд 2 (спека)
Дата 2026-11-24. Основание: docs/qa/BALANCE-finale.md. Инструмент приёмки: `node tools/sim/finale.mjs`.
Принцип: сложность — из механик, не из ЗДР (hpK Жреца 1.8 и Собирателя 1.5 не трогаем). Союзники — разовые эффекты.

## Цель для игрока
Ночь у вала ощущается тяжёлой даже с друзьями; друзья — «разовый сюрприз», а не вторая армия. Боссы переключают тактику по фазам. Партия из 3 не наказана за размер.

## 1. Союзники EVE_MODS: потолок и разовые эффекты
Правило-потолок (`WAVE4_RULES.allyCap`, новое): на волну не более `units: 1` союзного юнита и `volleys: 2` залпов; лишние флаги дают только тост без эффекта (порядок приоритета — как в таблице снизу вверх по строкам EVE_MODS). Суммарный разовый урон волны ≤ 6d8.

| harmony-ai | 2x wp-vet-l16 | `triggers: eve-ai-volley`, when round 1, `volley {dice:'3d8', radius:1, team:'enemies', dmgType:'pierce'}`, текст «Стрелки Военпрома: один залп» |
| harmony-ren | hpPct 0.75 (волна 1) | `renHpPct: 0.85` |

Добавить `w-eve-1`: +1 `acolyte-5` (партия 4 → 5 врагов). Для волн 4 враг/без флагов ожидаем ~65%.

## 2. Фазы боссов (hp-триггеры, `when {event:'hp', unit:'boss', below}`)
Новые ops нужны программисту: `spawn {unit, count, team, near:'boss'}`, `surface {id, cells, band}`, `aura {id, reduce, whileAlive:'<spawnTag>'}`, `prop {id, hp, ac, onBreak}`. Фазы также срабатывают в `finale.mjs` (иначе сим слеп).

### Кибер-Жрец (`boss-cyber-priest-prime`, hpK 1.8 без изменений)
| Фаза | Порог | Эффект |
|---|---|---|
| 1 | 100% | как сейчас. `cp-skrilet usesPerBattle` 2 → 3 |
| 2 «Хор вступает» | <=66% | spawn 2x `V('cult','vet',L)` метка `choir`; аура `choir-shield` — Жрец получает −30% урона, пока жив хоть один хорист (слабое место: убей хор); `cp-verdict` DC +2 (save penalty -2 игроку), usesPerBattle 2 → 3 |
| 3 «Сеть» | <=33% | `surface` fire (кибер-огонь 1d6/раунд) на 8 клетках средней полосы; Жрец ставит `prop` «Узел копии» hp 30 ac 12 рядом; `cp-upload` кастуется автоматически (щит `shieldV(L,5)`, 3 хода). Пока узел цел: `cp-soul-theft` ratio 0.5 → 1.0 и щит не истекает. Узел разбит: щит снят, Жрец оглушён 1 ход |
Лор: хор — культ у ворот, Жрец «подключает» их к себе; Помеха/`fin-vessel` не затронуты (диалог вне боя).

### Великий Собиратель (`boss-great-collector`, hpK 1.5)
| Фаза | Порог | Эффект |
|---|---|---|
| 1 | 100% | `gc-collect usesPerBattle` 3 → 4 |

## 3. Партия из 3
`WAVE4_RULES.smallParty = { size: 3, ally: 'wp-vet-l16', count: 1, bossHpPct: 0.9, enc: ['w-eve-1','w-eve-2','w-eve-3','enc-cyber-priest-strong','v4-boss-cyber-priest','v4-boss-collector','w-cc-finale'] }`. Для size <=3 `encounterSetup` добавляет `count` союзников и `hpPct` для боссов; для size 2 — count 2. Союзник не входит в `allyCap` флагов (отдельный лимит) и без `Судья hard` переопределения: для hard (воплощение) bossHpPct 0.9 действует поверх +25%. Финал `w-cc-finale` уже имеет `minParty 3` через finaleMods — смальпати-союзник заменяет его только когда нет флагов.

## 4. Рейнджер против резистов
Файл `data/classes/ranger.js`:
| Что | Было | Стало |
|---|---|---|
| `field-tuning-15` | maxHp -40, dmg -3 | maxHp -20, dmg 0 |
| Новый пассив `armor-bane` ур.16, path null | — | `op: { resistPierce: 1 }` — дальняя атака оружием: резист цели → обычный урон (immune → resist). Запасной вариант без нового op: `dmg: { ranged: 3 }` и `critRange: 19` против целей с резистом |
Также `wp-cmd` резист pierce/slash: `resist 'resist'` остаётся (осознанное давление на класс).

## Состояния и события
Фаза — один раз (hp-триггер), лог «Хор вступает» и т.п.; убитый хорист/экспонат снимает ауру немедленно; узел/каталог — цели атак, враг-команда `enemies`.

## UI/фидбек
Тост при входе в фазу; иконка ауры на боссе; подсветка узла/каталога; кибер-огонь — анимация поверхности. Звук: хор (низкий пад) в фазе 2 Жреца; щёлк стекла при разбитии каталога.

## Критерии приёмки (finale.mjs, n>=20, seed 1/2/3)
1. `--prep 1 --chain 1 --size 4`: цепочка 1–3 с союзниками 70–85% (было 99–100%); без флагов (`--prep 0`) 60–70%.
2. Жрец (оба энкаунтера) win 55–70%, раундов <=12; Собиратель 55–70% (c8 torn не выше обычного минимум на 5 п.п. меньше).
3. `--size 3` (с smallParty): ни один бой/цепочка <45%; Судья 0 терминалов >=45%, hard >=45%.
4. Ни один класс <45% в цепочке (ranger >=45 при `--only`/`--cls ranger`); разброс худший–средний <=20 п.п.
5. `node tools/test.mjs` без регрессий; hp-триггеры фаз срабатывают в сим (`lockOpen` не падает).

## Вне рамок
Диалоговый выбор Жреца в бою; wp-patrol/host L16; пересборка путей других классов; hpK боссов; волна 2 Кузнечика (после замеров).
Ручки для balance-tester: aura Жреца 0.7→0.8, узел hp 30→20, bossHpPct 0.9→0.85, ally уровень.
