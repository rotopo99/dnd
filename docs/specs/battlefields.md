# Поля сражений: раскладки, биомы, погода (art-director, feedback 2026-11-07)

> Для программиста. Ассеты: `game/src/assets/tilesets.js` (`tileSprite(biome, kind, variant)`, 9 биомов × floor/wall/half/full/debris/water/decal), `game/src/assets/props.js` (`propSprite(id)`, 41 предмет с метаданными). Палитра и размеры — `docs/STYLE.md` («Поля сражений»). Лист: `node tools/out/tiles-sheet.mjs`.
> Карта боя — 22×12 клеток, тайл 16 px, рендер ×3 (как в `world/arena.js`).

## 1. Легенда ASCII-карт
| Символ | Смысл | Ассет |
|---|---|---|
| `.` | пол | `floor` (вариант по хешу клетки) |
| `#` | стена / непроходимо | `wall` |
| `c` | полуукрытие | `half` тайл (или реквизит с `cover:'half'`) |
| `C` | полное укрытие | `full` тайл или реквизит `cover:'full'` |
| `x` | обломки (проходимо, замедление — на усмотрение правил) | `debris` |
| `~` | вода/лужа/масло (поверхность `water`/`oil` по биому) | `water` |
| `h` / `H` | высота 1 / 2 | пол + кромка высоты (как сейчас) |
| `=` | настил моста, проходим, без укрытия | prop `bridge` (или пол) |
| `f` | забор-сетка (блок, стрелять можно) | prop `fence` |
| `v` | техника: по биому `lada`/`moskvich`/`bus`/`kamaz`/`container`/`wagon` | prop (многоклеточные занимают клетки вправо) |
| `b` | бочка (`barrel`, `barrel-toxic`) | prop, `destructible` |
| `T` | палатка | prop `tent` |
| `k` | костёр | prop `campfire` (поверхность `fire`) |
| `s` | сервер-стойка | prop `server` |
| `t` | вышка | prop `tower` |
| `D` | выход (цель «дойти до выхода») | `tile-door` |
| `P` / `A` / `E` | старт героя / союзников / врагов | пол |
| `B` | босс (только в ручных аренах) | пол |

Правило подбора реквизита: символ `v`/`b`/`C`/`c` — это слот; программист берёт из `PROP_IDS` предмет, у которого `biomes` содержит биом боя (или `'*'`) и подходящий `cover`. Многоклеточные (`w`×`h` > 1) ставить, только если клетки справа свободны, иначе выбрать 1×1. Шаблон можно зеркалить по горизонтали (меняя `P`↔`E`) и красить любым биомом; ручные арены — нет. Для боёв на карте мира выбор шаблона: по типу места (мост/переправа → Мост, город → Улица/Перекрёсток/Двор, завод → Цех, лагерь/засада → Лагерь, оборона/штурм → Баррикада), иначе по seed.

## 2. Семь шаблонов 22×12

### 2.1 Мост
```
~~~~~~~~~~~~~~~~~~~~~~
~~~~~~~~~~~~~~~~~~~~~~
~~~~~~~~~~~~~~~~~~~~~~
.ff================ff.
.PA=c====v=====C====E.
.P=====b====c=====bE=.
.P==x===C=====c===E=..
.PA=c===v====x==c==E=.
.ff================ff.
~~~~~~~~~~~~~~~~~~~~~~
~~~~~~~~~~~~~~~~~~~~~~
~~~~~~~~~~~~~~~~~~~~~~
```
Река/пролом; бой идёт по настилу `=` (проходимо, без укрытия), `ff` — перила-сетка по краям; падение в воду `~` = выбывание/урон (решает программист). Узкий фронт: укрытия `c`/`C`/`v` на настиле решают бой.

## 3. Биомы и регионы
Биом боя: `encounter.biome` > `location.biome` > регион (таблица) > хазард > `wasteland` (как сейчас `biomeOf` в `data/combat.js`). Старые 6 биомов `BIOMES` переносятся так: `wasteland`→`wasteland`, `village`→`ruins-city`, `agro`→`mutant-forest` (огонь/газ остаются), `cyber`→`cyberspace` (или `bunker-interior` в помещениях), `port`→`port`, `mutant`→`mutant-forest` (болотные места — `swamp`). Количества объектов (`crate`, `barrel`… в `BIOMES`) остаются как веса.

## 4. Погода и время суток
Состояние боя: `S.weather` (одно из) и `S.tod` (`day`|`dusk`|`night`). Рисуется оверлеем поверх террейна и юнитов, до UI. Цвета — из палитры.

| id | Оверлей (цвет, α) | Дальность видимости `vis` | Прочее |
|---|---|---|---|
| `day` | нет | без ограничений | по умолчанию |
| `dusk` | `1` α0.22 | без ограничений | тени длиннее — только вид |
| `night` | `0` α0.55; вокруг своих юнитов, костра, ламп, огня, неоновых и экранов (`h`,`a`,`e`) «дыры» света радиусом 3–4 клетки | 6 клеток; враги вне света и дальше 6 скрыты (`isHiddenFoe`) | Скрытность +; фонарь (налобный) — радиус 5 |
| `fog` | `4` α0.30 + два слоя дрейфующих полос `5` α0.12 (0.2 клетки/с) | 5 клеток; дальше — «неизвестная цель» | дальний бой: помеха дальше 3 клеток |
| `rain` | `1` α0.18; штрихи `4`/`f` 2×1 px падают под углом, брызги на полу | 8 клеток | огонь гаснет на 1 ход быстрее, `water` растёт (лужи), электричество по воде сильнее; шум: слышно хуже (звук — `sound`) |
| `blizzard` | `5` α0.25, горизонтальные точки `5`/`4` быстро | 5 клеток | огонь слабее; только в биоме `snow` |
| `storm` | `0` α0.30 + вспышка янтаря/циана `a`/`h` α0.35 раз в 4–7 с (proxy/кибер-бури) | 7 клеток | только `cyberspace`, `bunker-interior`; усиливает `proxy` |

Допустимо по биомам: wasteland — day/dusk/night/fog/rain; swamp — dusk/night/fog/rain; snow — day/dusk/night/blizzard/fog; ruins-city — всё кроме blizzard; bunker-interior — только day (освещение ламп) и storm (отключение света: ночь); factory — day/night/rain (снаружи); port — day/dusk/night/fog/rain; mutant-forest — day/dusk/night/fog/rain; cyberspace — day/night/storm. Время суток берётся из дня в игре (`save.day`, фаза), погода — seed боя + регион (шансы: day 55%, остальные делят остаток). Видимость считать по расстоянию Чебышёва до ближайшего юнита игрока/источника света; HUD показывает иконку погоды и число `vis` в строке помощи.

## 6. Для интеграции (чек-лист)
1. Рендер: `drawTile(ctx, biome, kind, variant, x, y, 3)` вместо `tileSpriteIds`; для `half`/`full`/`debris`/`water`/`decal` тайл уже содержит пол — пол отдельно не рисовать. Реквизит — `drawProp(ctx, id, x, y, 3)` (x,y — левый верх footprint; высокие уходят вверх).
2. Реквизит `cover:'half'|'full'|null`, `blocks`, `destructible`, `hp`, `debris` (id поверхности, остаётся при разрушении), `height` — берутся из `PROPS[id]`. Тайлы `half`/`full` — это «безымянное» укрытие без hp (как сейчас `c`).
3. Вариант тайла — по хешу (col,row), как `tileSpriteIds`; декаль 0 (кровь) и 1 (гарь) — поверх боевых событий, 2–3 — случайная расстановка (до 6% клеток).
4. Проверка: `validateTilesets()`, `validateProps()` → пустые массивы.
