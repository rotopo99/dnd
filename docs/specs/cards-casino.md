# Спека: карточная игра «Хлам и Кринж» и казино

Дата: 2026-11-08. Данные: `game/src/data/cards.js` (карты, герои, соперники, казино, экономика; проверено `node --check` и скриптом: 111 карт, все колоды по 20, id NPC/узлов существуют, `npcHome` совпадает). Оригинальная игра, названия и правила свои; общее с жанром — только «коллекционные карты 1×1».

## 1. Цель для игрока
Азарт и «собирательство»: выиграть странную партию у знакомого NPC, получить его карту и на неё перестроить колоду. Казино — рискованный сток кредитов с жёсткими лимитами, а не источник дохода.

## 2. Правила партии
### 2.1 Числа (`CARD_RULES`)
| Параметр | Значение |
|---|---|
| Колода | 20 карт, ≤2 копий, легенда ≤1 |
| ЗДР героя | 25 |
| Рука | макс. 7 (лишняя карта сгорает) |
| Поле | 5 слотов на сторону |
| Старт. рука | первый 3, второй 4 + «Запасная батарейка» |
| Заряд (ресурс) | в начале хода +1, макс. 8; с лишним не переносится |
| Сила героя | 2 заряда, раз за ход |
| Выгорание | добор из пустой колоды: N-й раз — N урона герою |
| Таймер хода | 60 с, потом авто-конец |
Победа: ЗДР героя врага ≤ 0.

### 2.2 Ход
1) +1 заряд, добор, события `turn-start`. 2) Любой порядок: играть карты, атаковать существами, сила героя. 3) «Конец хода»: события `turn-end`, статусы тикают.
Существо, вышедшее на поле, атакует со следующего хода (кроме Рывка). Существо атакует раз за ход: по существу врага или (если нет Заслона) по герою. Бой существ — обмен ударами одновременно. Если у врага есть Заслон — бить можно только Заслон.
Гаджет: ложится в отдельный слот (макс. 2), `dur` — число срабатываний; потом уходит. Заклинание — разово, потом в сброс.
Слот занят — карта существа не играется.

### 2.3 Ключевые слова
| Слово | Правило |
|---|---|
| Заслон (taunt) | врага можно атаковать только через Заслон-существ |
| Рывок (rush) | атакует в ход выхода (только существа, не героя) |
| Щит (shield) | гасит весь урон от первого попадания, потом снимается |
| Яд (poison) | любое существо, получившее урон от этого, умирает |
| Кринж-аура N | пока на поле: вражеские существа −N АТК (мин. АТК 1). Сумма аур ≤ `cringeAuraCap`=3. Скрилет (`immuneCringe`) не замечает |
| Выход / Финал | `on: play` / `on: death` |
Теги `mech`, `skeleton` — для «против механизмов/скелетов» (`vsTag`).

### 2.4 Словарь эффектов `{ on, op, to, ... }`
`on`: `play`, `death`, `turn-start`, `turn-end`, `aura`, `cast` (+`oncePerTurn`). Вне `on` у заклинаний — `play`.
`op` (переиспользованы из боя): `damage`, `heal`, `shield` (дать Щит), `buff` (`atk`,`hp`,`turns?` — без turns навсегда), `status` (`id`,`turns`: `stun` — не атакует, `poison` — 1 урон в конце хода, `cringed` — −`atk`), `summon` (`card`,`n`,`fill`), `drain`. Новые: `draw`, `discard` (случайная), `gain` (заряд до конца хода), `give` (карта в руку), `tax` (карты врага +n к цене), `destroy` (`where`: `atkMax`, `costMax`, `tag`, `kw`), `duel`, `roll` (`die`,`low`,`high`), `steal`, `scry`, `devour`, `armor` (герой, до своего следующего хода), `cringe` (аура).
`to`: `self`, `self-hero`, `enemy-hero`, `choose-enemy`, `choose-enemy-creature`, `choose-ally-creature`, `choose-ally`, `choose-any`, `choose-any-creature`, `choose-enemy-gadget`, `all-enemy-creatures`, `all-ally-creatures`, `all-creatures`, `all-other-creatures`, `adjacent-allies`, `random-enemy-creature`, `random-ally-creature`, `weakest-enemy-creature`. Нет цели — заклинание/выход пропадает (карту можно сыграть только при наличии цели для обязательных «choose»).
Прочее: `vsTag {tag: n}` — урон n вместо n при теге; `if {allyCreaturesMin}`.

### 2.5 Состав (111 карт)
По 13 в наборах: АИ Партия, Жестяное братство, Пираты, Мусорщики, Мутанты, Техоньки, Кринжгоны (8 существ, 3 заклинания, 1 гаджет, 1 легенда); нейтральных 20 (14 существ, 4 заклинания, 1 гаджет, 1 легенда «Судья»). Жетоны (6) вне коллекции. Колода собирается из 1 фракции + нейтральных (чужие наборы запрещены). Герои — `CARD_HEROES` (8, пассивка + сила героя).
Взаимодействие с игрой: герой «Хан», «Азтун» и др. — NPC из `npcs.js`; сила героя — фракционная пассивка; Кринж-аура и Заслон — те же понятия, что в бою.

## 3. ИИ соперника (для программиста)
Профиль `ai: {aggro 0..1, risk 0..1}`. На своём ходу, по шагам до исчерпания заряда:
1. **Летал**: если сумма АТК готовых существ ≥ ЗДР героя игрока и нет Заслона — все бьют героя.
2. **Розыгрыш**: перебрать играбельные карты; оценка = стоимость карты (чем дороже, тем лучше) + бонус за влияние: убийство существа +(его cost+2), урон по лицу при aggro>0.6 +1/ед., лечение при ЗДР<10. Играть лучшую, повторять. Существо ставить в крайний слот; Заслон — в центр.
3. **Атаки**: для каждого готового существа искать «выгодный размен»: оно убивает цель и переживает (приоритет), затем равный размен (cost цели ≥ cost своего) при `risk` ≥ 0.5. Иначе — если нет Заслона и aggro ≥ 0.5 — бьёт героя, иначе не атакует.
4. Сила героя: если остался заряд ≥2, не из-за обязательных карт.
5. Конец хода. Пауза между действиями 0.6–0.9 с (анимация).
Ошибки допустимы: с вероятностью `0.15 − 0.03·tier` выбрать вторую по оценке карту. Без подглядывания в руку игрока.

## 4. Получение карт
| Источник | Правило |
|---|---|
| Старт | `STARTER_DECK` (нейтральная, 20) + герой «Странник» |
| Победа над NPC | первая — карта `reward`; дальше 25% пак (`winPack`) из набора соперника; ставка выплачивается |
| Торговцы | `CARD_ECONOMY.vendors`: одиночные карты по `RARITY.buy`; пак 5 карт — 80 кр, ≥1 редкой; ассортимент по `stock`; обновление раз в 5 дней |
| Лут боёв | 4% (обычный бой) / 25% (босс) — карта набора фракции врага; шанс по `RARITY.w` |
| Легенды | только боссы фракций, квесты, турнир; не продаются |
| Продажа | 25% от цены покупки (`sell`) |
Коллекция (`save.cards = {owned: {id:n}, decks: [{name,hero,ids}], active, wins: {npcId:n}, casino: {...}}`) в инвентаре отдельной вкладкой «Карты», **не занимает сетку**. Редактор колоды: слева коллекция (фильтры набор/стоимость/редкость, счётчик «n/20»), справа колода кривой стоимости; чужую фракцию добавить нельзя; кнопка «Автосбор» (по кривой 1–3×6, 4–5×6, 6+×2).

## 5. Соперники (`CARD_RIVALS`)
12 NPC по узлам, у каждого колода, ставка, tier 1–5 и награда:
Туз (raytsentr, 15), Дед Отмычка (pirates-m30, 25), Крысиная Тома и Щуп (svalka, 30/40), Распорядитель Сабля (cc-duel-club, 50), Бумеранг (putinlyandiya, 60), Полковник Шуруп (kreml, 80), Секиро (velikaya-arena, 100), Тётя Лоза (garmoniya, 120), Искра (stanok, 150), Кринж-Шут (pepelnoe-gornilo, 200), Мадам Ставка (pirates-m30, 250, босс). Вызов — действие «Сыграть в карты» у NPC (враждебные фракции отказываются; отказ снимается проверкой Обмана/Убеждения СЛ 13). Ставка и проигрыш — в кредитах; нет денег — играть нельзя. Ничья невозможна (при взаимном 0 побеждает ходивший вторым). Баланс-проверка: колода tier N должна проигрывать стартовой колоде в ~70% при N=1 и ~25% при N=5 (играет balance-tester).

## 6. Казино (`CASINO`)
**Где:** «Игорный зал» в Баре Лагуны, узел `pirates-m30` (в лоре уже есть игорный зал: `nsa-dec-casino`; хозяйка — Мадам Ставка, она же в Баре). Вход открыт при нейтральной репутации Пиратов.
| Игра | Правила | Мин/Макс | RTP |
|---|---|---|---|
| Карты | партия с NPC (§5) | 10/250 | зависит от игрока |
| Кости | 2d6 против дома, игрок может перебросить 1 кость, если сумма < 8; дом — < 7; дубль +1 к сумме; ничья — дому; выигрыш ×2 | 10/100 | ≈95.3% |
| Автомат | 3 барабана, одинаковые ленты 12 позиций: Тушёнка 4, Шестерёнка 3, Радио 2, Скелет-череп 1, Кринж-маска 1, Глаз Судьи 1. Три одинаковых: ×6/10/20/40/80/200; две Кринж-маски ×3; две Тушёнки ×1 | 5/50 | ≈93.6% |
| Рулетка | 38 ячеек (0 и «00 Кринж»); число 35:1, цвет/чёт 1:1, дюжина 2:1 | 5/100 | 94.7% |
**Лимиты:** чистый проигрыш за день ≤ 300 кр (потом «Дед Отмычка выводит вас за воротник» — столы закрыты до утра); чистый выигрыш за день > 500 кр закрывает столы до утра. Столы не дают опыта, репутации и предметов — только кредиты.
**Долг:** Мадам Ставка даёт до 200 кр; +20% каждые 3 дня; срок 9 дней. Просрочка: Пираты −3 реп., бой «w-road-pirates» (сборщики) при следующем входе в регион, столы закрыты. Квест `q-casino-debt` (записать в `quests-npc.js`): стадии — отработать долг (взлом/Обман СЛ 14 против букмекера, либо бой) или выиграть ставку 250 у Мадам; награда: долг списан, +5 реп. Пиратов. Связан с компаньонским `cq-stavka` (стадия `debt`): не пересекаются по флагам.
**Турнир** `q-casino-tournament`: взнос 100, 3 раунда (Туз → Отмычка → Мадам Ставка) с той же колодой игрока, проиграл — вылет; приз 500 кр + карта «Мадам Ставка» + реп. Пиратов +5; раз в 14 дней.

## 8. Критерии приёмки
1. `cards.js` загружается без ошибок; 111 коллекционных карт, у каждой уникальный id, все `fx.card` существуют; каждая колода соперника и `STARTER_DECK` — 20 карт, ≤2 копий (легенда 1).
2. Партия: счётчик заряда растёт 1→8, рука ≤7, пустая колода даёт возрастающий урон, победа при ЗДР ≤ 0.
3. Заслон нельзя обойти атакой; Щит гасит первый удар; Яд убивает существо любой прочности; Рывок позволяет бить в ход выхода.
4. ИИ: при смертельном «летале» бьёт по лицу; не атакует в Заслон героем при выгодной цели; не зависает (ход ≤ 8 с).
5. Лимиты казино: ставка вне [мин;макс] отклоняется; после −300 кр за день столы закрыты; RTP автомата в симуляции 10⁶ круток 93.6% ±1%.
6. Долг растёт на 20% каждые 3 дня и блокирует столы при просрочке; победа/выкуп снимает.
7. Коллекция не занимает ячейки сетки инвентаря; сохранение/загрузка сохраняют колоды.
