# Спека: интерактивные кинематографические сцены («как в Dispatch»)

Дата: 2026-11-21. Владелец: game-designer. Данные: `game/src/data/cinematics/` (индекс `index.js`, шесть сцен `c1…c6`). Движок: Three.js (`threejs-migration.md`), модели GLB (`tools/blender/README.md`). Лор: `docs/lore/BIBLE.md`, `docs/story/main-plot.md`.

## 1. Цель для игрока
В ключевые моменты сюжета бой и карта уступают место анимированному «кино»: камера, актёры, мимика, реплики. Игрок не зритель: на таймере выбирает тон, в нужный миг жмёт кнопки. Чувство: «я это пережил, и мир запомнил». Молчание — тоже ответ, а провал QTE — не наказание, а другая ветка.

## 2. Формат сцены (данные)
Корень: `{id, title, mins, music, stage, trigger, req?, cast, start, beats, ctr0?}`. `beats` — граф узлов; ссылка на узел — по ключу.

| Поле beat | Смысл |
|---|---|
| `shot` | кадр: `<frame>:<актёр>[:<второй>][>move[:сек]]`. Frames: wide, two, med, close, xclose, ots, low, high, dutch. Moves: push (наезд), pull, pan, orbit, crane, fig8 (восьмёрка), hand, whip, shake. Числа — `SHOT_FRAMES/SHOT_MOVES`. Камера считается от актёров |
| `tr` | переход: `cut` (по умолчанию), `fade`, `whip` |
| `set` | состояние актёров с этого узла: `{who: {at:[x,z], face:'who'\|градусы\|[x,z], anim, emo}}`; сохраняется до смены. Единицы — метры, `+z` к камере по умолчанию |
| `lines` | реплики по порядку: `{w, t, emo?, anim?, p?, vox?}`; `w` = ключ актёра или `narr` (титр/радио); `p` — пауза до реплики (сек); `vox` — `choir` (3 наложенных голоса) или вокализ из `audio/vox.js` (sigh grunt scream laugh hm battleCry); без `vox` — «блип» по `voice` актёра. Субтитры всегда |
| `hold` | задержка кадра после реплик (сек) — «пауза-реакция» |
| `react` | врезка реакции `{who, shot, emo, sec}` на последней реплике |
| `fx` | `sfx` (id из `audio/sfx.js`), `music` (трек `audio/music.js` + fade), `fade`, `shake`, `grade` (цветокор: mono-blue, red-dim, white-flash…), `glitch`, `vox` |
| `choice` | `{sec, who, prompt?, opts:[{id,l,tone,next,on,req?}], silence:{l,next,on}}`: 2–4 варианта (без silence) + **обязательное** `silence`. Тон: kind/hard/smart/funny/silent (`TONES`) |
| `qte` | `{kind: tap\|hold\|mash\|seq, keys, sec, need?, label, ok:{next,on}, fail:{next,on}}` |
| `check` | проверка навыков `{skills, dc, mod:[{ctr\|flag, dc}], ok, fail}` через `checks.js rollCheck` (лучший из партии) |
| `branch` | `[{if:{flag\|notFlag\|any:[..]\|ctr:{имя:min}}, next}, …, {next}]` — первое сработавшее |
| `on` | последствия (см. §3); на beat — применяются при входе |
| `end` | `{result, on?, fx?}`; `result` читает вызывающая сцена (`to-battle-1`, `court-won`…) |

`cast`: `{k:'hero'}` — герой игрока (модель/внешность из `hero.look`); NPC: `{name, model (GLB-пресет), hair, portrait (для 2D-фолбэка, `portrait-of.js`), voice{gender,race,pitch,choir?}, look?}`.

## 3. Правила
Числа — `CINE_RULES` (крутит balance-tester).

| Параметр | Значение |
|---|---|
| Скорость субтитров | 15 симв./с, мин. 1.2 с, зазор 0.25 с |
| Таймер выбора | по умолчанию 8 с, 5–12; настройка: Расслабленный ×1.5 / Обычный / Короткий ×0.75 / Выкл. Ввод блокирован первые 0.4 с |
| Таймер вышел | срабатывает `silence` (герой молчит; NPC реагирует на молчание — у каждой сцены своя реплика) |
| QTE tap | 1.2 с, одно нажатие |
| QTE hold | удержать `need` из `sec` (обычно 2.5 из 4 с); отпустил — прогресс падает вдвое быстрее |
| QTE mash | `need` нажатий за `sec` (8 за 3 с … 12 за 4 с) |
| QTE seq | 3–4 клавиши, на всю серию 3.2–3.5 с; неверная клавиша = провал |
| Доступность | «Упростить QTE»: время ×1.5, need ×0.7; «Пропускать QTE»: всегда успех |
| Провал QTE/проверки | **никогда не game over**: ветка `fail` (потеря МРЛ 5–10%, иной исход, иной бой) |
| Отношение NPC `rel` | ±5, `save.cine.rel[npc]`; если NPC — напарник: `addLoyalty(Δ × 2)` |
| Романтика | `bond: {npc: Δ}` → `romance.addBond`; `romance: {npc:'date'}` → `finishDate` (1 свидание) |
| Репутация | `rep: {фракция: Δ}` → `applyRep` (±1 на сцену) |
| «X запомнит это» | `rem:{who, t?}`: тост 2.5 с; по умолчанию «<Имя> запомнит это» |
| Счётчики `ctr` | локальны сцене (`ctr0`), используются в `check.mod` и `branch` |
| Флаги | `on.flag` → `save.flags`; ключевые таблицей ниже |
| Длина | 1–4 мин (сейчас сцены 1–2.5 мин при чтении ~15 симв./с без пропусков); 9–27 узлов |
| Частота | ≤ 1.5 сцены за час игры, ≤ 12 в игре; повтор — только из Кодекса («Пересмотр»); скип доступен после первого просмотра |

Последствия `on`: `{flag, rel, rep, bond, romance, mrlPct, ctr, rem}`. Опыт не даётся: награда сцены — сюжет и ветки.

## 4. Режиссура (как подавать)
1. **Герой молчит** (канон пролога): варианты — намерения и жесты («Показать пустые руки», «Положить руку на плечо»), отвечает мир. Так нет проблем с полом и расой героя.
2. **Пауза решает.** После тяжёлой реплики — `p: 0.8–1.8` и крупный план на слушающем (`react`). Драма — тишина и наезд (`push`), юмор — быстрый «рубленый» ответ на следующем кадре.
3. **Юмор через контраст:** чем торжественнее строй (суд, протокол, очередь), тем бытовее деталь («Ваш номер — 4 118 902», борщ, «автограф?»). Жрец и Судья смешны ровно до тех пор, пока не страшны.
4. **Разгрузка:** после драматичного выбора — одна смешная реплика (радио Шумка, «реклама мыла»), чтобы не давить.
5. **Выбор — три цвета:** мягко / жёстко / умно+смешно; молчание — всегда четвёртое, и оно значимо (Судья: «молчание — признание»).
6. **Камера:** wide — установка и финал; two/ots — диалог; close/xclose — эмоция и решающие слова; low — угроза; high — ничтожность героя; dutch — тревога; fig8 — напряжение перед вердиктом; push на выбор, pull на потерю.
7. **Частота:** только ключевые моменты (завязка, первые встречи с главными антагонистами, правда, суд, роман, жертва). Не вместо диалогов NPC и не на каждый квест.
8. **«X запомнит это»** — только если решение действительно меняет реплики/лояльность дальше.

## 6. UI и фидбек
- Letterbox 2.35:1 (чёрные полосы), субтитры снизу: имя актёра цветом, текст до 2 строк.
- Выбор: 2–4 плашки справа/снизу, значок тона (`TONES`), полоса таймера по убыванию; кончилась — плашка «Молчать» вспыхивает и выбирается. Клавиши 1–4, мышь.
- QTE: круглая подсказка клавиши у героя, кольцо таймера; успех — вспышка и звук `buff`, провал — глухо `debuff`, без красного экрана.
- «X запомнит это»: тост в углу + звук.
- Пауза (Esc) останавливает таймер. «Пропустить» — после первого просмотра, держать 1 с.
- Звук: музыка по `music`/`fx`, блипы голоса (`vox.js`), хор — три слоя со сдвигом 40–80 мс.

## 7. Что нужно от программиста
1. `game/src/scenes/cinema.js` на Three.js: `playCinematic(game, id, {onEnd(result)})`; разбор `shot` (таблицы `SHOT_FRAMES/MOVES`), актёры из GLB-пресетов (`models.js`), эмоции — атласы лица `face_*.png` + shape keys, взгляд — `look` на актёра/камеру; граф `beats`, `branch`, `choice` (таймер, silence), `qte`, `check`, `on` (флаги → `state`, `rel`, `rep` → `reputation.applyRep`, `bond` → `romance`), сохранение прогресса сцены (выход в паузу).
2. **Фолбэк без 3D:** «комикс»: 2D-портреты (`portrait-of.js drawSpeaker`) в рамках-панелях, смена панели = смена `shot` (frame задаёт размер/позицию панели), те же субтитры, выбор, QTE.
3. Площадки `stage` (6 шт. в `STAGES`) от art-director: простые диорамы, не боевые карты.
4. Клипы: сверх текущих `idle…death` нужны `talk shrug point lean sit nod shake laugh cry hands_up stagger reach` (список `CLIPS`) — заказ Blender-скриптам (`anim.py`); пока нет — проигрывать `idle` с процедурным жестом. Модели `judge-avatar` и `outfit_cyber_m` — на очереди.
5. Опционально: просмотрщик сцены (`?cine=<id>` в URL: пройти граф, подсветить ветки, показать флаги), валидатор графа (ссылки, `silence` везде, клипы/эмоции из списков).
6. Хуки запуска: по `trigger` (`at`, `before`, `after`, `needFlag`, `romance`); одноразовость — флаг `cine-seen:<id>`; Кодекс «Пересмотр».

## 8. Критерии приёмки
1. Каждая из 6 сцен проходится от `start` до `end` по всем ветвям; нет мёртвых ссылок (проверено скриптом: все узлы достижимы, у каждого выбора есть `silence`).
2. Таймер выбора: по истечении выбирается `silence`, настройка «Выкл.» отключает таймер; пауза замораживает.
3. QTE: успех и провал ведут в разные узлы; игра не заканчивается; «Пропускать QTE» всегда даёт `ok`.
4. Последствия записываются: после `c3` стоит `truth-lox5` или `lox5-partial`; после `c6` — `lox-dead` или `lox-alive-door`+`door-halfsealed`; тост «запомнит» появляется.
5. В `c4` СЛ проверки меняется по счётчикам (3 свидетеля, улика, защитник → 19 − 6 − 1 − 1 = 11); без свидетелей провал → `lost`.
6. Без WebGL сцены играются в режиме «комикс» с теми же выборами и субтитрами; консоль чиста.

## 9. Вне рамок
Озвучка живыми голосами (только вокализ и блипы); свободное хождение в сцене; скрипт-язык и редактор в игре; смена внешности NPC по выбору; сцены на все 16 напарников (по образцу `c5`/`c6` — позже); мультиплеер (в кооперативе сцена показывается всем, выбор — у хоста).
