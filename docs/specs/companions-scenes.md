# Напарники и «сцены проверки» (2026-11-07)

Данные: `game/src/data/companions.js`, `game/src/data/world/check-scenes.js` (форматы — в шапках файлов). Движок не тронут.
Расхождение с просьбой: в игре уже было **16** напарников, а не «10–12»; не удаляли (сломались бы сейвы и квесты). Добавлено 5 женщин → **21** (11 женщин). Решение для режиссёра: если нужен именно потолок 12 — делать «ротацию»: часть скрыта до квеста.

## Часть 1. Напарники

**Цель для игрока.** Партия — это люди, а не слоты: их нужно заслужить, держать в доверии и прокачивать вместе с собой.

**Состав (новые).** Седьмая — андроид, Рейнджер/Охотник, Военпром. Булатка — человек, Забивной/Железный титан, Жестяное братство. Косточка — скелет, Айтишник/Изобретатель, Мусорщики. Ласка — мутант-зверь, Мутант/Хищник, Пираты. Проволока — техонёк, Эколог/Техно-шаман, Техоньки. Женщины среди прежних: Дымка, Мадам Ставка, Зоя Клык, Тётя Лоза, Заря, Сестра Помеха.

**Правила вербовки.** `recruit.conditions` — все выполнены, ИЛИ все `alt`. Виды условий: репутация фракции, «знакомство» (стадия `meet` личного квеста), чужой квест, проверка навыка (авто-сцена), плата, мировоззрение, флаг, предмет, уровень, несовместимость (`notWith`: hard — нельзя нанять, пока тот в партии; soft — трение). Отказ показывает `why`. Пары hard: Секиро–Мадам Ставка, Зоя–Заря (снимается личным квестом одной из них). Soft: Lox–Помеха, Дымка–Булатка, Дисс–Помеха, Тик–Косточка.

**Лояльность** = `approval` (−100…100, `rules.js`). Источники: теги поступков (likes/dislikes + `loyalty.deeds`), события из таблицы. Уход: ≤ −70 (предупреждение −50), реплика `leave.line`, возврат — извинение + старт −40.

| Событие | Δ |
|---|---|
| этап / завершение личного квеста | +5 / +15 |
| 3 боя без потерь | +1 |
| напарник упал, не поднят | −3 |
| герой поднял упавшего | +3 |
| ждёт на хабе, за 3 дня | −1 |
| подарок по вкусу (раз на предмет) | +4 |
| привал: связанная пара / soft-несовместимые | +1 / −2 |
| отказ в просьбе напарника | −5 |

**Личный квест**: `PERSONAL_QUESTS['cq-<id>']`, 2–3 стадии (`meet` → бой/проверка → выбор), стадии открываются по `loyaltyMin`. Награда: опыт, +15 лояльности, право сменить путь на `altPath`.

**Прокачка.** Свой `p.xp`. Доля от наград героя: активный ×1.0, ждёт ×0.5, ушедший 0; отстающий — ×1.5; уровень ≤ уровня героя. На повышении: ASI (уровни `asiLevelsFor(cls)`) через существующий `openAsi`; при лояльности ≥ 20 выбирает игрок (+2 / +1+1 / талант из 3 + любимый), иначе напарник сам (`autoAsi`), игроку — строка. Смена пути — раз, с 5-го уровня, после личного квеста.

**Реплики.** 17 ситуаций (`COMPANION_RULES.barks.chance`), глобальный кулдаун 75 с, на напарника 150 с, на ситуацию 240 с, макс. 1 за сцену, не в диалогах; реплики likes/dislikes и «упал союзник» — самые вероятные. Пул: `BARKS_GENERIC` + личные (`barks` напарника: старт боя, победа, союзник упал).

**UI.** Диалог вербовки: список условий с галочками/причинами. Лояльность — полоса с названием (`bands`) в «Партии». Реплика — пузырь с портретом 3.5 с. Уход — тост + запись в журнале.

**Критерии приёмки.**
1. Каждый из 21 в диалоге показывает условия; невыполненное блокирует найм и показывает `why`.
2. Hard-пара: второго нанять нельзя, пока первый в партии/ждёт.
3. Опыт: 50% у ждущего, 0 у ушедшего; уровень не выше героя.
4. На уровне ASI при лояльности ≥ 20 открывается окно выбора, при < 20 — авто-выбор и строка.
5. За 10 боёв реплик ≤ 4 на партию; в диалоге не звучат.
6. Лояльность ≤ −70 — уход на `home`; возврат работает по `leave`/извинению.

**Вне рамок:** романы, смерть напарника навсегда, торговля между напарниками, озвучка.

## Часть 2. Сцены проверки

**Цель.** Проверка — маленькая сцена с выбором подхода, а не голая кнопка.

**Правила.** Сцена: пролог 1–3 строки; 2–4 подхода (навык ⊆ навыки проверки, `dcMod` −3…+3, предмет `+2` с `consume`, напарник `+2`/преимущество, реплика `say`); бросок d20; исходы: успех / провал / крит. успех (натуральная 20 при успехе) / крит. провал (1 при провале), у каждого текст и `fx` (hp, mrl, party, days, rep, credits, items, flags, xpPct). Провал по-прежнему запускает `onFail` стадии. Нет своей сцены — `autoScene` (шаблоны `SKILL_TEMPLATES` — все 20 навыков).

**Анимация** (`CHECK_SCENE_RULES.anim`): кубик крутится 0.9 с (18 к/с) → замирает на натуральном → слева направо плюсуются модификаторы (0.22 с на каждый) → «N против СЛ M» → слово исхода (крит. — вспышка 0.45 с, крит. провал — тряска). Помеха/преимущество — два кубика, лишний тускнеет. Клик/Enter — пропуск до итога.

**Переведено в сцены (15, ключи `qid/stage#путь`):** ворота (`mq-exodus/get-in`), узел (`find-node`), перепрошивка (`close`), три маяка (`mq-beacons`), Маячник, закладки (4 слота), Хихик ×2, чипы ×2, посылка Алика, чип раба, ведомость, дверь Кремля, суд Киберспейса.

**Критерии приёмки.**
1. Открытие проверки из списка 15 показывает пролог и ≥2 подхода; недоступный подход серый с причиной.
2. Бросок проигрывает анимацию; пропуск не меняет результат.
3. Крит. 20/1 показывает свой текст; `fx` применяются один раз (повтор из `save.memo` не повторяет).
4. Остальные ~140 проверок открываются с авто-сценой по первому навыку.
5. `fx.days`/`hp`/`rep` отражены в тосте.

**Вне рамок:** озвучка, сцены для `challenge` (серии), портреты в сцене.
