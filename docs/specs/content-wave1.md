# Контент-волна 1 (2026-11-17)
Основание: `docs/FEEDBACK-2026-11-07.md` (постоянное поручение), `docs/research/crpg-what-players-love.md`. Ориентир тона — Wasteland 3: сухая серьёзность абсурда. Лор — по канону, домыслы помечены.

## 1. Радио «Голос Пустошей» (`world/radio.js`)
- **Цель:** мир замечает героя. Эфир иронично пересказывает поступки (розыск, деяния, романы, квесты, Исход).
- **Диджей Шумок** — придуман (канон знает только радио). Сухой голос, новости как прогноз погоды.
- **Контент:** 106 новостей (фон 14, Исход 8, сюжет 10, розыск 7, деяния/репутация 12, романы 7, отряд/бои 9, деньги/место 6, волна 1 — 28, мета 6), 12 перебивок.
- **Где слышно:** рация (кнопка «Эфир»), радиоузел базы (3 новости при входе), привалы/таверны (50%), хабы (25%), Остановка со связью (60%).
- **Правила:** кулдаун 10 дней; `once` не повторяется; выбор по `prio`, затем давно не звучавшая; перебивка 35%. Условия — DSL в шапке radio.js.
- **Приёмка:** 1) при `wanted>=1` в эфире звучит `rd-crime-1`; 2) `once`-новость не повторяется; 3) в `radio-room` при входе 3 разные; 4) после `w1-station:comms` шанс в хабах выше.

**Тест «зачем этот тип здесь?» / что реально разное / что меняется / где смешно**
- filters: Огород — единственный, кто знает, чья вода; 5 разных ценников (rep, цены Кучи, отложенная жажда/колодец); сито для макарон.
- circus: Арлекин считает апокалипсис антрактом; три концовки (переезд, возрождённые гастроли, труппа); манекены-зрители.
- flood: Причал видит оба конца; спасти обе нельзя без чистой работы; судьба Белбы/баржи отложена (урожай/плевок беженца).
- cauldron: улики противоречат (ключ у Якоря ложная, плесень+долг — правда); ложный приговор → второй яд через 3 дня.
- hearing: Колобок приютила скелета; 4 метода, поражение не тупик; прецедент меняет слухи; носки.
- medbox: Флажок не врёт «врагам», только «друзьям»; правда всплывает через 4–6 дней по-разному.
- hunter: Труп считает кости; условие (уважение Мусорщиков) открывает мирный путь; Костолом вернётся при фальшивке.
- station: Расписание 11 лет ждёт поезд; одна из трёх систем меняет услуги и цены узла.

## 3. Последствия и отложенные (`consequences-wave1.js`)
Формат consequences + `delayed [{id, days, say, fx, radio}]`, `services`, `priceZone`, `deeds`. Каждый исход имеет слух; 15 отложенных (4–8 дней).

## 4. Данные
Сдача — `text/quest-turnin-wave1.js`; проверки — `check-scenes-wave1.js` (30 сцен, ключи `qid/stage#путь`, подцели `s<N>` с 1); NPC-выдача добавлена в `GIVERS` (`density-npcs.js`).

## 5. Нужно от программиста
1. Подключить `QUESTS_WAVE1_MAP`, `QUEST_TURNIN_WAVE1`, `CONSEQUENCES_WAVE1`, `CHECK_SCENES_WAVE1` в `world/data.js`; `outcomeBy` фоллбэк `late`.
2. **Отложенные эффекты:** `save.delayed`, срабатывание при passDays, флаг `dl:<qid>:<id>`, тост + журнал.
3. **Таймер квеста** `timer {days, stage, onExpire}`; `all` с `min:1` и `doneFlag`, ставящимся fx сцен; при истечении — исход `late`.
4. **Дебаты:** `challenge` уже есть; нужен переход `onFail` в stage с `choice`. Проверить `onFail` внутри `all` (в wave1 не используется).
5. **Обвинение:** обычный choice с `requires.flags`; новых механик нет.
6. **Радио-эфир:** окно «Эфир», DSL условий, счётчики `deeds/battlesWon/fled`, хуки places, звук перебивок (`track`).
7. Consequences: `services`, `priceZone`, `deeds`, `delayed`; сцены: `fx.flags` и записки.
8. Записки: окно «Находка» по `LORE_WAVE1.notes[].where` (`stage:`, `scene:`, `cq:`); тайны — в кодекс.
