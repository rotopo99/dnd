# Управление в духе Divinity: Original Sin 2

Дата: 2026-11-15. Основа: `docs/specs/free-roam.md`, `roam.js` (ЛКМ = идти/взаимодействовать, C = красться уже есть), `battle.js`, `ui/unit-pin.js`.

## Цель для игрока
Всё, что можно сделать с объектом, видно в одном месте по ПКМ: не надо помнить кнопки и лезть в меню узла. Партия ходит как отряд: выбрал, повёл, разделил, собрал. Чувство: «я командир», а не «я двигаю одну фигурку».

## Правила

### 1. ПКМ: клик против перетаскивания
- ПКМ-клик (сдвиг < `GFX.camera.dragMin`, уже в `input.js`: `mouse.rightClicked`) открывает контекстное меню; ПКМ-перетаскивание остаётся панорамой.
- Цель клика определяется как у ЛКМ (`S.hoverEnt`, иначе клетка). Партия: свой член на карте.
- Меню закрывается: Esc, ЛКМ вне меню, повторный ПКМ в другом месте (тогда открывается новое), начало боя, модал.
- Меню не открывается над кнопками HUD и при открытом модале.

### 2. Пункты меню (порядок сверху вниз; недоступные серые с причиной в подсказке)
| Пункт | Для кого | Условие | Действие (что вызываем) |
|---|---|---|---|
| Поговорить | NPC | рядом (досягаемость `ROAM`) | `npc-actions.talk` |
| Торговать | NPC с профилем | `tradeAccess` | `openShopHere` |
| Вербовка | NPC-кандидат | `recruitStatus` | `openRecruit` |
| Поручение | NPC, у которого квест/резерв | `offeredBy` / экспедиции | `offerQuest` / `openExpeditions` |
| Отдать предмет | NPC / член партии | есть предмет | список рюкзака → `giveGift` / `moveItem` |
| Украсть | NPC | включён режим «Красться» | `openTheft` (со спины: бонус `theftMod`) |
| Атаковать | NPC, враг | `attackBlock` не блокирует | враг: бой сразу; NPC: `openAttack` (подтверждение, розыск) |
| Осмотреть | любой | всегда | NPC/враг: запись кодекса (`codexLevel`), объект/клетка: описание |
| Использовать навык | точка навыка, узел | `skillActionsAt` не пуст | список `node-skill-actions` с шансом; приёмы вне боя из `skill-uses` |
| Взломать | контейнер, дверь, терминал | навык взлома/СЛ | `runSkillAction`/`openCheck` |
| Обыскать | ящик, труп | не обыскан | существующий `objectAction` |
| Закрепить карточку | юнит в бою | только в бою | `pinUnit` |
| Идти сюда | пустая клетка | проходимо | `goTo` |
Пустое меню (только «Осмотреть») не показываем: сразу тост-описание.

### 3. «Атаковать» врага на карте
- Бой начинается на вырезке карты узла (`roam-battle.js`), как при обнаружении.
- До удара партия подходит на дистанцию оружия (новое число `ROAM.attackReach` = 1.5 клетки для ближнего боя, иначе дальность оружия): герой идёт, затем **анимация атаки** 0.35 с (выпад вперёд на 0.3 клетки и возврат, вспышка клинка/дульная вспышка по `weapon.range`), потом старт боя с флагом `roamFirstStrike`: цель и сторона атакующего получают +1 к инициативе (не удар «бесплатно», чтобы не ломать баланс). Из режима «Красться» и со спины — внезапность: враг теряет первый ход.
- Цель, видящая партию, не получает бонуса.

### 4. Режим «Красться» (C, уже есть) — доводка
| Параметр | Значение |
|---|---|
| Клавиша | C, переключатель; Shift (бег) временно перебивает |
| Скорость | `ROAM.stealth.sneak` (медленная ходьба, не менять) |
| Поза | спрайт приседает: высота −20 %, смещение вниз 2 px, ритм шага ×0.6 |
| Анимация перехода | 0.2 с (присесть/встать) |
| HUD | иконка «глаз» у лидера, полоса заметности как сейчас |
| Меню | «Украсть» доступен только в приседе |

### 5. Групповое управление (свободная карта)
- Партия в цепочке (как сейчас); новое: выбор членов. ЛКМ по члену — выбрать его; Shift+ЛКМ — добавить/убрать; клавиши 1–4 — выбрать №; Ctrl+A — все; рамка выделения ЛКМ-перетаскиванием по пустой клетке.
- Приказ «идти» ЛКМ по клетке относится к выбранным; невыбранные остаются стоять.
- Режимы: **Цепочка** (по умолчанию, выбраны все, остальные следуют за лидером по `trail`) и **Свобода** (клавиша F2/кнопка в HUD: каждый член ходит независимо, выбранные идут на клик, формация не сохраняется). В свободе без лидера «Красться» и «Бег» работают на выбранных, а обнаружение считается по самому заметному.
- Смена режима «Свобода» → «Цепочка»: члены идут к лидеру; при выходе из узла/бое автоматически Цепочка.
- Вход в бой: члены остаются на своих клетках (`roamBattleMap` уже ставит старты по клеткам); вырезка включает всех.
- Кооп: у гостя свой герой (`move` как сейчас), групповое управление доступно только хосту для NPC-спутников.

### 6. Таблица конфликтов клавиш и кнопок
| Ввод | Сейчас | Решение |
|---|---|---|
| ПКМ-клик, карта | нет действия | контекстное меню |
| ПКМ-перетаскивание | панорама 3D | без изменений |
| ПКМ-клик, бой | закрепить карточку (`battle.js:999`) / отмена выбора | без изменений: контекстное меню в бою открывает **только** пункт «Закрепить карточку» + «Осмотреть» (если цель не в режиме выбора) — иначе ПКМ отменяет, как раньше |
| Tab | меню (карта), закрепление (бой) | без изменений |
| E | взаимодействие с ближайшим | без изменений = первый пункт меню ближайшей цели |
| G | снаряжение (`nav 'gear'`) | без изменений |

### 7. Затронутые файлы (для программиста)
- Новый `game/src/ui/context-menu.js`: `openContextMenu(game, {x, y, items: [{id, label, disabled?, reason?, key?}], onPick})`, `updateContextMenu`, `renderContextMenu` (рисует через `draw.js panel/button`, `tooltip.js` для причин; закрывается по правилам §1).
- `scenes/roam.js`: обработка `m.rightClicked`, сборка пунктов из `npc-actions` и `node-actions`, выделение, режим «Свобода», анимации приседания/атаки (спрайт-модификаторы в рендере).
- `scenes/battle.js`: ПКМ — меню из двух пунктов (§6).
- `data/text/roam.js`: строки `ctx.*`.
- Звук: клик меню `uiClick`, замах `miss`/`hit` по оружию, присед — тихий шелест.

## Состояния и события
`S.ctx = null | {x,y,target,items}`; `S.sel = Set<ключ члена>`; `S.mode = 'chain' | 'free'`; `S.sneak` (есть). События: `ctx:open`, `ctx:pick(id)`, `party:select`, `party:mode`, `attack:start` → `startWorldBattle`.

## UI и фидбек
Меню у курсора (сдвигается внутрь экрана), заголовок — имя цели, иконка пункта; недоступные серые, причина в подсказке; hover подсвечивает цель контуром. Выбранные члены — кольцо под ногами, портреты в HUD с рамкой. Присед и выпад видны; тосты режимов.

## Критерии приёмки
1. ПКМ-клик по NPC открывает меню, состав пунктов зависит от NPC (торговец — «Торговать», кандидат — «Вербовка»); недоступное серое с причиной.
2. ПКМ-перетаскивание панорамирует и меню не открывает.
3. «Атаковать» врага: подход, анимация 0.35 с, бой на вырезке карты; из приседа — враг без первого хода.
4. C: спрайт приседает, скорость = `ROAM.stealth.sneak`, «Украсть» доступно только в приседе.
5. Shift+ЛКМ добавляет члена к выбору; в «Свободе» клик ведёт только выбранных; в «Цепочке» идут все.
6. В бою ПКМ по юниту закрепляет карточку, как раньше; Tab, E, G, F не изменили поведения.

## Вне рамок
Горячие клавиши пунктов, настройка клавиш, меню в хабах-меню узла (`location.js`), жесты геймпада, формации, стоп-команда «держать позицию», контекстное меню инвентаря.
