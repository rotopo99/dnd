# Спека: ядро правил «Руслания Лайт» (v1)

> Автор: режиссёр, по решениям человека от 2026-11-03. Источник — `docs/canon/`.
> Это **контракт** между дизайном (данные в `game/src/data/`) и кодом (`game/src/rules/`).
> Меняешь схему — правишь этот файл и предупреждаешь режиссёра.

## Решения человека
1. Бой **пошаговый на сетке**.
2. **Все 11 классов** настолки, сбалансированные между собой **и с расами**.
3. Расы — **по лору**, больше четырёх.
4. Попадание: **d20 + бонус атаки ≥ КБ**.
5. Кринж — **урон по МРЛ**.

## Объём v1
Уровни **1–5**. Путь класса выбирается на 1-м уровне (как в каноне). Мультикласс, крафт, торговля и дипломатия в бою — вне рамок v1.

## Характеристики
7 характеристик (код → название): `str` СИЛ, `dex` ЛВК, `con` ТЕЛ, `int` ИНТ, `wil` ТВД, `cha` ХАР, `per` ВОС.
- Модификатор: `mod(v) = floor((v - 10) / 2)`.
- Создание: все по 8, **27 очков**. Значения 9–13 стоят 1 очко за пункт, 14–15 — 2 очка (канон). Максимум 15 до расовых бонусов.
- У каждого класса есть `recommended` — готовая раскладка на 27 очков (по ней же гоняется баланс).

## Ресурсы
| Ресурс | Формула | Канон |
|---|---|---|
| ЗДР `hp` | `10 + ТЕЛ + 5×ур + race.hpBonus + class.hpPerLevel×ур` | канон + классовый бонус (для баланса) |
| МРЛ `mrl` | `10 + 2×ТВД + ур + race.mrlBonus` | **канон ÷ 5** (135 → 27), чтобы кринж-урон был в масштабе ЗДР |
| ЭНР `enr` | `5 + ИНТ + 3×ур + race.enrBonus` | канон |

Значения характеристик — **сами значения, не модификаторы** (как в каноне).

**ЗДР = 0** → «Без сознания»: падает, криты по нему автоматические. Через 3 своих хода — «Мёртв», если его не стабилизировали (лечение ≥ 1 или способность со `stabilize`). Мёртв → душа в Киберспейс (сюжетная сцена, не в v1).
**Удар ≥ 50% макс. ЗДР за один раунд** → спасбросок ТЕЛ, СЛ 12, иначе «Оглушение» на 1 ход (канон: потеря сознания, в Лайт смягчено).

**МРЛ ≤ 50%** → «Надлом»: помеха на спасброски ТВД.
**МРЛ = 0** → «Срыв», бросок d20:
- 1–10 — **разрыв сердца**: теряет 70% текущего ЗДР (минимум до 1);
- 11–20 — **потеря контроля** на 1 ход: ход делает ИИ, цели случайные.

После этого МРЛ = 25% максимума.

**ЭНР** тратится на способности (поле `cost`). Ячеек заклинаний в Лайт **нет**: только ЭНР. В бою ЭНР не восстанавливается, после боя восстанавливается полностью.
**Каст без ЭНР** могут только классы с `overcast` (КиберТех → `veil`, СлавоТех → `proxyStorm`): способность срабатывает, затем бросок d20 по таблице из `game/src/data/effects.js` (таблицы канона 1d10, нечётные/чётные делятся по d20 → d10).

## Сетка и ход
- Клетка = **1.5 м**. Метры канона переводятся так: `тайлы = round(м / 1.5)`. 5 м → 3, 10 м → 7, 30 м → 20.
- Расстояние — по Чебышёву (диагональ = 1). Движение по 8 направлениям, клетку с существом проходить нельзя.
- Стены блокируют движение и линию видимости (алгоритм Брезенхэма). **Укрытие** (ящики, баррикады) не блокирует видимость, но даёт +2 КБ, если стоит на линии стрелка и цели или вплотную к цели со стороны стрелка.
- Скорость по умолчанию — **6 клеток** (`race.speed`).
- Инициатива: `d20 + mod(ВОС) + бонусы`. Порядок фиксируется на весь бой.
- За ход: **перемещение** (до скорости, можно дробить), **1 действие**, **1 бонусное действие**. **1 реакция** за раунд.
- Действие можно потратить на «Рывок» (ещё одна скорость движения). Бонусное — на «Отход»: в этот ход движение не вызывает атак при отходе.
- **Атака при отходе**: если враг выходит из соседней клетки, ближник может потратить реакцию на одну атаку оружием.

## Бросок атаки
`d20 + бонус атаки ≥ КБ цели` → попадание.
- **Натуральная 20** — крит: количество костей урона ×2 (модификаторы не удваиваются). **Натуральная 1** — промах.
- **Преимущество / помеха**: 2d20, берётся лучший / худший. Если есть и то и другое, они взаимно гасятся.
- Бонус атаки оружием: `mod(стат оружия) + бонус владения(ур) + ступень владения + weapon.hit`.
- Бонус атаки способностью: `mod(castStat) + бонус владения(ур)`.
- **Бонус владения**: уровни 1–4 → +2, уровень 5 → +3.
- **Ступени владения** (канон, 4 ступени): 1 «нет навыка» → помеха; 2 «умеет» → +0; 3 «владеет» → +1; 4 «мастерство» → +2. На 1-м уровне класс владеет своим стартовым оружием на ступени 3.
- **КБ** = `10 + armor.kb + mod(ЛВК)` (у тяжёлой брони максимум mod ЛВК = 0, у средней = +2) + бонусы. Это канон: 10 база + КБ брони + мод. ЛВК.
- **Спасбросок**: `d20 + mod(стат) + (бонус владения, если класс владеет спасброском) ≥ СЛ`. СЛ способности = `8 + mod(castStat) + бонус владения`.
- **Специализация** (канон, правило 1): проверка навыка вне специализации — с помехой, по специализации — с преимуществом. В бою v1 действует только для навыковых проверок (взлом, скрытность), не для атак.

## Урон
Типы (`dmgType`): `slash` рубящий, `pierce` колющий, `blunt` дробящий, `energy` энерго, `fire` огонь, `electric` электро, `toxin` яд/токсин, `proxy` прокси, `cyber` кибер (магия Судьи), `cringe` кринж, `psychic` пси.
- **`cringe` и `psychic` уменьшают МРЛ, а не ЗДР.**
- `resist` — урон ×0.5 (вниз), `vuln` — ×2, `immune` — 0.
- **Прокси** (канон): по `mechanical` ×1.5, по `organic` ×0.5, по `hybrid` ×1. Прокси-урон **не критует**.
- **Щит** (`shield`) поглощает урон по ЗДР до исчерпания или до конца длительности. Несколько щитов не складываются: остаётся больший.

## Теги существ
`organic` (живые), `mechanical` (роботы, скелеты), `hybrid` (и то и другое), `digital` (духи киберспейса). На теги смотрят прокси-урон, лечение (`heal` с `only: 'organic'|'mechanical'`) и иммунитеты (например, яд не действует на `mechanical`).

### Операции эффектов (закрытый список — движок умеет только их)
| op | Поля | Смысл |
|---|---|---|
| `damage` | `dice`, `dmgType`, `bonus?` (`'castMod'` \| `'weaponMod'` \| число) | урон по ЗДР (по МРЛ для cringe/psychic) |
| `weapon` | `extraDice?`, `extraType?`, `hit?` | атака оружием класса + доп. кости |
| `heal` | `dice`, `bonus?`, `resource: 'hp' \| 'mrl' \| 'enr'`, `only?` | лечение |
| `shield` | `dice` или `value`, `turns` | поглощение урона по ЗДР |
| `status` | `id`, `turns` | наложить статус из `effects.js` |
| `cleanse` | `count`, `kind: 'debuff' \| 'any'` | снять статусы |
| `buff` | `stat` (`'kb'` \| `'hit'` \| `'dmg'` \| `'init'` \| `'speed'` \| характеристика), `value`, `turns` | временный бонус/штраф |
| `move` | `tiles`, `mode: 'teleport' \| 'dash'` | перемещение кастера |
| `push` | `tiles` | оттолкнуть цель |
| `summon` | `unit` (id из `enemies.js` или `summons`), `turns` | призыв на соседнюю клетку |
| `stabilize` | — | поднять из «Без сознания» с 1 ЗДР |
| `extraAction` | `kind: 'action' \| 'bonus'` | доп. действие в этот ход |
| `drain` | `dice`, `dmgType`, `to: 'hp' \| 'mrl'`, `ratio` | урон и лечение себя на долю нанесённого |
| `mark` | `id`, `turns`, `value` | метка: атаки по цели получают +value к урону |

Если нужной операции нет, способность получает `todo: 'что нужно'` и попадает в отчёт. Движок такие способности пропускает.

### Пассивки (`passives` у рас и классов)
`{ id, name, desc, op }`, где `op` — одно из:
`{ statBonus: { str: 1 } }`, `{ resist: { fire: 'resist' } }`, `{ kb: 1 }`, `{ hit: 1 }`, `{ dmg: { melee: 2 } }`, `{ init: 2 }`, `{ speed: 1 }`,
`{ regen: { dice: '1d4', resource: 'hp', every: 'turn' | 'battleEnd' } }`, `{ immuneStatus: ['fear'] }`, `{ critRange: 19 }`,
`{ advantage: ['stealth' | 'saveWil' | ...] }`, `{ deathSave: 1 }` (раз за бой встать с 1 ЗДР).

### `game/src/data/effects.js`
`STATUSES[id] = { id, name, kind: 'buff' | 'debuff', desc, tick?: { op, ... }, mods?: { kb, hit, speed, ... }, skipTurn?: bool, ... }`
и таблицы `VEIL_TABLE` / `PROXY_STORM_TABLE` (10 строк из канона; каждая строка — эффект через операции выше).

### `game/src/data/enemies.js`
Те же поля, что у персонажа, но готовыми числами: `{ id, name, tags, stats, hp, mrl, enr, kb, speed, weapon, abilities, resist, ai: 'melee' | 'ranged' | 'caster' | 'support', xp }`.

## Расширения схемы v1.1 (по итогам дизайна классов — обязательны для движка)
1. **Пассивки классов** могут иметь `level` (с какого уровня, по умолчанию 1) и `path` (id пути или `null`).
2. **Пути** могут переопределять `weapon`, `armor`, `recommended`; плюс справочное `role`.
3. `range: 'weapon'` — дальность текущего оружия.
4. **Операция `weapon` внутри способности с `roll: 'attack'`** делает бросок атаки с бонусом оружия. Последующие `status` / `push` / `mark` срабатывают **только при попадании**. Два `weapon` подряд — два отдельных броска.
5. `onSave: 'half'` — урон пополам, статусы **не** накладываются; `'none'` — эффекта нет.
6. **Стороны зон:** зона с `target: 'enemy' | 'tile'` бьёт только врагов (без огня по своим). Зона с `target: 'self' | 'ally'` действует на своих. `target: 'ally'` включает самого кастера.
7. `castStat` может быть `'str'` / `'dex'` у бойцов — для СЛ их способностей со спасброском.

## Изменения правил v1.2 (по итогам смоука движка)
1. **«Срыв» у врагов и призывов** (не боссов, `boss !== true`): d20 1–10 — разрыв сердца (как у героев); **11–20 — «Сломлен»**: враг сдаётся или бежит и **выбывает из боя** (считается побеждённым, событие `broken`). У героев, NPC-союзников и боссов на 11–20 — потеря контроля на 1 ход, как раньше. Так кринж становится полноценным путём к победе, как задумано в каноне («полная потеря — разрыв сердца… или потеря контроля»).
2. **Овер-каст** (каст без ЭНР) — **не больше 2 раз за бой** на юнита. После лимита способности с `cost` > 0 недоступны при нехватке ЭНР.
3. **Дальняя атака в упор**: атака оружием или способностью с `range` > 1, когда рядом с атакующим стоит враг (не «Без сознания»), — **с помехой** (как в D&D 5e).

## Общие словари id (фиксированы, чтобы отделы работали параллельно)
**Статусы** (`effects.js` обязан содержать ровно эти id; новые — только через режиссёра):
`stun` оглушение (пропуск хода) · `bleed` кровотечение (1d4 ЗДР/ход) · `poison` отравление (−2 к атаке и урону, 1d4 яд/ход; не действует на mechanical) · `burn` горение (1d6 огонь/ход) ·
`fear` страх (помеха на атаки, нельзя приближаться к источнику) · `slow` замедление (скорость ÷2, −2 инициатива) · `blind` ослепление (помеха на атаки, атаки по цели с преимуществом) ·
`root` обездвиживание (скорость 0) · `silence` немота (нельзя способности с `cost` > 0) · `disarm` разоружение (нельзя `weapon`) · `curse` проклятие (−2 к атаке и спасброскам) ·
`prone` лежачий (ближние атаки по цели с преимуществом, дальние с помехой) · `invisible` невидимость (атаки по цели с помехой, своя атака снимает) · `stealth` скрытность (первая атака с преимуществом и +крит-кость, снимается атакой) ·
`cringed` кринж-эффект (1d4 кринж/ход, −1d4 к инициативе) · `corrosion` коррозия (−1 КБ/ход, до −4) · `hallucination` галлюцинации (50% атака по случайной цели) · `dazed` дизбаланс (игнор половины щита и КБ брони ÷2) ·
`regen` регенерация (1d4 ЗДР/ход) · `inspired` вдохновение (+1d4 к следующему броску атаки/спаса) · `blessed` благословение (+1 к атаке и урону) · `haste` ускорение (+2 инициатива, +3 скорость) ·
`berserk` берсерк (+2 урон в ближнем бою, −2 КБ) · `taunt` провокация (обязан атаковать источник) · `marked` метка (атаки по цели +2 к урону) · `fortified` стойка (сопротивление физическому урону).

**Враги и призывы** (`enemies.js`): `cultist` культист-фанатик (ближний) · `cultist-gunner` культист-стрелок · `skrilet` скрилет-убийца · `acolyte` аколит Судьи (кастер, бьёт по МРЛ; босс пролога) ·
`scavenger` мусорщик · `junk-mech` мех свалок (тяжёлый, mechanical) · `crawler` ползун (мутант-хищник) · `cringe-jester` кринж-шут (кринжгон, по МРЛ).
Призывы: `drone` · `turret` · `beast-wolf` · `cyber-demon` · `gang-thug` · `biomass` · `spirit` · `hologram` (ложная цель, 1 ЗДР, не атакует).
Стандартные бои: `ENCOUNTERS.standard1` и `ENCOUNTERS.standard5` — группы для баланс-сима (по сложности на одного героя своего уровня).

## Баланс (контракт для balance-tester) — v2, по решению человека
Человек: «некоторые классы — саппорты, плюс ответвления развития; балансируй как хочешь, добавлять можно что угодно, главное — не конфликтовать с лором».
Поэтому **основная мера — бой партией**, а соло — только вспомогательная.

- **Сим A — партия (главный).** Партия из 4 героев против стандартной группы для партии (`ENCOUNTERS.party1` / `party5`). Состав: случайные классы, пути и разрешённые расы. Тысячи боёв.
  Для каждого **класса** и каждого **пути** считается **вклад**: доля побед партий с ним минус доля побед партий без него (при прочих равных — парная выборка с заменой одного героя).
  **Цель:** вклад любого пути — в пределах **±5 п.п.** от среднего; общий процент побед партии — 55–65%.
- **Сим B — соло (вспомогательный).** Один герой против `standard1/5`. **Цели только для ролей `tank` / `melee` / `ranged` / `caster`:** 40–70%. Для `support` / `control` соло-цели нет, но они не должны быть беспомощны (не ниже 20%).
- **Расы:** при любом классе раса сдвигает вклад или победы не больше чем на **±5 п.п.**
- **Пути** — отдельные сущности баланса: путь-саппорт и путь-дамагер одного класса сравниваются с путями своей роли, а не между собой.
- **Кринж** (Рэпер, часть КиберТеха и Иллюзиониста) — полноценный путь к победе через «Срыв» и «Сломлен».
- **Можно добавлять** способности, пассивки, врагов и составы боёв, если это не противоречит канону (`docs/canon/`). Каждое добавление — со ссылкой на канон или с пометкой «вне канона, не противоречит» и причиной.
- Рычаги баланса по порядку: `hpPerLevel` → кости урона → `cost` → КБ брони → пассивки → новые способности.
- Все изменения чисел — в журнал `docs/balance/CHANGELOG.md` (что, было → стало, почему, эффект по симу).
