# Киберспейс v2 + Дух киберспейса

> Владелец — game-designer. Данные: `game/src/data/world/cyberspace.js` (все числа и id — там). Дата: 2026-11-08.
> Канон (`rules/core-rules.md`, `faction-stances.md`, `lore/timeline.md`): умерли — душа в Киберспейсе, выбираются сами или вытаскивают сопартийцы
> (терминалы); **тело уничтожено — возрождаешься духом Киберспейса**. Не противоречим: эпизод побега и «3-я Отметина = конец» остаются (решение человека 2026-11-03).

## 1. Цель для игрока
Киберспейс перестаёт быть «экраном штрафа»: это второй мир с зонами, рынком душ, хакингом и боссом Судьёй, связанный с терминалами и таймером «Третий исход». Чувство: жутко-смешно (кринж), но с наградой — туда **хочется нырнуть**.

## 2. Как попасть (CS_ENTRY)
| Вход | Условие | Режим |
|---|---|---|
| Смерть | 0 ЗДР героя / разгром | Эпизод побега: 3 узла из зон по уровню, 2 из 3, Отметины (как раньше) |
| Нырок | на узле с терминалом `ours`; 1 день; тело охраняет партия | «Вылазка»: до 5 узлов, свободный выбор зон; провал = выброс (−25% МРЛ), не Отметина |
| Нейропорт (имплант `cs-neuroport`) | с любого узла | как нырок, но зоны только Привратная/Архив/Рынок; хаки реального мира недоступны |
| Дух | `bodyDestroyed` | свободный вход, без таймера (см. §7) |
Нырок: кулдаун 2 дня; шанс 10% налёта на тело, если вне базы/хаба (бой партии).

## 3. Зоны (CS_ZONES)
8 зон: Привратная, Архив памяти (tier 1), Ледяной шлюз, Рынок душ, Реле реальности (2), Хор поглощённых, Пустошь удалённых, Трон Судьи (3). Открытие — `requires`: зачистка предыдущей (флаг `cs-zone:<id>`). Зона = 2–3 узла (бой / проверка / взлом / лавка) + 1–2 события + награда за зачистку. В эпизоде смерти берутся узлы **не обязательно зачищая зону**: по одному из доступных по уровню.
Связь с сюжетом: Реле реальности показывает `FINALE_TERMINALS` (+`term-harmony`, `term-kiberspeys`); Трон открывается при `cs-ghost-key` + ≥3 терминалов не-`ritual` + зачистке Реле и Хора; Судья ослаблен (`cs-judge-weakened`): в финале −1 фаза Кибер-Жреца и +30 дней к `mq-exodus`. Души: события `cs-soul:*` — вернуть NPC на терминале `ours` (квест `sq-cs-voices`). Виктор (мёртв по канону) — дух-союзник в Привратной (`sq-cs-victor`).

## 4. Взлом (HACK_RULES)
Граф узлов: вход → ядро, 2–3 пути, ходы-таймер, трассировка. Тиры по уровню героя (таблица в данных). Узлы: открытый, ICE (проверка Хакинг/Технологии/Анализ/Магия Судьи), ловушка, кэш, ядро. Кнопки «Пройти / Взломать / Обойти / Откат». Преимущество — флаги `terminal-touch`, `judge-code`, `cyberspace-adv`. Трассировка ≥ 6 — бой со сторожами зоны; ≥ 10 — Око Судьи.

## 5. Хакинг реального мира (HACK_EFFECTS / HACK_POINTS)
Из Реле, **только терминалы `ours`** (`ritual` — красное окно, бой; `dead` — окна нет). Эффекты: дверь (снять замок/`entry`/`hidden`), турели (−2 врага в следующем бое охраны), камеры (СЛ скрытности −3, розыск не растёт), цены (×0.85 на 5 дней, `wantedPriceMult` игнорируется), розыск (−2, раз на фракцию в 10 дней, нужна Кибердека). У каждого — кулдаун в днях. Привязка узлов — таблица `HACK_POINTS` (все 5 `FINALE_TERMINALS` покрыты). Флаги `cs-hack:<эффект>:<цель>` (срок — `days`).

## 6. Враги, события, награды
Существующие: `scriptlet`, `materialized-soul`, `spirit-victor`, `cult-firewall-l18`, `cult-datawraith-l18`, `cult-soul-reaper-l16`, `cult-skrilet-prime-l14`, `cyber-priest`, `boss-cyber-priest-prime` (+ призывы `cyber-demon`, `hologram`). **Новые 6** (`CS_ENEMIES`): `cs-glitch-hound`, `cs-ice-warden`, `cs-echo-wail`, `cs-leech-daemon`, `cs-null-walker`, `cs-judge-eye` (ур. 6–16, миниБосс). Враги масштабируются под героя (`scale: 'hero'`). 12 событий (`CS_EVENTS`) — выборы/проверки с последствиями. Награды: `cs-neuroport`, `cs-deck`, `cs-ice-pick`, `cs-ghost-key`, `cs-data-pearl`, `cs-null-patch`, `cs-echo-coil` (`CS_ITEMS`), осколки памяти, флаги зон, XP (`CS_RULES.xp` × ур./5).

## 7. Дух Киберспейса (SPIRIT)
**Триггеры** (тело уничтожено): смерть от урона ≥150% макс. ЗДР огнём/кислотой/прокси/кибером; разгром у ритуального терминала/Храма Приговора; провал побега при 2 Отметинах. Иначе — обычный эпизод (тело цело).
**Режим «Дух»** (`save.hero.spirit`, флаг `bodyDestroyed`): раса `cyber-spirit` (кибер resist, токсин immune, прокси vuln, скорость 6, ЗДР 50%). Ограничения: нет лавок, отдых только у терминала `ours`, перенос лута ×0.5, тяжёлая броня недоступна. Бонусы: вход в Сеть бесплатный, хакинг без таймера, `cyberspace-adv`. Зона Пустошь удалённых доступна только духу.
**Путь назад**: событие `cs-ev-new-body` в Пустоши → квест `sq-new-body` у Николы: протез за 400 кр + 2 `servo-parts` + 1 `soul-shard`; тело возвращается с 50% ЗДР/МРЛ, флаг `bodyDestroyed` снят. Остаться духом можно (`cs-stay-spirit`).
**Сцена духа**: экран Киберспейса, портрет героя с глитчем (§8), над ним плашка «ДУХ»; в `world` HUD — иконка `spirit` у портрета героя, подсказка «Тело уничтожено. Верни его у Николы».

## 8. Иконка / портрет «Дух киберспейса» (для art-director)
- **Иконка `spirit`** (`game/assets/icons/spirit.png`, 32×32 и 16×16 для `status-icons.js`): плоский светлый символ **цвета `h` (#70d8f2)** на тёмной скруглённой плитке **цвета `i` (#1c4a5a)**. Символ: силуэт головы/бюста в профиль, нижняя часть рассыпается в пиксели (квадраты 2 px, падающие вниз); глаза — яркая точка `5`; пара горизонтальных срезов-сдвигов (глитч) в `n` (#e04fa8) на 1 px — только как акцент, не больше 2 штук.
- **Портрет духа** (`drawHeroAvatar` + `opts.spirit`): тот же силуэт героя, прозрачность 0.7, тинт `h`, сканлайны через 3 px цветом `0`, каждые ~0.25 с случайный срез строки по горизонтали (сдвиг ±3 px) и 2 кадра-эха со смещением в `n`/`h`; нижняя треть — деградация в шум; глаза — тёмные ямы со светлой точкой `5`. Контур 1 px цвета `0`.
- **Кадры** (глитч-анимация): 3 кадра по 0.15 с — норма / срез / эхо. Размеры: 128 px (смерть-экран), 64 px (партия), 16 px (статус).
- Тон: жутко и смешно: дух выглядит так, будто его плохо сжали.

## 9. Критерии приёмки (qa-tester)
1. Смерть героя → Киберспейс: 3 узла из зон, показаны названия зон; успех при 2 из 3.
2. Нырок на `ours`-терминале даёт выбор зон; провал не ставит Отметину.
3. Взлом: граф ≥6 узлов, таймер/трассировка, провал при трассировке ≥6 запускает бой.
4. Взлом «цены» у `term-harmony` снижает цены на `alpha-harmony` на 5 дней (×0.85).
5. Тело уничтожено — иконка духа в HUD и ограничения (нет лавки); путь назад через `sq-new-body`.
6. `node tools/test.mjs` без ошибок; все id из `cyberspace.js` разрешаются.
