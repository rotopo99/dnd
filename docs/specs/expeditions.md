# Поручения резерву (экспедиции напарников)

> Владелец — game-designer. Данные: `game/src/data/world/expeditions.js`. Дата: 2026-11-08. Запрос: feedback 2026-11-07.
> Опирается на `world/companions.js` (`idleHome`, `canRejoin`, `sendToReserve`, `baseIdle`) и лояльность (`COMPANION_RULES`).

## 1. Цель для игрока
Резерв не простаивает: напарник вне отряда приносит лут, деньги, разведданные или закрывает мелкий квест, пока герой занят другим. Чувство: «у меня есть команда», но риск реален.

## 2. Правила
- Кто: напарник `state: 'waiting'` и лояльность выше «Остыл» (`minLoyalty −19`). Откуда: с узла `idleHome` (база, если открыта; иначе узел, где его оставили) — партия должна быть там же.
- Одновременно до `maxActive = 2` экспедиций. Во время неё напарник недоступен для отряда.
- Типы (`EXP_TYPES`): **Лут** (регион), **Торговля** (хаб региона, нужны вещи в рюкзаке напарника), **Разведка** узла (слухи, скрытые маршруты, метки опасности), **Простое поручение** (квест из `AUTOABLE_QUESTS` — 13 мелких density-квестов с одной проверкой; квест должен быть **принят**).
- Длительность: по типу `days [мин, макс]`, +1 день за каждый хоп до региона; считается в игровых днях (`passDays`).
- Режим: **осторожный** (награда ×0.6, риск −3, смерть невозможна) / обычный / **рискованный** (×1.4, +3).
- Проверка по возвращении: `d20 + мод. лучшего навыка типа (checkInfo) + ⌊(ур. напарника − ур. региона)/2⌋ + режим` против `СЛ = 8 + 2 × danger региона + 0.5 × дней`.
- Исход по `margin = бросок − СЛ`: ≥8 блестяще; ≥0 успех; −1…−4 частично; −5…−9 ранен; −10…−14 плен; ≤−15 погиб. nat 20 — на строку лучше, nat 1 — хуже. Плен возможен при danger ≥ 2, смерть — при danger ≥ 4 и не осторожном режиме; иначе исход заменяется на «ранен».
- Ранен: 2 дня недоступен, при возвращении ЗДР ×0.5. Плен: срок спасения 5 дней (боевой квест-освобождение в узле региона), потом «потерян». Погиб: как смерть напарника (возврат только по канону — терминал `ours`, существующая услуга `revive`).
- Лояльность: блестяще +3, успех +2, частично 0, ранен −3, плен −5, потерян при пленении −4 (`EXP_LOYALTY`).

## 3. Таблица исходов (числа — в данных `EXP_OUTCOMES`)
| Исход | margin | Награда | Лояльность | Состояние |
|---|---|---|---|---|
| Блестяще | ≥8 | ×1.5 | +3 | — |
| Успех | 0…7 | ×1.0 | +2 | — |
| Частично | −4…−1 | ×0.5 | 0 | — |
| Ранен | −9…−5 | нет | −3 | wounded, 2 дн. |
| Плен | −14…−10 | нет | −5 | captive, спасать 5 дн. |
| Погиб | ≤−15 | нет | — | dead (реанимация терминалом) |

## 4. Награды
Лут: `credits [30,80] + 8×ур.`, 2 броска таблицы `EXP_LOOT` по tier опасности. Торговля: цена проданного ×1.15, +1 реп. фракции хаба, шанс 15% редкого товара. Разведка: открывает скрытый узел/маршрут, слух, метку опасности, 30 XP. Поручение: награда квеста ×0.8. Опыт напарнику: доля `waitingShare`.

## 5. Состояния и события
`p.exp = { type, target, start, days, mode }` → по `save.day ≥ start+days` в `baseTick`/`passDays` разрешается проверка → `p.expResult` (показ при следующем заходе на узел `idleHome` модалом «Вернулся: …»). События: `expStart`, `expReturn`, `expCaptive`, `expLost`.

## 6. UI/фидбек
Окно «Напарники» → карточка резерва → кнопка «Отправить» (выбор типа, цели, режима; показ СЛ, шанса успеха, дней, риска; предупреждение «может погибнуть»). Иконка в портрете «в пути» (`exp` + дни). Тост при возврате, барк реплики. Звук `uiClick`/`buff`/`debuff`.

## 7. Критерии приёмки (qa-tester)
1. Отправка из резерва на базе: напарник уходит, нельзя взять в отряд до возвращения.
2. Через N дней результат по таблице; осторожный режим не даёт смерти.
3. Тип «Поручение» доступен только для принятых квестов из `AUTOABLE_QUESTS`, награда ×0.8.
4. При лояльности ≤ −20 кнопка серая с причиной.
5. Смерть/плен только при danger региона ≥ 4/≥ 2.
6. Тест `node tools/test.mjs` без ошибок, сохранение/загрузка сохраняет `p.exp`.

## 8. Вне рамок
Экспедиции вдвоём, снаряжение для миссий, события «в дороге» с выбором, сюжетные квесты, боёвка в экспедиции (кроме плена), автоповтор.

## Баланс (балансёру)
`EXP_DC`, `EXP_OUTCOMES.minMargin`, множители режима, `EXP_LOOT`, длительность, штрафы лояльности.
