# Свободное перемещение по узлам (free-roam)

Дата: 2026-11-08. Источник: docs/FEEDBACK-2026-11-07.md п. 6 («как Fallout 1–2»). Глобальная карта (`world-map.js`) не меняется.

## Цель для игрока
Узел — место, где ходишь сам: идёшь к торговцу, подкрадываешься к охране, лезешь в ящик, замечаешь выход. Чувство: «я в мире», а не «я в списке кнопок».

## Принципы
- Тот же тайловый язык, что у боя: `parseMap`, `T_*`, `terrain.js`, рендер тайлов из `battle-terrain.js`. Новый только слой «мир узла».
- Узел без карты остаётся меню-узлом (`location.js` не трогаем). Кнопка «Меню узла» на карте открывает его же — всегда.
- Все действия на карте вызывают существующие окна: диалог, лавка (`openShopHere`), сцены проверок, кража/нападение (`crime.js`), отдых, схрон. Правила не дублируются.
- Этапы независимо играбельны; флаг `FREE_ROAM` (по умолчанию выкл. до конца этапа 1).

## Этап 1. Хождение (без боя на карте)

### 1.1 Карта узла
Сцена `scenes/roam.js` (id `roam`), логика без DOM в `world/roam.js`. Выбор: у узла есть `data/maps/towns/<id>.js` → ручная; иначе генерация по `kind`/тегу; `kind: wild|sea|boss|terminal` — меню-узел (этап 1).

Размер: 40×30 тайлов (параметр, до 64×48). Тайл на экране 32 px (зум 24/32/40 колесом), камера следит за лидером с ограничением по краям, плавный сдвиг.

Формат `data/maps/towns/<locId>.js` (расширяет `parseMap`, старые символы те же):
```
export default {
  id: 'marta', name: '...', kind: 'camp', size: [40, 30],
  grid: [ '#####...' ×30 ],      // символы боя: # стена, . пол, c ящик-укрытие, ~ вода, D выход, 1/2 высота
  elev: null,
  spawn: { from: { 'world': [20, 28], 'bunker-lisa': [3, 5] } },  // точки входа по источнику
  objects: [ { id, type, x, y, ...} ],
  npcs:    [ { npc: 'id из npcsAt', x, y, route?: [[x,y]…], hours? } ],
  zones:   [ { id: 'market', rect: [x,y,w,h], faction?: 'f', restricted?: bool } ],
}
```
Типы объектов: `exit` {to: 'world'|locId, label}, `stall` {npc} (прилавок торговца: клик → лавка), `stash` {loot|id, dc?} (ящик/тайник, открывается один раз, флаг `roam:<loc>:<id>`), `terminal` {id} (существующие терминалы/цели `terminal`), `bed` {tier} (вызывает отдых по правилам `rest`, нужна услуга `rest` узла), `bench` (верстак: открывает «Разобрать»/моды), `door` {locked, dc} (взлом через `openCheck`), `sign` {text}. Объект блокирует клетку, если `solid`; взаимодействие — с соседней клетки (радиус 1,5).

Генерация (`world/roam-gen.js`, детерминированно: seed = `locId`): шаблон узла = рамка + набор **блоков** (прямоугольники 8×6…14×10 из `data/maps/blocks.js`: дом, лавка с прилавком, площадь, склад, казарма, забор с воротами, палатка, пирс, развалина, шлюз-коридор) расставляются по сетке с дорожками между ними, проверка связности (как в `arena.js`, ≤5 попыток), затем объекты из данных узла.

| Тип узла | Состав блоков | Выход(ы) | Особое |
|---|---|---|---|
| hub | площадь, 4–6 домов, лавки, казарма | 2–3 ворота | много NPC, бункер/схрон |
| деревня (town, нейтрал.) | 6–8 домов, колодец, поле | 1–2 ворот | NPC ходят |
| руины | 5–7 развалин (T_RUBBLE), завалы, ящики | 2 пролома | больше тайников |
| бункер (dungeon-hub) | шлюз, коридоры, 3–4 комнаты | 1 люк | много дверей/терминалов |
| лагерь (camp) | палатки по кругу, костёр, 1 ограда | 1 | малый, 28×22 |
| порт | пирс, склады, вода (T_WATER) | ворота + причал | лодка = выход |
| город фракции | стена, ворота-КПП (охрана), рынок, 2 района | КПП | зоны `restricted` |

Размеры по типу: лагерь 28×22, остальное 40×30, город фракции 48×36.

### 1.2 Движение
- ЛКМ по клетке: A* (`reachable`/`pathTo` с `stepCost` и `blocksMove`, 8 направлений, без срезания угла стен). WASD/стрелки — по клеткам со сглаживанием. Шift — бег/ходьба (в этапе 2 влияет на шум).
- Скорость: 4 клетки/с (ходьба), 6 (бег). Высоты и обломки замедляют ×0,6 как `stepCost`.
- Партия цепочкой: лидер + следование по трассе лидера, интервал 1 клетка; узкий проход — не застревают (последний телепортируется к лидеру при отставании >6). Напарники — по порядку отряда.
- Время: реальный ход, вне боя `game.time` идёт: 1 игровая минута за 2,5 с ходьбы (параметр), пауза в модалах и меню; сутки по правилам GDD «Время действия». Реальное время не должно сжигать эффекты, у которых счёт в днях.
- ПКМ по объекту/NPC — подсказка (тултип `tooltip.js`) без действия. Двойной клик — бег к цели.

### 1.3 Объекты и NPC
- NPC: берутся из `npcsAt(locId, save)` — **источник правды**; карта лишь задаёт позицию (`npcs[].x,y`), нет записи — автоматически рядом с прилавком/на площадь. Исчезновение NPC (`npcPlacement`, смерть) убирает его с карты.
- Торговец с профилем лавки стоит у `stall`, не ходит. Остальные: стоят или ходят по `route` (цикл, 1 клетка/с, паузы 3–8 с), в диалоге замирают. Убийство — снимается, как сейчас.
- Взаимодействие: клик по NPC/объекту или E рядом → путь до соседней клетки → окно. Для NPC — меню действий из `location.js` (Говорить, Лавка, Нанять, Украсть, Напасть), переиспользовать функцию-сборщик кнопок NPC, не копировать.
- Выход `exit` на `world`: подтверждение «Покинуть узел?» → глобальная карта. Выход в другой узел — вход со `spawn.from`.
- Квестовые события: `onArrive` вызывается при входе в узел как сейчас; цель `talk` — при диалоге; новое: подсвеченный маркер у NPC с квестом.
- Мини-HUD: имя узла, час, «Меню узла», «Партия/Журнал/Сохранить» (как в `location.js`), мини-карта 160×120 (этап 1 — по желанию).

## Этап 2. Бой на карте и скрытность

### 2.1 Бой
- Триггер: враг/враждебный NPC (из нападения, тревоги, `hunterEncounter`, события узла) видит партию в радиусе 10 клеток с линией видимости (`lineOfSight`) → «Бой!»: свободное время останавливается.
- Переход: вырезается область 24×16 с центром в среднем между партией и врагами (сдвиг, чтобы вписаться в границы карты; меньше — вся карта). Позиции юнитов — их текущие клетки; расстановка по `S` боя, как сейчас; враги из `ENCOUNTERS`/`guardEnemies`. Карта вырезки — копия тайлов узла (укрытия/высоты/вода работают как в бою).
- Объекты узла внутри области становятся боевыми `OBJECT_CHARS` (ящики — укрытия). NPC-мирные уходят из области/паникуют (прячутся в зону дома); торговцы не участвуют.
- После боя: вернуться в `roam` на то же место, позиции живых — как в бою, трупы остаются лутом (существующая добыча `world-battle.js`), охрана-победители не воскресают. Поражение — по текущим правилам.
- Нападение на NPC: действие «Напасть» → `attackSetup`, бой на карте здесь же; охрана в радиусе 12 клеток присоединяется (по `crime.js`).

### 2.2 Скрытность
- Режим «Красться» (Ctrl/C): скорость 2 кл/с; бросок скрытности не каждый кадр, а при попадании в конус.
- Конус зрения охраны: 90°, дальность 8 (день) / 5 (ночь), блокируется стенами и укрытиями; NPC-охрана смотрит по направлению движения или в заданную сторону (`facing`).
- Обнаружение: накапливаемая «заметность» 0–100 за секунду в конусе: ходьба +40/с, бег +80/с, крадёшься +15/с; снижение −20/с вне конуса. При 100 — тревога. Бросок Скрытность партии (лучшая броня-помеха из `checks.js`) модифицирует скорость накопления: успех проверки раз в 5 с в конусе = −50%.
- Кража у NPC: сзади/сбоку (вне конуса) — СЛ `theftDc` −2; видят — как сейчас, провал → розыск (`addHeat`).
- Тревога: зона `restricted` без разрешения → охрана идёт к партии, 15 с даётся уйти или заплатить штраф (`fineFor`), дальше бой. Тревога тоже поднимает `heat` по `crime.js`.

## Этап 3. Ручные карты и распорядок
- Ручные карты для 10 ключевых узлов (список утвердить с режиссёром — хабы с главными NPC: стартовые деревни, база, 2–3 города фракций, порт, Марта, бункер Лиса).
- Распорядок NPC: `hours` (например `[{h:[6,20], at:'stall'}, {h:[20,6], at:'bed'}]`), торговцы закрывают лавку ночью (прилавок пуст, запрет торговли, «Постучать» — проверка Убеждения), стража меняет смену, ночью конус короче.

## Сохранения
`save.roam = { loc, x, y, party: [[x,y]…], facing, t, opened: [objId], dead: [npcId] }`. Позиция партии пишется при выходе из сцены/автосейве. Нет `roam` или карта изменилась (нет клетки проходима) — ставим на `spawn`. Версия сейва +1, миграция — пустая запись. Лут/взломанное — флаги `roam:<loc>:<id>`. Время и NPC-маршруты не сохраняем (пересчёт от игровых часов). Карты не хранятся в сейве.

## Производительность
- Рендер только видимой части: ≈ (W/32)×(H/32) ≈ 40×23 = 920 тайлов; тайлы статичны — кэшировать в offscreen-canvas чанками 16×16 тайлов, перерисовывать только при изменении (дверь, ящик).
- Динамика (NPC, партия, конусы) — поверх, ≤ 60 сущностей; обновление NPC вне экрана — раз в 0,5 с.
- A*: поиск ≤ 1600 узлов; запрос не чаще раз в кадр; кэш пути к цели.
- Целевая частота 60 fps при 1280×720; бюджет update < 3 мс, render < 8 мс.
- Конусы считать лучами по 5° (≈18 лучей) лишь для ближних охранников (≤ 15 клеток).

## Критерии приёмки
1. Этап 1: узел с картой (сгенерированный) открывается из глобальной карты; клик по клетке ведёт партию цепочкой, WASD работает; нет ошибок консоли.
2. NPC из `npcsAt` присутствуют на карте, торговец у прилавка открывает лавку; убитый NPC или отсутствующий по `npcPlacement` не отображается.
3. Выход на карту возвращает на глобальную; «Меню узла» открывает прежнее меню с теми же действиями; узел без карты открывается как раньше.
4. Тайник открывается один раз (флаг), после перезагрузки/загрузки остаётся открытым; позиция партии после сохранения/загрузки совпадает.
5. Этап 2: появление врага в радиусе 10 с LOS переключает в пошаговый бой на вырезке той же карты; после победы партия возвращается на прежние клетки; кража сзади получает бонус СЛ −2, в конусе срабатывает обнаружение и тревога.
6. FPS ≥ 55 на 40×30 в плейтесте, рендер — не более ~1000 тайлов в кадр.

## Вне рамок
Мультиэтажность/лестницы; динамическое освещение; разрушаемая среда вне боя; погода; транспорт; порядок распорядка NPC для всех узлов (только 10 ключевых); полноценный стелс-бой с оглушением; редактор карт; изменение глобальной карты и маршрутов.

## Риски и вопросы режиссёру
1. Правило «время реальное» может сжигать сутки: нужен потолок (параметр) и пауза в диалогах.
2. Сколько ручных карт реально делать — решается в этапе 3 по сценарию.
3. Нужен ли `location.js` рефактор (вынести сборщик кнопок NPC) до этапа 1 — да, мелким PR.

## Решения режиссёра (2026-11-08)
1. Ручные карты (этап 3): 10 узлов с наибольшим числом квестов/NPC — выбирает программист скриптом по данным (квесты+NPC+торговцы), обязательно: хаб Альфа-Гармонии, Райцентр (Хатаб-Сити), Дача Галины/бункер, Жестяная арена (tin-arena).
2. Реальное время в узле дней не тратит вообще (время идёт только в пути и на отдыхе, как сейчас).
3. Да: перед этапом 1 вынести сборщик кнопок/действий NPC из location.js в отдельный модуль (world/npc-actions.js), чтобы его использовали и меню-узел, и свободная карта.
