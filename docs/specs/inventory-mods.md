# Спека: инвентарь-сетка, разгрузка, моды, вторая рука (v7)
Дата: 2026-11-07. Источник: FEEDBACK-2026-11-07 («Поток просьб»). Данные: `game/src/data/items/mods.js` (75 модов, +47), `items/offhand.js` (8 предметов), дополнения в `vendors.js`, `loot.js`. Движок и сцены этой спекой не меняются, это ТЗ для программиста.

## Цель для игрока
Рюкзак как в Quasimorph: тетрис из вещей, на который жалко места, и разгрузка с гранатами под клавишами 1–6, чтобы бросить гранату, не лезя в меню. Моды видны на карточке предмета и ставятся перетаскиванием: чувство «собрал свой ствол». Щит — реальный предмет второй руки, и понятно, как его надеть.

## 1. Сетка рюкзака
**Решение:** у каждого героя и компаньона свой рюкзак и разгрузка (`equipment` уже личный); плюс общий схрон (вместимость 10×12) в узлах-хабах/лагере/бункере, доступен только там; «Передать» между членами партии — перетаскиванием на портрет в панели. Вес не вводим.

Размер: поле `size: [w, h]`; если нет — выводится по таблице, поле переопределяет.

| Категория / тип | w×h |
|---|---|
| Нож, кулак, кастет, метательное | 1×2 |
| Пистолет, ПП | 2×1 |
| Меч, сабля, катана, топор, молот | 1×3 |
| Древковое, двуручное, полуторное | 1×4 |
| Винтовка, автомат, арбалет, лук, энерго, плазма, лазер | 4×1 (мельта, гранатомёт, пулемёт 4×2) |
| Броня: ткань 2×2, лёгкая 2×3, средняя 3×3, тяжёлая 3×4, мех 4×5 | |
| Вторая рука | `size` в данных (щиты 2×2…3×4, пистолет 2×1, нож 1×2) |
| Мод | 1×1 (тир 4–5 — 1×2) |
| Расходник/граната/стим/ловушка | 1×1; стак до `stack` в одной клетке; ловушка и щит-кейс 2×1 |
| Еда, патроны, детали | 1×1 |
| Квестовое/реликвия | 1×1 (оружие-реликт по типу) |

Поворот: R или ПКМ при переносе (w↔h). Вместимость: базовый «карманы» 6×4; рюкзак — предмет в слоте «Рюкзак» (отдельный слот снаряжения), 4 штуки:

| Рюкзак | Сетка | Тир | Цена |
|---|---|---|---|
| Авоська | 6×5 | 1 | 20 |
| Армейский вещмешок | 7×6 | 2 | 90 |
| Туристический станковый | 8×7 | 3 | 220 |
| Тактический «Лис» (реликт) | 9×8, +1 быстрый слот | 5 | 0 |

Без рюкзака — карманы 6×4. Переполнение лута: предмет не влез — подсветка красным, окно «Добыча» предлагает выбросить/заменить; предметы подбираются автоматически в схрон при выходе из узла нельзя (теряются только по явному решению).

## 2. Разгрузка (быстрые слоты)
| Источник | Слотов |
|---|---|
| Без разгрузки | 2 |
| Жилет-разгрузка (новый предмет брони-аксессуара) / любая броня light–medium | 4 |
| Тяжёлая броня, мех | 3 |
| Мод «Карманы на липучке» (`quick: 1`) | +1 |
| Рюкзак «Лис» | +1 |
Максимум 6. В слот кладутся только расходники (`cat consumable`), гранаты, ловушки, патроны; оружие/броня/моды не кладутся. Слот хранит стак (до `stack`).

Бой: клавиши 1–6 → предмет слота; граната/ловушка сразу входят в режим выбора клетки с превью зоны (как «Предметы», I); цена действия — как сейчас (`it.action` из data: action/bonus). Рюкзак в бою: **разрешено «Порыться в рюкзаке» = полное действие**, перекладывает 1 предмет из рюкзака в свободный быстрый слот (или меняет местами) без использования. Обоснование: запрет делает бой унылым при нехватке слотов; бесплатность обесценивает разгрузку; полное действие — осмысленная цена, как в Quasimorph. Использовать прямо из рюкзака в бою нельзя. Меню «Предметы» (I) остаётся, показывает только быстрые слоты.

## 3. Моды
### 3.1 Слоты
У оружия: огнестрел — optic, muzzle, mag, grip; холодное — edge, grip; энерго/прокси/кринж — optic, core, grip. У брони: plate, lining, sole. Число слотов по качеству (QUALITY.slots): Хлам 1, Рабочее 2, Мастеровое 3, Реликт — как в данных; тяжёлая броня и мех +1 plate. Один мод на тип слота. Сейчас движок знает слоты как «один на modSlot» — число слотов на предмет (`slots` по `quality`) ограничивает общее количество вставленных модов.

### 3.2 Установка
Вне боя: перетащить мод из рюкзака на пустой слот карточки (подсветка допустимых слотов зелёным по `fits`, недопустимых — красным с причиной в подсказке). Снятие: перетащить обратно в рюкзак (бесплатно); при `req` — проверка навыка. Требование `req {skill, dc, tool?}`: бросок Технологий СЛ `dc`, лучший в партии (`autoCheck`); инструмент `tool` — предмет в рюкзаке (не расходуется, ремнабор тратит 1 заряд). Провал: мод не вставлен, 25% что сломан (хлам-мод — удаляется). Без `req` — автоматически.

### 3.3 Разборка предмета на моды
Кнопка «Разобрать» на карточке (ПКМ в схроне/хабе): Технологии СЛ = `disassembleDc` (10 + тир). Успех: все вставленные моды возвращаются + `servo-parts` (`disassembleParts`). Провал: моды возвращаются, предмет теряется. Хлам и мастеровое — 1 дополнительный шанс 50% получить мод из таблицы фракции предмета.

### 3.4 Новые поля мода (для программиста; движок их пока не читает)
| Поле | Тип | Смысл |
|---|---|---|
| `surfaceOnHit` | `{kind, size, turns, on: 'hit'\|'crit'}` | при попадании/крите создаёт поверхность через `createSurface` (kind из `data/surfaces.js`) |
| `immuneSurface` | `[kind]` | поверхности носитель игнорирует (нет урона, статусов, штрафа ИИ `surfaceHarm`) |
| `immuneStatus` | `[id]` | уже было; статусы из `effects.js` |
| `onHit` с `chance`, `save` | как в оружии | в `add` обычных статусов (`burn, shocked, chilled, acid, poison, dazed, oiled, prone, bleed`) |
| `speed` | число | +/− клеток скорости |
| `quick` | число | +N быстрых слотов |
| `thorns` | `{dice, dmgType}` | пассивка `thorns` брони |
| `ignoreSmoke` | bool | дым/пар не дают помеху стрелку |
| `req` | `{skill, dc, tool?}` | см. 3.2 |
| `enr: -1` | число | уже суммируется; не ниже 0 |
Рецепты: oil-mag/oiled-edge (oiled) + incendiary/thermal (burn/fire) = пожар; shock-edge/mag (shocked) по wet/water — электролужа; cryo + water = лёд; фракции: Партия (aiParty) — электро/холод, Военпром — бронебой/оптика, Техоньки — прокси, Рейнджеры/Отступники — огонь, Механиды — смазка и ток, Агрозона — кислота/газ, Кринжгоны — кринж.

### 3.5 Распределение
Торговцы: только добавлены id в тир-списки архетипов `gunsmith, bladesmith, armorer, techmod, cyber, junk, fence, general, hunter` (+ `sig` у `gunsmith-kalibr` (thermal-scope), `stn-tranzistor` (proxy-resonator), `archivist-nine` (hover-pads)). Лут: таблицы 14 фракций и мест (`dungeons`, `lis-vault`) получили моды и вторую руку. Тир 4–5 — только у Л/кибер-торговцев и в бункерах.

## 4. UI
Экран «Снаряжение» (`panel-gear.js`), 1280×720: слева портрет и слоты — оружие, вторая рука, броня, рюкзак; под ними разгрузка (1–6, номера на слотах). Центр — сетка рюкзака (клетка 36 px, подсветка размера переносимого предмета, красный = не влезает). Справа — карточка выбранного предмета: заголовок, `size`, числа, под ними ряд слотов модов (иконки, пустые — контур с названием слота), `req`-метка замка, кнопки «Разобрать», «Передать». Перетаскивание: ЛКМ зажать — несёт, отпустить на слот/клетку; R — поворот; ПКМ по предмету — меню (надеть, в разгрузку, разобрать); Shift+ЛКМ — быстро в первый подходящий слот. Подсказка при наведении — `itemTip` (+ строка «Слоты: 2/3», «Подходит: …»); при переносе на слот — «Если надеть» (дельта КБ/урона/шанса) как сейчас в сравнении. Сравнение с надетым — по Alt.

## 5. Миграция сейвов
`normalizeSave`: если у героя/члена партии нет `grid`, авто-раскладка `hero.items` (id→count): сортировка по площади убыв., первая-подходящая позиция (слева-направо, сверху-вниз, без поворота, потом с поворотом); не влезло — в общий схрон (`save.stash`). Расходники → 2–4 в разгрузку (гранаты первыми). Надетое остаётся в `equipment`. Вставленные моды и `slots` — как были (лишние сверх лимита слотов остаются, но новые не ставятся). `save.v` поднять, откат невозможен.

### 6.2 Как видно
Слот «Вторая рука» всегда на экране справа от «Оружие» с контуром щита и подписью. Пустой — подсказка «Щит, пистолет, нож или фонарь». Хотя бы одна вещь в рюкзаке, подходящая в слот, подсвечивает слот мягкой пульсацией при открытии экрана. Карточка щита: строка «Вторая рука», КБ крупно.

### 6.3 Как надевать
Перетащить предмет на слот (или Shift+ЛКМ, или ПКМ → «Надеть во вторую руку»). Старый предмет возвращается в рюкзак. Двуручное оружие (`twoHanded`) блокирует слот: слот затемнён, замок и подпись «Занят двуручным: <имя>»; перетаскивание предмета туда — красная подсветка и подсказка «Снимите двуручное или возьмите одноручное»; надеть двуручное при занятой руке — снимает предмет второй руки в рюкзак с тостом «Вторая рука освобождена». Если не влезло в рюкзак — отказ.

### 6.4 Взаимодействия
Щит +КБ суммируется с бронёй (ЛВК-кап брони сохраняется, щит КБ — вне капа); `req` не выполнен — скорость −2 и помеха на атаки (как у брони).

## Критерии приёмки
1. Все 75 модов и 8 предметов второй руки находятся в `ITEMS`; `node tools/test.mjs` без ошибок; у каждого мода `fits` корректен.
2. Старый сейв после загрузки: все предметы раскладываются в сетку без пересечений, лишние — в схрон.
3. Предмет не влезает → нельзя бросить в сетку; поворот R меняет w↔h.
4. Клавиши 1–6 в бою используют предмет разгрузки, гранаты — с превью зоны; «Порыться» тратит полное действие; из рюкзака напрямую использовать нельзя.
5. Мод с `req` и слот: провал проверки не вставляет мод; тултип показывает причину.
6. Щит надевается перетаскиванием, двуручное блокирует слот с понятной подписью, КБ меняется на значение из таблицы.
