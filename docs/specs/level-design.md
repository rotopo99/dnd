# Спека: левел-дизайн в духе Divinity

Дата: 2026-11-15. Часть `metric-combat.md` (раздел 7). Основа: `battlefields.md` (шаблоны `TEMPLATES`, `BOSS_ARENAS`, `data/maps/fields/layouts.js`), `3d.md`, `free-roam.md`. Код не затронут.

## Цель для игрока
Бой происходит в месте, которое имеет смысл: засада на мосту, оборона баррикады у ворот, перестрелка на крыше склада. Игрок читает местность, ищет обходы, пользуется окружением и находит секреты. Чувство: «я в мире», а не «на арене».

## Правила

### 7.1 Принципы
| Принцип | Норма |
|---|---|
| Ручная или полуручная сцена | Все ключевые бои — авторские карты; процедурка остаётся только для случайных встреч, но собирается из ручных «кусков» (модулей 6×6 м–12×12 м), а не из блоков-клеток |
| Вертикаль | ≥ 3 уровня высоты на карте (0 / 0.5 / 1.0 м, крыши 2.0 м): лестницы, рампы, крыши, мосты, обрывы (падение = урон `1d6` за 1.5 м, не смертельно) |
| Несколько путей | Минимум 3 способа добраться до цели: прямой, обход (фланг), вертикаль (крыша/мост), хотя бы один скрытый (люк, подкоп, вентиляция — за навыком) |
| Интерактив | ≥ 4 типа на карту: бочки, рычаги, двери (заперта/заклинена), ловушки, разрушаемые стены, поверхности (масло, вода, кислота) |
| Повествование среды | 3–5 «читаемых» мест: записка, следы, труп, граффити, терминал. Тексты ≤ 140 символов, пишут в кодекс (`codex.js`, `markTerm`) |
| Секреты | 1–2 тайника на карту: проверка навыка (Внимание/Взлом/Следопыт/Акробатика), награда — предмет/кредиты/кодекс |
| Точки интереса | Каждые 15–20 м хода — «зацепка»: укрытие с видом, интерактив или нарратив; пустой отрезок > 20 м запрещён |
| Бой встроен в место | Каждая карта имеет `scenario`: засада (враги в укрытиях, герои в узком месте), оборона (волны к точке), штурм (враги укреплены, есть обходы), дуэль (босс на арене с механикой) |
| Масштаб | Арена боя 36–60 м по длинной стороне; 6–10 юнитов с каждой стороны (учитывать метрику 1.5 м) |

### 7.2 Формат данных ручных карт (`data/maps/handmade/<id>.js`)
ASCII остаётся для общей формы (быстрый авторинг), JSON — для всего остального. Загрузчик `loadHandmade(def)` превращает в геометрию `b.geo` (метрический движок) и в совместимую сетку `tiles/elev` (этап 1, старый код).
```
{
  id, name, biome, scale: 1.5,            // метров на ASCII-клетку
  ascii: { floor: [...], elev: [...], objs: [...] },   // три слоя строк
  layers: [{ id:'ground', h:0 }, { id:'roof', h:2.0, mask:[...] }],
  geometry: [                                          // поверх ASCII
    { type:'wall'|'low'|'rail'|'rect'|'poly', pts:[[x,z]...], h, mat },
    { type:'ramp'|'stairs', from:[x,z], to:[x,z], w, layers:['ground','roof'] },
    { type:'bridge', pts, w, h, breakable? },
    { type:'cliff', pts, drop }
  ],
  props: [{ id, x, z, rot, hp?, tags:[] }],            // реквизит и интерактив (props.js)
  surfaces: [{ layer:'oil', shape:'circle'|'poly', c|pts, r }],
  zones: [{ id, shape, tag:'spawn:P'|'spawn:E'|'objective'|'noSpawn'|'alarm', ... }],
  interact: [{ id, kind:'lever'|'door'|'hatch'|'terminal'|'note'|'trap'|'secret',
               at:[x,z], req?:{skill, dc}|{key}|{item}, text?, codex?:'id', onUse:[ops] }],
  triggers: [{ id, when:{event:'enter'|'turn'|'death'|'use'|'hp', ...}, if?:{flag}, do:[ops], once:true }],
  scenario: { kind, waves?, win, lose, intro, brief },
  poi: [{ at, kind }]                                   // для проверки плотности точек интереса
}
```
Операции `do[]` (минимальный набор): `spawn{unit,at}`, `open/close{door}`, `collapse{geometry}` (разрушение моста/стены), `surface{layer,shape}`, `damage{zone,dice}`, `toast{text}`, `flag{set}`, `log{text}`, `codex{id}`, `reveal{secret}`, `alarm{}`. Скриптов-кода нет — только данные: безопасно для кооп-детерминизма (все операции на сервере хоста).

### 7.3 Инструменты
1. Этап A (дёшево): ASCII + JSON в одном файле, валидатор `tools/validate-maps.mjs` проверяет: связность 3 путей, плотность POI (≤ 20 м между), число слоёв/интерактивов, достижимость стартов, подбор секретов, тексты ≤ 140 символов.
2. Этап B: простой редактор в браузере `game/editor.html` (для нас, не для игрока): пол/высота кистью, расстановка реквизита и триггеров, вид 3D/2D, экспорт JSON. Без зависимостей, на `gfx/` и `camera.pick`; сохранение через скачивание файла.
3. Этап C: полуручная генерация — «модули» (комната, мост, баррикада, двор, крыша) расставляются генератором по `scenario`, каждый — ручной файл.

### 7.5 Стыковка
- Метрическое движение: ручная геометрия — первичный источник; ASCII → прямоугольники (этап 3 `metric-combat`). Этап 1: загрузчик отдаёт и сетку, и геометрию. Навсетка 0.5 м строится из `geometry`; рампы/лестницы — отрезки перехода слоёв; мосты — проходимая полоса над обрывом (ломаемая — триггер `collapse` перестраивает навсетку локально).
- LOS/укрытия: `rail/low` — половинное укрытие, `wall` — полное; крыши блокируют LOS снизу.
- 3D-рендер: `geometry` → меши (как стены сейчас), `layers` — отдельные чанки, cutaway по слою (крыша срезается, если над ней нет юнитов героя — раздел «Обзор» `metric-combat.md`). Реквизит — `props3d`, поверхности — плоские меши.
- 2D-режим: слои рисуются со смещением, высота — подписью `h`; редактор показывает оба.
- Кооп: триггеры и интерактив выполняет хост, остальным уходят события (детерминизм не ломается).
- Случайные встречи: `templateFor` продолжает работать, но берёт ручные модули.

## Состояния и события
`b.geo`, `b.layers`, `b.interact`, `b.triggers`; `flags` боя. События: `trigger:fire {id}`, `interact:use {id, unit}`, `geo:collapse {id}`, `secret:found {id}`, `codex:note {id}`.

## UI и фидбек
Интерактив подсвечивается контуром при наведении (как в Divinity: пунктир + значок), подсказка с навыком/СЛ и шансом; секреты появляются только при проверке (значок «?» на подозрительных местах после успеха Внимания); записки открываются текстом в окне 1–3 строки + запись в кодекс; обвал/рычаг — камера плавно на событие 0.6 с, звук.

## Критерии приёмки
1. Формат читается загрузчиком; валидатор падает на карте без трёх путей / с POI-разрывом > 20 м.
2. Два образца (мост-засада, баррикада) проходятся тремя способами (в лоб, фланг, вертикаль), в каждом есть секрет за навыком и записка в кодексе.
3. Триггер `collapse` убирает мост из навсетки, юниты на нём падают с уроном.
4. Рендер: слои высоты, крыша срезается при cutaway; 2D и 3D показывают одну геометрию.
5. Кооп: ход интерактива даёт одинаковый результат у хоста и гостя.
6. Контент: список 10 узлов и 6 боссов утверждён режиссёром; для каждого есть бриф `scenario`.

## Вне рамок
Редактор для игроков, моды, процедурные подземелья, синематики, скриптовый язык, динамическая вода/физика обвалов (только фиксированные триггеры), озвучка записок.
