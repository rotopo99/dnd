# Романы (спека, 2026-11-08; п. 8 FEEDBACK-2026-11-07)
Данные: `game/src/data/romance.js` (`ROMANCE_RULES`, `ROMANCE[id]`, `ROMANCE_CONFLICTS`, `ROMANCE_EVENTS`, `romanceStage`, `romanceEpilogueKey`). Код сцен не тронут.

## Цель для игрока
Тёплая, серьёзная линия поверх кринж-мира: напарник становится близким человеком, а не бонусом к статам. Чувство: «мне есть за кого возвращаться» — и цена, если не вернуться. Без откровенного: максимум поцелуй, «утро после» — затемнение/записка. Все персонажи взрослые, всё по согласию (отказ возможен, повтор в тот же день блокируется).

## Правила (числа — `ROMANCE_RULES`, крутит balance-tester)
Близость `bond` 0–100, отдельно от лояльности. Этапы: Знакомство 0, Интерес 15, Флирт 30, Свидания 45, Отношения 70, Кризис 85.
| источник | Δ | лимит |
|---|---|---|
| флирт «Поговорить наедине» (успех/провал) | +3 / −1 | раз в день на напарника; проверка Харизмы/темы, СЛ 12 +1 за повтор, макс 17 |
| подарок по вкусу / любой | +4 / +1 | раз в день |
| этап / завершение личного квеста | +4 / +10 | |
| бой без падения партнёра | +1 | ≤2 в день |
| решение по likes / dislikes | +3 / −4 | |
| выбор внутри свидания | −2…+4 | |
| привал в партии | +1 | |
| ожидание на базе | −1 / 3 дня | |
Свидания (3 на роман, по порядку, раз на сцену): №1 bond ≥15 и лояльность ≥20; №2 ≥40 / ≥30, через ≥2 дня; №3 ≥60 / ≥40, через ≥2 дня (после №3 — «Отношения»). Место — привал (camp) или база (base), как в данных. Кризис: bond ≥80, 3 свидания, личный квест закрыт; выбор ставит флаги `rf` для эпилога. Отказ от свидания −3.
Ревность: bond ≥30 с двумя → сцена `ROMANCE_CONFLICTS` (раз на пару): выбор партнёра (флаг `rom-pick-*`) или «время» (−3); проигравший −6 bond, −3 лояльности. Личные реплики ревности — `jealousy` у каждого.
Смерть партнёра (bond ≥45, умер в бою/не поднят): сцена `farewell`, трек tragic, траур 1 день (−1 к проверкам Харизмы). Разрыв: «Расстаться» / кризис-выбор −8 / bond <25 после «Отношений»: сцена `breakup`, tragic, bond −30, лояльность −10; партнёр остаётся, если лояльность ≥ −19.
Эпилог (`romanceEpilogueKey`): tragedy (погиб) / parted (разрыв или bond <70) / together; 3 слайда на исход в `epilogue`, вписывать в `epilogueSlides`.

## Состояния и события
`save.romance[id] = {bond, stage, dates:[id…], talkDay, giftDay, crisis:flag, lost, broken}`; события: флирт, подарок, бой, квест, свидание, кризис, ревность, смерть, разрыв, финал.

## Музыка (`audio/music.js`)
`romance` (сейчас ALIAS → town): сцены свиданий, кризис, эпилоги together/parted. `tragic` (ALIAS → menu): farewell, breakup, эпилог tragedy. После сцены — возврат к прежнему треку. Файлы mp3 необязательны.

## UI/фидбек
- Значок ♥ на карточке напарника в партнёрстве; пустое ♡ при bond ≥15. Тост «Близость +N».
- «Партия»: шкала «Близость» (цвет mrl) с этапом и подсказкой «следующее: свидание №N (bond X, лояльность Y)».
- Кнопка «Поговорить наедине» — на привале и в базе у карточки напарника: список тем (`taste.flirtTopics`/`flirt[]`), «Пригласить на свидание» (если открыто), «Расстаться» (с подтверждением).
- Свидание: полноэкранный диалог (диалоговая сцена), 6–8 реплик с 2–3 выборами, портрет напарника.
- Реплики в отношениях — `barks.romance`/`hurt`, `partyBarks`.

## Критерии приёмки
1. Все 18 свиданий открываются по порядку и только при выполнении ворот (bond, лояльность, интервал); повторное нельзя.
2. Флирт: раз в день на напарника; при провале bond −1, не уходит ниже 0.
3. С двумя bond ≥30 один раз показывается конфликт; выбор ставит флаг, второй роман не растёт.
4. Смерть партнёра → сцена farewell под tragic, затем возврат трека.
5. Эпилог выбирает верный исход из 3, по флагам кризиса.
6. Сейв/загрузка сохраняют `save.romance`.
