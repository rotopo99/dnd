# Навыки v3: системное применение

> Дата: 2026-11-08. Владелец: game-designer. Запрос человека (3-й раз): «очень много навыков не пригождается». Аудит — `docs/qa/SKILLS-AUDIT-v3.md`. Канон не менять: 20 навыков `stats-skills.md`.

## Цель для игрока
В каждом узле видно, где пригодится навык партии (значок), и есть кнопка действия. «Мой навык что-то решил» — не только в квесте. Чувство: «хорошо, что взял Медицину».

## Правила
Данные: `game/src/data/world/node-skill-actions.js` (`NODE_SKILL_ACTIONS` — 100 действий, `BATTLE_SKILL_TRICKS` — 7 приёмов), `skill-hints.js` (`NODE_HINTS`, `NPC_HINTS`). Числа:

| Параметр | Значение |
|---|---|
| СЛ действий | 10–15 (общие по типу узла 11–14, особые 14–15) |
| Бросает | лучший член партии (`autoCheck`), как N5; окно `openCheck` — по желанию (кнопка «Выбрать»), крит/провал — как в `check-run.js outcomeKey` |
| `once` | `node` (по умолчанию) — раз на узел; `day` — раз в игровой день на узел; `game` — раз на мир |
| Флаги выполнения | `nsa:<id>` / `nsa:<id>@<node>` / `nsa:<id>@<node>:<день>` |
| Fx | hp, mrl, party, days, rep, repLocal (фракция узла `locFaction`), credits (±), items, removeItems, flags, xp (плоский, масштабировать `×(1 + уровень/10)`) |
| Провал | всегда есть цена (ЗДР 1–4 / МРЛ 1–4 / кредиты / репутация / день), ни одного смертельного |
| Крит 20 | успех ×1.5 к credits и xp; крит 1 — цена ×1.5 |
| Приёмы боя | бонусное действие, раз за бой на юнита на навык, d20 + навык против `dc` + ур. врага ÷ 2 (как N6) |

## Подключение (программист)
1. **Сборщик** `world/node-actions.js` (по образцу `npc-actions.js`, без DOM): `skillActionsAt(save, game, locId, loc)` → список `{id, skill, dc, label, text, hint, done, best}`: фильтр по `node === locId` (через `sameLocation`) или `nodeType === loc.kind`; `needs` проверить `requiresOk`; `done` — по флагу `once`. Исполнение `runSkillAction(game, a, {rng})`: бросок через `autoCheck` → текст `a.text` + `success/fail.text` → `applyFx` (`check-run.js`; добавить `repLocal` и плоский `xp`) → флаг → `saveGame`.
2. **Узел-меню** (`scenes/location.js`): под действиями NPC вторая группа «Навыки» (`flowButtons`), подпись `label`, справа бейдж навыка; выполненные — серые, подсказка «сделано».
3. **Свободная карта** (`scenes/roam.js`): те же кнопки в нижней панели (общий сборщик, как `createNpcActions`).
4. **Бой** (`scenes/battle.js openTricks`): добавить `BATTLE_SKILL_TRICKS` к списку навыков; цели — `foe` (кроме `isHiddenFoe`), `foeNoDeaf` (`listens(enemyId)` из `skill-uses.js`), `foeHidden` (`isHiddenFoe`), `ally`, `self`. Операции: `op.status`+`turns` → `combat.applyStatus`, `op.cleanse` → `applyOp({op:'cleanse', ids})`; `op.reveal` — новая мелкая операция «снять скрытность» (флаг, который читает `isHiddenFoe`); `maxLevelDelta` — отсекать врагов выше героя на N. Подписи/ключи `trick.<skill>` в `text/`.
5. **hintSkills**: `hintSkillsOf(nodeId)` = `NODE_HINTS[node]` ∪ навыки доступных действий узла ∪ навыки тайников/`entry` узла (не более 3, порядок: свой список, действия, тайники); `NPC_HINTS[npcId]` — значки на карточке NPC и в диалоге. У тем диалога можно ставить поле `hintSkills: [skill]` (тот же формат, значок рядом с кнопкой темы). Значок (`drawIcon` навыка или буква) цвета владения: есть в партии — яркий, нет — тусклый; подсказка «Здесь пригодится: Навык (есть у: имя)».

## Состояния и события
Выполнение действия: бросок → исход → Fx → флаг. Событие `queueBark('check')` для напарников, чей навык сработал. Записи в журнал: «Навык: <label> — успех/провал».

## UI/фидбек
Бейдж навыка на кнопке; тост «+N кредитов / предмет» через `grant`; звук `buff` на успех, `miss` на провал (как приёмы боя). Строка в подсказке навыка `newUsesLine` (панели): «Теперь работает: N действий в узлах».

## Критерии приёмки
1. В узле типа `town` видны кнопки навыковых действий (не менее 5 общих по всем навыкам); после выполнения кнопка серая, сохраняется после загрузки.
2. Повторный клик по `once: 'day'` в тот же день недоступен; на следующий день доступен.
3. Провал даёт цену из данных, успех — награду; предметы попадают в рюкзак (`giveItem`), `repLocal` меняет репутацию фракции узла.
4. В бою у героя доступны приёмы всех 20 навыков; приём «Заметить засаду» недоступен, если нет скрытых врагов; «Урезонить» недоступен против «глухих».
5. В узлах из `NODE_HINTS` и у NPC из `NPC_HINTS` виден значок; `node tools/check-skill-data.mjs` выдаёт OK.

## Вне рамок
Новые навыки и характеристики; переделка квестовых проверок с 4+ навыками; новые ивенты; значки в диалогах всех NPC; награды за серию действий.
