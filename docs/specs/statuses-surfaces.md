# Спека: статусы и поверхности (Этап B)

Дата: 2026-11-07. Запрос человека: «статусные эффекты побольше с описанием и влиянием на процесс, создание поверхностей типа огня, тока и т. п.» (как в Divinity). Пункты 33–34 `docs/FEEDBACK-2026-11-07.md`.
Код: статусы — `data/effects.js` (схема `mods/tick/endSave/...` уже есть), движок — `rules/combat.js` (`applyStatus`, `b.zones`, `hazardEnter`, `trapCheck`), `rules/grid.js`, `rules/ai.js`.

## 1. Цель для игрока
Поле боя «живое»: клетка под ногами — часть тактики. Поджечь масло, загнать врага в электролужу, потушить себя в воде, не встать в кислоту. Каждый статус читается с первого взгляда: иконка, цвет, одна строка подсказки, число раундов.

## 2. Общие правила

| Параметр | Значение |
|---|---|
| Масштаб урона тика | `tier(L) = 1 + ⌊(L−1)/5⌋` (ур. 1–5 → ×1, 6–10 → ×2, 11–15 → ×3, 16–20 → ×4); тик = базовая кость × `tier`, L = уровень источника (наложившего/создавшего), для окружения без источника — уровень боя. Итог ≈ 0.45–0.5 удара того же уровня (удар ≈ 1.5·L из `levels-20.md`) |
| Стак статуса | тот же id не стакается: обновляется длительность до большей, источник — последний |
| Поверхность на клетке | не более 1 слоя + 1 «газ» (дым/токсин-газ); новая поверхность либо комбинируется (раздел 4), либо заменяет, если не указано иное |
| Тики статусов | в начале хода носителя (как сейчас); тики поверхностей: вход (шаг, толчок, телепорт), начало хода на клетке; не чаще 1 раза за ход на 1 клетку и 1 раз на вид урона |
| Длительность поверхностей | в раундах, −1 в `roundStart`; 0 → исчезает (событие `surfaceEnd`) |
| Размер | по области способности/гранаты (радиус R клеток); стены и препятствия не заполняются; поверхность не создаётся под юнитом «в воздухе» (нет таких) |
| Безопасный проход | `grantSafePassage` (Акробатика) игнорирует урон поверхностей, но не статусы-ловушки (липкое: вода/масло/лёд всё равно действуют) |
| Теги существ | `mechanical`, `organic`, `digital`, `hybrid` (есть в данных); добавить тег `plant` мутантам-растениям (`mutants-r`) и `proxy` техонькам |
| Фобии | `PHOBIA_COMBAT_TRIGGERS`: урон поверхности ставит соответствующий тип (`fire`, `electric`, `toxin`...), как обычный |

### Существующие статусы (не меняются, кроме отмеченных)
`stun, bleed, poison, burn, fear, slow, blind, root, silence, disarm, curse, prone, invisible, stealth, cringed, corrosion, hallucination, dazed, regen, inspired, blessed, haste, berserk, taunt, marked, fortified`. Изменения:

| id | Что меняется |
|---|---|
| `burn` | тик `1d6 × tier`; гасится: действие, вход в воду/лёд-воду/кровь-лужу нет (только вода), статус `wet` (раздел 3); длительность по умолчанию 3 раунда (раньше без лимита у источников) |
| `bleed` | на клетке остаётся `blood` (поверхность) раз в 2 хода носителя; тик `1d4 × tier` |
| `poison` | тик `1d4 × tier`; сопротивление: `plant` и `mutants` — тик ×0.5 |
| `blind` | в подсказке причина «дым/вспышка/свет»; не стакается с `choking` |
| `slow` | `speedMul 0.5`, −2 init (как есть); `chilled` усиливает до `frozen` |
| `corrosion` | поверхность `acid` ставит его (раздел 3) |

## 5. Таблица комбинаций

Срабатывает в момент, когда на клетку (или в область поверхности) попадает второй элемент (способность, горящий юнит, попавший в зону). Результат применяется к пересекающимся клеткам; цепная реакция — на соседние клетки той же поверхности (разные клетки с поверхностью `oil`/`toxgas` загораются волной 1 клетка/шаг в начале раунда, цепочка ограничена 12 клетками за раунд).

| А + Б | Результат |
|---|---|
| `water` + `electric` | **Электролужа**: ток расходится на ВСЮ связную лужу воды; урон/`shocked` каждому в воде (с `wet` +50%); `water` сохраняется 1 р., затем электричество исчезает через 3 р. |
| `blood` + `electric` | как `water` + `electric`, но площадь только 1 клетка вокруг крови |
| `oil` + `fire` | **Пожар**: масло превращается в `fire` на все клетки лужи за 1 раунд (волной), +1d6×tier урона огнём при воспламенении; длит. огня 5 р.; в конце — `smoke` |
| `oil` + `electric` | искра: поджигает масло только если ток нанёс урон ≥ 1 (то же, что `oil` + `fire`) |
| `water` + `fire` | **Пар**: `fire` и `water` удаляются, на их месте `steam` 2 р. |
| `ice` + `fire` | **Таяние**: `ice` → `water` (и `steam` не появляется), `fire` на клетке гаснет |
| `ice` + `water` | вода замерзает: `water` → `ice` на 6 р. (способности холода) |
| `water` + холод-способность | `water` → `ice`, существа в воде: `frozen` 1 р. без спаса |
| `toxgas` + `fire`/`electric` | **Взрыв газа**: по всем клеткам газа `2d6 × tier` fire (спас ЛВК — половина), толчок 1 клетка от центра, газ исчезает, оставляет `fire` 2 р. на центре |
| `acid` + `water` | растворение: `acid` исчезает, `water` остаётся и 2 р. считается «кислой» (вход: `acid` 1 р., без тика) |
| `acid` + `fire` | `acid` испаряется в `toxgas` 2 р. (1 клетка) |
| `blood` + `fire` | кровь испаряется, `smoke` 1 р. |
| `blood` + `ice` | розовый лёд: `ice` с эффектом `scent` на входе (косметика + `scent`) |
| `cringe` + `fire` | **Сгореть со стыда**: кринж-лужа выгорает, юниты в ней получают `panic` 2 р. без спаса, `cringe` исчезает |
| `cringe` + `proxy` | усиление: оба слоя объединяются, `cringe` тик ×1.5 и `overload` не снимается (кринж «питается» прокси) |
| `proxy` + `electric` | **Перенапряжение**: `electric` бьёт ×1.5 механику (по канону прокси ×1.5), `overload` +1 р., 2 р. дополнительно |
| `oil` + `water` | масло всплывает: остаётся `oil` (вода сверху), `wet` не ставится на вход, только `oiled` |
| `smoke` + `fire` | дым не горит; огонь +1 р. длит. (`smoke` усиливает задымление) |
| `smoke` + ветер | вне рамок |
| `oil` + `acid` | `acid` растворяет масло: обе исчезают, оставляя `smoke` 1 р. |
| `oil` + `ice` | лёд не образуется; `slick` на 3 р. |
| `ice` + `electric` | ток проходит по льду на клетку и разбивает его (`ice` → `water` 3 р.) |

Приоритет при нескольких комбинациях одного события: взрыв газа > пожар > электролужа > пар > остальное. Комбинации создают события `surfaceCombo {kind, tiles}` для лога и озвучки.

## 7. ИИ (`rules/ai.js`)

| Правило | Числа |
|---|---|
| Оценка клетки `planTile` | штраф `-surfaceValue` за вредную поверхность: `fire` −8, `electric` −7, `acid` −6, `toxgas` −6, `cringe` −5 (−9 если МРЛ ≤ 25%), `proxy` −4 (−8 для органики, +2 для техоньки), `oil` −3 (−12 если рядом/в клетке `fire`), `ice`/`water` −2 при риске `electric`/`fire` в радиусе 3 у врага-игрока; `T_HAZARD` −6 остаётся |
| Стоимость маршрута | вредные клетки в пути +2 к цене шага; не заходит, если альтернатива ≤ +3 клеток; игнорирует при `safePassage`, иммунитете, `burn` уже есть (огонь «хуже не станет») |
| Поджог | если у ИИ есть огненная способность/гранаты и у цели `oiled`/в клетке `oil`/`toxgas`: бонус к EV +4 за каждого юнита игрока на связанной поверхности; не использует, если рядом ≥ 1 союзник в зоне (штраф −6 за союзника) |
| Электро | при цели `wet`/в воде: EV ×1.5 и приоритет электро-способности |
| Толчок в поверхность | `push`/`scv-slam`: бонус EV +3, если клетка приземления — вредная поверхность и цель не иммунна |
| Создание поверхности | оценка `surfaceEV`: ценность = Σ (число врагов в области × вред поверхности) − (союзники в области × вред); ИИ ставит поверхность с `cringe`/`acid`/`toxgas` перед боем, если цели в узком проходе |
| Потушить/выйти | юнит с `burn`: если рядом `water` клетка в радиусе движения — идёт в воду; с `wet`+`electric` рядом — уходит; `shocked`/`frozen` — не двигается, использует способность |
| Роли | `ranged`/`caster` держатся вне поверхностей; `melee` игнорирует на 50% (берсерки, звери) |
| `scent` | звери (`mutants-j`) повышают вес цели с `scent` ×1.5 |

## 8. UI/фидбек

- **Подсветка клеток**: полупрозрачный цвет поверхности (см. таблицу 4, альфа 0.35) + 2 пикселя границы на крае лужи; анимации: огонь мерцает (3 кадра 0.15 с), ток — дуги, вода — блики, кислота — пузырьки, кринж — пульс. Газ — туман поверх юнитов.
- **Подсказка при наведении на клетку**: если на клетке поверхность — карточка `{title: имя, glyph, lines: [строка эффекта, «Осталось: N р.», «Взаимодействует: ...»]}` через `tooltip.js showTip`; при наведении на клетку в диапазоне хода — предупреждение «Шаг сюда: −N ЗДР, статус X» (оценка урона `surfaceEnterPreview`).
- **Подсказка статуса**: как сейчас (`statusTip`), + строки: «Осталось N раунда», «Источник: имя», числа тика/штрафов, «Снимается: ...», сопротивление носителя «Устойчив (×0.5)» / «Иммунитет».
- **Иконки статусов**: рядом с портретом и над юнитом (маленькие 12×12 по палитре: `wet` f, `oiled` 6/n, `shocked` h, `chilled`/`frozen` h/5, `acid` j, `irradiated` b, `panic` n, `glitch` h/n, `overload` a, `choking` 3, `scent` c, `slick` 4); у юнита максимум 4 иконки, остальные «+N».
- **Лог**: `surfaceCreate/surfaceEnd/surfaceCombo`, сегменты с подсветкой цветом поверхности; всплывающий `actPop` при комбинации («Электролужа!», «Пожар!», «Взрыв газа!»).
- **Звук** (сухо и механически, в духе Quasimorph): огонь — шипение, ток — треск, вода — всплеск, кислота — шипение, кринж — расстроенный «пик-пик», взрыв газа — глухой хлопок.
- **Тултип способности/предмета**: добавить «Создаёт: <поверхность> R, N р.» и «Накладывает: <статус>».

## 9. События и состояния
Новые события: `surfaceCreate {kind,x,y,size,turns,src}`, `surfaceEnter {target,kind,x,y}` (вместо `hazard`, `hazard` оставить для совместимости), `surfaceTick`, `surfaceEnd`, `surfaceCombo {a,b,result,tiles}`, `surfaceIgnite`. Новый op `surface {kind, size, turns}`; предметы/способности: поле `surface: {kind, size, turns}` рядом с `zone`. В `unitView` — список статусов с описанием и числами. Сейв: поверхности не сохраняются (бой не прерывается), `b.surfaces` пересоздаётся пустым.

## 10. Критерии приёмки
1. В бою кинуть `molotov` в клетку с `oil` — вся лужа загорается за раунд, юниты в ней получают `burn`; в логе событие `surfaceCombo`.
2. Юнит со статусом `wet`, получив `electric` урон, получает `shocked` без спаса и +50% урона; `electric` на воде расходится по всей связной луже.
3. `toxgas` + огонь: взрыв `2d6 × tier` по клеткам газа, газ исчезает; `water` + `fire` даёт `steam`, `ice` + `fire` — `water`.
4. Подсказка статуса и клетки показывает число раундов, механику и сопротивление; наведение на клетку хода показывает превью урона.
5. ИИ не заходит на `fire`/`acid`/`electric`, если есть путь вокруг, поджигает цель на `oil`, не ставит поверхность на своих (проверить симом: 20 боёв, потери от своих поверхностей < 10%).
6. `node tools/test.mjs` и `smoke-rules` зелёные; плейтест без ошибок консоли; старые сейвы грузятся.

## 11. Вне рамок
Ветер/распространение дыма, разрушение этажей и высота, поверхность «кислота на броне предмета» (износ предметов), мировая радиация вне боя (`irradiated` после боя — только рюкзак-антирад, без штрафа к ТЕЛ), анимации комбинаций кроме базовых, поверхности на мировой карте, звук по семплам (синтезом), «болото/лава».
