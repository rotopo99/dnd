# Спека: таланты — «примочки» героя (v1)

> Владелец — `game-designer`. Дата: 2026-11-03. Данные — `game/src/data/talents.js`.
> Канон: `docs/canon/rules/talents.md` («4 фита у нового перса»: расовый, род деятельности, фракционный, добрый или злой;
> «можно добавить свои»), `extra/stat-talents.md`, `rules/feats.md`. Операции и пассивки — `docs/specs/core-rules.md`.
> Мир, в котором работают небоевые таланты, — `docs/specs/world.md`.

## Цель для игрока
Таланты делают героя «своим»: два одинаковых Забивных отличаются тем, что один пьёт просроченный алкоголь и знает
пароли старых мастеров, а другой бывший культист с «Кодом смерти». Большинство талантов — **про мир** (проверки,
торговля, дороги, Киберспейс), меньшинство — небольшие боевые приёмы «раз за бой».

## Правила

### Слоты при создании (канон: 4 таланта)
| Слот | Откуда список | Условие |
|---|---|---|
| `race` расовый | `slot: 'race'`, `req.races` | 5 играбельных рас; оба подвида мутантов делят список |
| `job` род деятельности | `slot: 'job'`, `req.jobs` | класс открывает группы `JOB_GROUPS` (у каждого класса 2–4 группы) |
| `faction` фракционный | `slot: 'faction'`, `req.origins` | игрок выбирает **происхождение** (`ORIGINS`), оно даёт +20 репутации своей фракции |
| `alignment` мировоззрение | `slot: 'alignment'`, `req.alignment` | сначала выбор «добрый / злой» (сохраняется в герое), потом талант из списка |

### Боевые и мировые
- `kind: 'world'` — только вне боя. `kind: 'combat' | 'both'` — **боевой**.
- **Лимит активных боевых талантов** `COMBAT_TALENT_LIMIT`: 2 на уровнях 1–3, 3 на уровнях 4–5.
  Лишние боевые таланты лежат в запасе, набор меняется на отдыхе. Мировые таланты работают всегда, без лимита.
- При создании боевых может быть не больше 2 (то есть лимит уровня 1).

### Получение в мире
| Источник | `source.kind` | Как |
|---|---|---|
| уровни 2 и 4 | `level` | +1 талант: из своих списков `race` / `job` или `stat` (если характеристика ≥ порога) |
| наставник | `trainer` | NPC с `services: ['train']` и `trains: [id]`; цена `cost` кредов, иногда порог репутации `rep` и предмет `item` |
| репутация «союзники» | `rep` | второй фракционный талант этой фракции (если она есть в `ORIGINS`) |
| квест, тайник | `quest` | мистические дары, `noble-gesture` |
| импланты | `implant` | `services: ['implant']` (Никола, инженеры); цена `cost` |
| мутации | `mutation` | события аномалий, прокси-бурь, «Химеры»; только `organic` |
| Киберспейс | `cyberspace` | после успешного или неуспешного возвращения: d20 1–5 — уникальный талант, раз за игру |
| компаньон | `trainer` | одобрение ≥ +50 — учит своему таланту бесплатно |

### Сила
Цель: **один боевой талант ≈ +3–5 п.п.** к вкладу героя в победу партии (мера из `core-rules.md`, Сим A).
Ориентиры, по которым подобраны числа:
| Эффект | Примерная сила |
|---|---|
| +1 КБ, +1 к атаке, +2 инициатива, иммунитет к 1 статусу | ~+3 п.п. |
| способность «раз за бой» (дебафф при попадании, лечение 1d6, щит, метка +2) | ~+3–4 п.п. |
| `deathSave` 1, +2 КБ (только с 3-го уровня, имплант за 400 кредов) | ~+5 п.п. |
Классы (`classes/*.js`) и враги (`enemies.js`) таланты **не меняют**. Нынешний баланс (55–65% побед партии)
снят **без талантов**. Когда таланты подключат к герою, balance-tester прогоняет Сим A со случайными допустимыми
наборами и подстраивает **составы боёв**, а не классы. Талант, вклад которого > +5 п.п., режется (числа — в таблице ниже).

### Механика
- `passives` — пассивки ядра (`op`: `kb`, `hit`, `dmg`, `init`, `resist`, `immuneStatus`, `regen`, `deathSave`,
  `advantage`, `statBonus`). Подставляются в `buildCreature` вместе с расовыми и классовыми.
- `abilities` — способности по схеме ядра, id с префиксом `talent-`, у всех `usesPerBattle: 1`, если не сказано иное.
- `world` — эффекты вне боя:
  `{ check: 'skill', bonus: N }` (прибавка к проверке), `{ check: 'skill', adv: true }` (навык становится специализацией),
  `{ worldFlag: 'id', value?, factions? }` (флаг для систем мира; закрытый список `WORLD_FLAGS` в `talents.js`).
- `todo` — талант ждёт доработки, **игроку не предлагается** (`talentAllowed` возвращает `false`).

### Расширения схемы (предложение программисту)
1. `buildCreature({ …, talents: ['id', …] })` — добавляет `passives` и `abilities` активных боевых талантов.
2. Пассивка `{ maxHp: N }` (а также `maxMrl`, `maxEnr`) — прибавка к максимуму ресурса. Нужна для «Железной воли».
3. Условие пассивки `cond: 'targetWounded'` (цель ниже 100% ЗДР) — для «Игры с жертвой».
4. Пассивка «урон атакующему в ближнем бою» (`thorns: { dice, dmgType }`) — для «Кислотного пота».
5. Смена оружия (предметы) — для «Быстрого привыкания» (мир v1.1).

## Классовые «примочки» (предложение, вне `talents.js`)
Фирменный предмет класса, выдаётся при создании, **только мировые эффекты** (баланс боя не трогаем).
Улучшается у наставника своего класса. Реализация — после предметов (v1.1). ❓ — ждёт решения человека.
| Класс | Примочка | Эффект в мире |
|---|---|---|
| Забивной | Арматура с изолентой | Атлетика: выбить дверь / завал без проверки раз за узел |
| Техномант | Самопальный дека-браслет | терминалы: Хакинг +2; видит состояние терминала (`ritual`/`dead`/`ours`) издали |
| Мутант | Банка с «Химерой» | событие мутации по желанию на отдыхе (риск: d20 1–5 — дебафф до отдыха) |
| Айтишник | Мультитул из хлама | крафт аптечки или гранаты на отдыхе |
| Рейнджер | Кибер-кошка (канон: гаджет «Кибер-кошка») | разведка соседнего узла: состав боя виден до входа |
| Арбитр | Жетон Арбитра | в поселениях «подозрительны» считаются «нейтральны» для входа |
| Уголовник | Отмычка-глушилка | одна тихая отмычка за отдых (автоуспех Взлома) |
| Эколог | Гербарий | Биология +2, находит лечебные травы (аптечка) на привале |
| Рэпер | Микрофон | выступление в поселении: креды и +3 репутации раз за визит (проверка Убеждения) |
| СлавоТех | Оберег Старого бога | партия защищена от прокси-бурь региона техоньков |
| КиберТех | Флешка с кодом Судьи | терминалы культа: перепрошивка Магией Судьи с преимуществом; побег из Киберспейса +2 (культ −5 за использование) |

## Состояния и события
- Герой: `talents: [id]`, `activeCombat: [id]` (≤ лимита), `origin`, `alignment` — в сохранении (`world.md`, п. 8).
- События: `talentGained { id, source }`, `talentLoadoutChanged` (на отдыхе). Мир читает `world` эффекты при проверках,
  встречах, торговле, отдыхе, побеге из Киберспейса.

## UI/фидбек
- Создание: 4 карточки слотов после выбора расы и класса; карточка таланта — имя, значок **Б/М**, одна строка эффекта,
  строка канона («Из настолки» / «Новое»). Боевые сверх лимита — серые с подсказкой.
- В бою способности талантов — в общей панели действий со значком таланта.
- В проверке навыка строка лога называет талант: «+2 Глазомер», «преимущество: Замок — не преграда».
- Новый талант — баннер «Новый талант: …» и короткий звук (sound-designer).

## Критерии приёмки
1. При создании у героя ровно 4 таланта, по одному на слот; список каждого слота фильтруется по расе, классу,
   происхождению и мировоззрению (`talentAllowed`), таланты с `todo` не показываются.
2. Нельзя выбрать больше 2 боевых талантов на уровне 1; на уровне 4 активных боевых может быть 3.
3. `buildCreature` с талантом «Кожевник» даёт КБ на 1 больше, чем без него; способность «Грязный боец» появляется
   в бою, срабатывает раз за бой и при попадании накладывает `blind`.
4. Проверка Обмана андроидом с «Фальшивыми эмоциями» показывает +2 в логе; с `adv: true` бросок идёт с преимуществом.
5. Происхождение «Пираты» даёт +20 пиратам и распространяет репутацию по матрице (`world.md`, п. 3).
6. Скелету недоступно происхождение «Мусорщики», андроиду — «Жестяное братство», мутанту — «АИ Партия».

## Вне рамок
Фиты из `rules/feats.md` (крупные перки — позже, как награда союзникам фракций), таланты из несыгранных рас
(кринжгоны, техоньки, духи), условные пассивки до расширения движка, смена оружия, классовые примочки до предметов.
