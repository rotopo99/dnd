# Спека: «Третий исход» — глобальный таймер, гейты сюжета, насыщенность мира

Дата: 2026-11-07, game-designer. Основание: `docs/FEEDBACK-2026-11-07.md` (Этап B), канон («Судья ищет идеальное тело», «Альфа-Гармония разобьётся», время игры 2015), `docs/specs/levels-20.md`.

## 1. Глобальный таймер

### Цель для игрока
Мир живёт и без героя: культ копит силу, Судья тянется к телу. Каждое решение «потратить день» чего-то стоит (как водяной чип в Fallout 1), но запас достаточен, чтобы сделать побочное, если не топтаться. Чувство: «успею, но не всё».

### Как идёт время сейчас (проверено в коде)
- `save.day` (старт 1, `world/state.js`) растёт **только в пути**: +1 за каждый пройденный день маршрута (`world-map.js:211`, `hopDays` = `route.days`, ночной переход на 2+ дня экономит 1 день). Дни маршрута = `ceil(km / SPEED)`, SPEED: road 40, trail 25, wild 20, sea 150, lake 100, canoe 60, tunnel 30; район внутри узла = 0 дней. Средний маршрут по карте ≈ 9 дней, макс. 39.
- Отдых, торговля, бои, диалоги **дней не стоят**. Это нужно изменить: отдых = 1 день (иначе таймер обходится «отдыхом на месте» нулевой ценой и не давит на фарм). Бои и диалоги по-прежнему 0.

### Правила
| Параметр | Значение |
|---|---|
| Единица | игровой день `save.day` |
| Старт таймера | флаг `prologue-done` (тот же, что открывает `mq-exodus`); `save.exodus = { start: day, ext: 0, mark: 0 }` |
| Дедлайн D | `start + T0 + ext` |
| T0 (базовый запас) | **B × 1.20** , округлить вверх до 5. B — «базовый маршрут» (см. ниже). **Измерено: B = 402 → T0 = 485** (`node tools/sim/xp-route.mjs`, 2026-11-07; решение режиссёра — формула ×1.2, потолок 240 не применён) |
| Потолок продления `ext` | 60 дней (сумма по всем источникам) |
| Отдых на узле | +1 день (бесплатно при дружелюбии больше не отменяет день) |
| Осталось | `left = D − save.day` |

**Результат (2026-11-07, `tools/sim/xp-route.mjs`, флаг `--stops N` — остановок на регион):** 1 остановка/регион — B = 402 (16 остановок, 46 переходов, 386 дн. пути + 16 отдыха) → **T0 = 485**; 2/регион — 749; все узлы с боями/квестами — 1556 (53 остановки, 148 переходов). Средний переход ≈ 8,4 дн., поэтому оценка «B ≤ 170» в спеке не сходится с картой; T0 ≤ 240 потребует сократить дни маршрутов (SPEED) — вопрос дизайнеру.

**Расчёт B (задача баланс-тестеру).** Расширить `tools/sim/xp-route.mjs` (или новый `days-route.mjs`): пройти регионы в порядке xp-route кратчайшими маршрутами `ROUTES`, + 1 день отдыха на каждый узел с боями/квестами. Это B для «средней прохождки» (15–20 узлов-остановок, 40–55 переходов). Затем T0 = ceil5(B × 1.20), проверить: запас 15–25 % при ext=0. Если B > 170, поднять T0 до B×1.15 и вернуть напряжение за счёт цен/эскалации (стр. ниже), но T0 ≤ 240. Игрок, который идёт «в лоб» к финалу, тратит ~60 % T0; который выполняет все побочки и союзы, получает ext и укладывается; который фармит и отдыхает без нужды — проигрывает.

### Продление (`ext`, одноразово, при выполнении; id квестов/флагов существуют)
| Дело | Условие | + дней |
|---|---|---|
| Терминал `term-villages` | выключен или перепрошит (`FINALE_TERMINALS`, `locations.js:529`) | +8 |
| Терминал `term-agrozone` | то же | +8 |
| `cc-terminal-1/2/3` | то же, за каждый | +6 |
| Перепрошивка (вместо слома) любого из 5 | исход `ours` | +4 сверх |
| `mq-beacons` завершён (флаг `beacons-out`) | союз с Нейтральными селениями | +10 |
| `mq-agro-fire`: `agro-marta` ИЛИ `agro-order` ИЛИ `agro-truce` | один из исходов, `truce-failed` — +0 | +8 |
| `sq-cult-mines` завершён | сорван ритуал в шахтах | +6 |
| `sq-terminals` (`terminals-marked`) | отмечены терминалы | +4 |
| `sq-archon` завершён | помощь «сосуду» Архонту (знание об исходе) | +6 |
| Итого возможно | | 79 → срезается до 60 |

Привязка в данных: поле квеста/терминала `exodus: { ext: N }`; выдаётся в `grant()`/`applyTerminal` один раз (флаг `exo-ext:<id>`). Журнал: «Исход отложен на N дней».

### Отметки эскалации (по доле остатка, `left / (T0 + ext)`; пересчёт при смене `day`)
| Метка | Доля | Эффект (все мягкие, обратимо только отметкой 1–2 через дела) |
|---|---|---|
| 1 «Шёпот» | ≤ 75 % | Слух по радио; в регионах культа/Дикие земли шанс встречи +1 к порогу (d20 ≤ 3×danger+1); NPC упоминают исход |
| 2 «Культ активен» | ≤ 50 % | Появляются отряды культа на дорогах всех регионов 8+ (бой `<prefix>`=cult, уровень региона); пошлины на входах +25 % |
| 3 «Души материализуются» | ≤ 30 % | Случайные встречи: материализованные души (враг «Скрилет-ревенант», уровень региона, МРЛ-урон); цены в лавках +20 %; ночёвка вне узла: помеха на спас от потери МРЛ |
| 4 «Альфа-Гармония разобьётся» | ≤ 15 % (или `left ≤ 25`, что раньше) | Цеpеведущее событие: платформа падает (канон). Хаб теряет услуги: нет отдыха, торговли техникумов, тренеров; беженцы — NPC-руины (маркер места крушения на карте открыт). Квесты Гармонии закрываются со штрафом (`harmony-fallen`). Оставшиеся 4 хаба работают |
| 5 «Последний круг» | ≤ 5 % | Все цены +40 %, встречи на пути = только враги культа, Сера вызывает к узлу |
| 0 | `left ≤ 0` | Воплощение, см. ниже |

Метки односторонние (назад не откатываются), кроме эффектов цен/встреч, которые берутся из текущей метки.

### Ноль: воплощение Судьи
- Событие `exodus-zero` при любом входе в узел или при завершении дня пути: затемнение, сообщение, герои телепортируются к `cc-node` (если не в Киберспейсе).
- Бой `w-cc-finale` (v4, ур. 20) идёт **без** `reduce`-бонусов и без `finaleMods`, плюс у босса «Воплощение»: +25 % ЗДР, терминалы все `ritual`. Если средний уровень партии ниже 15 — бой не ослабляется (человек: «игра не должна быть лёгкой»).
- Исход: победа → флаг `node-destroyed-late`, концовка «Пирровa победа» (мир потерян, герои живы; текст сценаристу). Поражение → «Судья воплотился» (плохой финал, конец игры, сохранение-слот не удаляется, можно загрузить).
- Если до нуля игрок успел закрыть `mq-exodus` (`exodus-stopped`) — таймер выключается, метки сбрасываются (кроме падения Гармонии, оно остаётся).

### UI/фидбек
- HUD мира (`world-map.js:594`, строка «День …»): добавить «Исход: N дн.» цвет `C['b']`, ≤ 30 % — красный, мигание при ≤ 5 %; до `prologue-done` не показывать.
- Тултип: «Судья ищет сосуд. Каждый день без остановки ритуалов — шаг к воплощению. Продлевается делами.» + список метки.
- Журнал (`journal.push`): запись при каждой метке и при продлении; в журнале квеста `mq-exodus` — строка «Осталось N дней».
- Слухи: радио «Голос Пустошей» и 1 реплика у NPC каждого узла на метках 1–3 (в `npc-dialogue.js`, хук `mq-exodus`).
- Звук: низкий гул на метках 2+, удар колокола при падении Гармонии (запрос sound-designer).
- Подтверждение: перед маршрутом >5 дней при метке ≥ 3: «Это займёт N дн. До исхода останется M».

### Критерии приёмки
1. До `prologue-done` таймера нет; после — `save.exodus` создан, HUD показывает `T0` минус пройденное.
2. Отдых +1 день; переход в 6 дней уменьшает остаток на 6 (ночной переход — на 5 при `days ≥ 2`).
3. Каждый источник продления срабатывает ровно один раз (повторный вход/перезагрузка не удваивает); сумма ≤ 60.
4. Метки 1–5 срабатывают на своих порогах и один раз; метка 4 ломает хаб Гармонии, сохранение/загрузка помнит состояние.
5. `left ≤ 0` запускает финал без бонусов; `exodus-stopped` отключает таймер.
6. Симуляция: «средний маршрут» при ext=0 заканчивается с запасом 15–25 % дней (отчёт balance-tester).

### Вне рамок
Таймер на побочных квестах; ночь/день суточный цикл; возврат в прошлое; новые финальные катсцены (текст — сценарист, отдельно).

## 2. Гейт сюжета `mq-exodus` по уровню (квесты 1–5 не трогаем)
Стадии 1–2 (`data`, `go-city`, ворота) остаются как есть — это «ранний вход». Гейты на стадии, где идёт эскалация:

| Стадия | Гейт | Как показать |
|---|---|---|
| `find-node` (улицы мёртвых, `cc-dead-streets`) | средний уровень партии ≥ 12 ИЛИ флаг `gate-passed-early` (игрок пошёл на риск) | Дверь/стража: «Здесь лучше не бывать до ур. 12» (предупреждение, не стена) |
| Бой Кибер-Жреца в силе / `cult`-узлы Сокральни | ур. ≥ 16 (рекомендация) — предупреждение в кнопке боя при −3 | Использовать `levels` региона |
| `assault` (`w-cc-finale` v4) | **жёсткий**: ср. ур. ≥ 17 ИЛИ `exodus-zero` ИЛИ обязательно закрыты ≥ 3 из 5 терминалов (`FINALE_TERMINALS`) И Военпром/Кринжгоны посещены (флаги входа `visited:warprom`, `visited:cringegons`) | Сера: «Ты не готов. Узел сожрёт тебя». Кнопка серая с причиной |
| Путинляндия (регион, ур. 15–19) | вход разрешён с ур. 12 (рекомендация), жёсткий гейт — нет | Предупреждение в карточке узла |
Исход: `mq-exodus` остаётся 3-го ур. по записи, но `level` поля поднять до 17 (журнал/сортировка); добавить в `requires` `{ avgLevel: 12 }` для стадии `find-node`. Тот же `requires.avgLevel` добавить в движок квестов (программист). Старые сейвы: поле необязательное, нет — гейт выключен.

## 3. План «насыщенности мира» (задача сценаристу)
Стартуем с минимума на узел, затем растим по регионам. На каждый узел — **мин. 3 NPC**, из них 1 с мелким заданием, 1 тайник, 1 разовое событие. Данные: `data/world/npcs.js` (или актуальный), `quests-v3.js` (sq-*), `events.js`, `locations.js` (поле `caches`/`finds`, скрытые находки по навыку `perception`), `text/npc-dialogue.js`.

| Группа регионов | NPC (всего) | Мелкие задания | События | Тайники |
|---|---|---|---|---|
| Хаб + ближний круг (Гармония, Селения, ЖБ, Пираты) | +24 | +10 | +8 | +12 |
| Второй круг (Мутанты-Ж, Мусорщики, Агрозона, Мутанты-Р, Техоньки, Механиды) | +36 | +14 | +12 | +18 |
| Дальние (Отступники, Дикие земли, Военпром, Кринжгоны) | +24 | +10 | +10 | +12 |
| Столицы (АИ, Культ) | +14 | +6 | +8 | +8 |
| **Итого** | **~98** | **~40** | **~38** | **~50** |

Правила: мелкое задание — 1 стадия (принеси/поговори/проверка), награда 50–150 XP × (уровень региона/5), кредиты/предмет; 1 из 4 имеет бонус «исход +2 дня» (до потолка 60). Тайник: проверка `perception`/`survival` СЛ 10+2×(ур. региона/3), награда предмет/креды. События: ротация раз в 20 дней (часть привязана к меткам эскалации). Первой волной — узлы с 1–2 NPC, они же и проверяются через `tools/playtest.mjs`.
