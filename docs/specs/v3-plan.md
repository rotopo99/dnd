# v3 — расширение мира по канон-карте

> Режиссёр, 2026-11-04. Запрос человека: «Расширяем мир, пул врагов, NPC, городов, локаций, мест, квесты, сюжет, орудия, броню, предметы. Не бойся заимствовать идеи откуда-либо, главное — чтобы по сеттингу подходили. И добавь гибкое создание персонажей игрокам».

## Источник географии
`docs/canon/map/` (MAP.md, map.png) и `game/src/data/world/canon-map.js`: 14 фракций-государств, **37 бургов с населением**, **25 авторских маркеров** (Дача Бабки, Бункер Лиса, Дозорка Джона, Бункер Куксиуса, Лиза, Артём, Могила Виктора, 5 меток Lox, Вооружение, Спутник, Выжигатель Вайба, Киберспейс, Крушение Небесного базара, Место крушения Альфа-Гармонии, Великий Храм, Великая Арена, Ледяной ринг, Семя Чумы, Экспедиция исцеления, Великий Мех, Марта), POI генератора (подземелья, руины, некрополи, монстры, банды, пиратские воды, поля битв).
**Постоянные id мест — поле `slug`** в `canon-map.js` (например, `putinlyandiya`, `dacha-babki`, `lox-3`). Все отделы ссылаются на них.

## Отделы и владение файлами (волна 1)
| Отдел | Файлы |

| Сценарист | `docs/story/main-plot.md`, `game/src/data/world/quests-v3.js`, `npcs.js` (добавления), `text/npc-dialogue.js` (добавления), истории авторских маркеров |
| Программист движка | `game/src/rules/*` — снаряжение, предметы в бою, правила оружия канона (ступени владения по типам, очередь: скорострельность и отдача), гибкое создание (валидация) |
